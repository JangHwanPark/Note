## `getByRole`의 핵심 — Role 종류 (WAI-ARIA)

`getByRole('button', ...)`의 첫 인자가 WAI-ARIA role:

- [WAI-ARIA 1.2 — Role Definitions (W3C 공식 명세)](https://www.w3.org/TR/wai-aria-1.2/#role_definitions)
- [MDN — ARIA roles](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles)

자주 쓰는 role:

| Role | 매핑되는 요소·용도 |
| --- | --- |
| `button` | `<button>`, `role="button"`, submit input |
| `link` | `<a href>`, `role="link"` |
| `textbox` | `<input type="text">`, `<textarea>` |
| `checkbox` | `<input type="checkbox">` |
| `radio` | `<input type="radio">` |
| `heading` | `<h1>` ~ `<h6>` (`level` 옵션) |
| `dialog` | `<dialog>`, `role="dialog"`, 모달 |
| `listitem` | `<li>` |
| `list` | `<ul>`, `<ol>` |
| `row` / `cell` | 테이블 행·셀 |
| `tab` / `tabpanel` | 탭 UI |
| `navigation` | `<nav>` |
| `region` | `<section>` with `aria-label` |
| `alert` | `role="alert"`, 토스트 |
| `status` | `role="status"`, polite 알림 |
| `img` | `<img>` |

## 자동 추천 도구

본인이 짠 셀렉터가 안정적인지 모를 때 / 어떤 role·name으로 잡을지 모를 때:

- [Codegen (CLI)](https://playwright.dev/docs/codegen) — `pnpm exec playwright codegen http://localhost:3000` 으로 UI 클릭 → 추천 셀렉터 자동 생성
- [VS Code Extension](https://playwright.dev/docs/getting-started-vscode) — "Pick locator" 기능, IDE 안에서 hover로 셀렉터 추출

## 추천 읽기 순서

1. **[Locators 메인](https://playwright.dev/docs/locators)** — 한 페이지에 7가지 `getBy*` + 우선순위 + 자주 쓰는 패턴이 다 있음. 가장 가성비 좋음.
2. [Best Practices — Use locators](https://playwright.dev/docs/best-practices#use-locators) — 우선순위 권장 이유
3. [WAI-ARIA Role Definitions](https://www.w3.org/TR/wai-aria-1.2/#role_definitions) — role 종류 헷갈릴 때 사전처럼
4. [Locator class](https://playwright.dev/docs/api/class-locator) — `.filter()`·`.nth()` 보조 패턴 필요할 때

1번만 봐도 90% 커버. 나머지는 막힐 때 검색.
