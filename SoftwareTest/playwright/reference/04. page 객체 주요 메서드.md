# page 객체 주요 메서드

`page`는 한 탭(브라우저 페이지)을 조작하는 객체. Playwright fixture로 주입된다.

```ts
test('...', async ({ page }) => {
  // page 사용
});
```

## 네비게이션

| 메서드 | 용도 |
| --- | --- |
| `page.goto(url, opts?)` | URL 이동. `waitUntil: 'load' \| 'domcontentloaded' \| 'networkidle'` |
| `page.reload()` | 새로고침 |
| `page.goBack()` / `page.goForward()` | 히스토리 |

baseURL 설정 시 상대 경로 가능:
```ts
await page.goto('/projects/Testea');  // → http://localhost:3000/projects/Testea
```

## 요소 찾기 (Locator)

권장 우선순위 — [Locator 우선순위](./05.%20Locator%20%EC%9A%B0%EC%84%A0%EC%88%9C%EC%9C%84.md) 참고.

| 메서드 | 우선도 |
| --- | --- |
| `page.getByRole(role, opts?)` | **1순위** — `getByRole('button', { name: '저장' })` |
| `page.getByLabel(text)` | 2순위 — form 입력 |
| `page.getByPlaceholder(text)` | 3순위 |
| `page.getByText(text, opts?)` | 4순위 — 정적 텍스트 |
| `page.getByTestId(id)` | 마지막 보루 — `data-testid` |
| `page.locator(selector)` | CSS·XPath 셀렉터 (가능하면 위 것들 우선) |

전부 Locator를 반환. 즉시 평가 X, 사용 시점에 평가.

## 상호작용

| 메서드 | 용도 |
| --- | --- |
| `locator.click()` | 클릭 |
| `locator.dblclick()` | 더블 클릭 |
| `locator.fill(value)` | input·textarea 값 채움 (기존 내용 덮어씀) |
| `locator.type(text)` | 한 글자씩 타이핑 (보통 fill이 더 빠르고 안정적) |
| `locator.press(key)` | 키 입력 — `'Enter'`, `'Tab'`, `'Control+A'` |
| `locator.check()` / `locator.uncheck()` | 체크박스 |
| `locator.selectOption(value)` | `<select>` |
| `locator.hover()` | 호버 |
| `locator.focus()` / `locator.blur()` | 포커스 |
| `locator.dragTo(targetLocator)` | 드래그 |
| `locator.setInputFiles(path)` | 파일 업로드 |

전부 **자동 wait + actionability check** (보이는지, 클릭 가능한지 확인 후 동작).

## 조회

| 메서드 | 용도 |
| --- | --- |
| `locator.textContent()` | 텍스트 |
| `locator.innerText()` | 렌더된 텍스트 |
| `locator.inputValue()` | input 값 |
| `locator.getAttribute(name)` | 속성 |
| `locator.count()` | 매칭 개수 |
| `locator.isVisible()` | boolean (검증은 `expect` 추천) |

검증에는 `expect`를 쓰고, 조건 분기에 값 필요할 때만 위 메서드 사용.

## 대기

| 메서드 | 용도 |
| --- | --- |
| `page.waitForURL(url)` | URL 변경 대기 |
| `page.waitForLoadState('networkidle')` | 네트워크 안정 |
| `page.waitForResponse(url)` | 특정 응답 |
| `page.waitForRequest(url)` | 특정 요청 |
| `locator.waitFor(opts)` | 요소 상태 — `state: 'visible' \| 'hidden' \| 'attached' \| 'detached'` |

대부분 `expect`로 처리되므로 명시적 wait는 **API 요청 검증** 같은 특수한 경우에만.

## 네트워크 제어

| 메서드 | 용도 |
| --- | --- |
| `page.route(url, handler)` | 요청 가로채기 (모킹) |
| `page.unroute(url)` | 해제 |

```ts
await page.route('**/api/dashboard', route =>
  route.fulfill({ json: { /* mock */ } })
);
```

## 디버깅·유틸

| 메서드 | 용도 |
| --- | --- |
| `page.screenshot(opts?)` | 스크린샷 |
| `page.evaluate(fn)` | 페이지 컨텍스트에서 JS 실행 |
| `page.title()` | document.title |
| `page.url()` | 현재 URL |
| `page.content()` | HTML 전체 |
| `page.pause()` | 디버거 일시 정지 (Playwright Inspector) |

## 다이얼로그·콘솔

```ts
page.on('dialog', dialog => dialog.accept());
page.on('console', msg => console.log(msg.text()));
```

native dialog (`alert`/`confirm`)와 console message는 이벤트 리스너로 처리.

## 자주 쓰는 패턴

### 폼 제출
```ts
await page.goto('/projects/new');
await page.getByLabel('이름').fill('Test Project');
await page.getByLabel('동의').check();
await page.getByRole('button', { name: '생성' }).click();
await expect(page).toHaveURL(/\/projects\//);
```

### 클립보드
```ts
await page.getByRole('button', { name: '링크 복사' }).click();
const clipboard = await page.evaluate(() => navigator.clipboard.readText());
expect(clipboard).toContain('/projects/');
```

### 파일 업로드
```ts
await page.getByLabel('첨부').setInputFiles('./fixtures/sample.png');
```

## 한 줄 요약

> **`page.getByRole`로 찾고, Locator의 `click`·`fill`로 조작하고, `expect`로 검증.** 이 세 줄이 spec의 90%.
