## 각 노트 공통 구조
1. **한 줄 요약** — 외울 핵심
2. **정의 / 비유**
3. **핵심 포인트** — 표 또는 리스트
4. **면접 답변 템플릿** — 30초 분량
5. **실무 / 자동화 맥락** (해당하는 경우)
6. **관련 개념** — 같이 자주 묻는 개념 링크
