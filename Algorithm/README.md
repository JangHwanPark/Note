## 알고리즘이란 ?
- 알고리즘(Algorithm)은 문제를 풀기 위한 절차를 차례로 적은 것이다
- 9세기 수학자 알콰리즈미(al-Khwarizmi)의 이름에서 온 말이다
- 이 폴더는 코딩 테스트 문제 풀이와 자주 쓰는 풀이 기법을 정리한다

<br/>

## 목차
- [입력 받기](./입력%20받기(Reading%20Input)) : 표준 입력을 읽는 템플릿, `/dev/stdin`과 `0`의 차이, `\r\n`과 공백 처리, 입력 형태별 자르기
- [배열](./배열(Array)) : 인덱스와 범위 초과 막기, 선형 탐색, 거꾸로 출력, 최댓값과 최솟값의 시작값
- [문자열](./문자열(String)) : 문자열에서 찾기, 바꾸기, 지우기, 회전, 비교(UTF-16 코드 단위 순서)
- [반복문](./반복문(Loop)) : for와 while을 고르는 기준, 누적 변수와 break로 반복 활용하기
- [빈도수 세기](./빈도수%20세기(Frequency%20Counter)) : 객체, Map, 카운트 배열, Set으로 등장 횟수 세기와 그릇별 차이
- [해시](./해시(Hash)) : key로 바로 찾는 저장 방식, 객체와 Map, 해시 테이블과 해시 함수
- [정렬](./정렬(Sort)) : sort()의 비교 함수 패턴과 퀵 정렬 구현, 최악 O(n²)이 나오는 입력
- [완전 탐색](./완전%20탐색(Brute%20Force)) : 가능한 경우를 모두 확인하는 방법과 분류, 입력 크기로 가능 여부 가늠하기, 값 기준, 구간 단위, 시뮬레이션
- [dx dy 기법](./dx%20dy%20기법(Direction%20Arrays)) : 방향별 이동량 배열로 격자의 인접 칸 탐색하기, 4방향과 8방향
- [동적 프로그래밍](./동적%20프로그래밍(Dynamic%20Programming)) : 작은 문제의 답을 저장해 다시 쓰기, 탑다운과 바텀업
- [최대공약수, 최소공배수, 소수 판별](./최대공약수%20최소공배수%20소수%20판별(GCD,%20LCM%20and%20Prime)) : 유클리드 호제법, gcd로 lcm 구하기, √n까지 나눠 소수 판별, 에라토스테네스의 체
