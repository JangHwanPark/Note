## 알고리즘이란 ?
- 알고리즘(Algorithm)은 문제를 풀기 위한 절차를 차례로 적은 것이다
- 9세기 수학자 알콰리즈미(al-Khwarizmi)의 이름에서 온 말이다
- 이 폴더는 코딩 테스트 문제 풀이와 자주 쓰는 풀이 기법을 정리한다

<br/>

## 목차
- [입력 받기](./입력%20받기(Reading%20Input)) : 백준과 Node.js에서 표준 입력을 읽는 템플릿과 입력 형태별 처리
- [배열](./배열(Array)) : 배열 자료구조와 다루는 법
- [문자열](./문자열(String)) : 문자 찾기 등 문자열 문제
- [반복문](./반복문(Loop)) : for와 while을 고르는 기준과 반복문의 활용
- [빈도수 세기](./빈도수%20세기(Frequency%20Counter)) : 배열과 문자열에서 값이 몇 번 나오는지 세는 방법
- [해시](./해시(Hash)) : 해시 함수와 해시 테이블
- [정렬](./정렬(Sort)) : JS sort()와 퀵 정렬
- [완전 탐색](./완전%20탐색(Brute%20Force)) : 가능한 경우를 모두 확인하는 방법, 값 기준, 구간 단위, 상황을 가정하는 시뮬레이션
- [dx dy 기법](./dx%20dy%20기법(Direction%20Arrays)) : 격자에서 상하좌우로 이동하는 방법
- [동적 프로그래밍](./동적%20프로그래밍(Dynamic%20Programming)) : 작은 문제의 답을 저장해 큰 문제를 푸는 방법
- [최대공약수, 최소공배수, 소수 판별](./최대공약수%20최소공배수%20소수%20판별(GCD,%20LCM%20and%20Prime)) : GCD, LCM, 소수 판별 구현
