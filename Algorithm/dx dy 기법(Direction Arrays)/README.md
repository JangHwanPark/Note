## dx dy 기법이란 ?
- 2차원 격자에서 인접한 칸으로 이동할 때, 방향별 이동량을 배열(`dx`, `dy`)에 미리 적어 두고 반복문으로 돌리는 기법
- 상하좌우나 대각선을 조건문 여러 개 대신 반복문 하나로 처리한다
- 격자 시뮬레이션, 너비 우선 탐색(BFS), 깊이 우선 탐색(DFS) 같은 격자 탐색 문제에서 흔히 쓴다

### dx, dy (Delta x, Delta y)
dx, dy는 x의 변화량, y의 변화량이라는 뜻으로 읽는다. 수학에서 변화량을 Δx(델타 x)로 쓰는 것과 같은 의미로 쓰는 이름이다.
코드에서 `dx[dir]`, `dy[dir]` 는 방향 `dir` 로 한 칸 갈 때 x와 y가 얼마나 바뀌는지를 적은 표다.

나침반에 방향마다 "몇 칸 옆으로, 몇 칸 위아래로"를 적어 둔 것과 같다. 어느 방향으로 갈지만 고르면 이동량은 표에서 읽으면 된다.

<br/>

## 왜 쓸까
조건문으로 상하좌우를 하나씩 쓰면 아래처럼 된다. 여기서 `x` 는 열(가로 위치), `y` 는 행(세로 위치)이고, `n` 은 열의 개수, `m` 은 행의 개수다.

```js
if (x + 1 < n) console.log(x + 1, y);  // 오른쪽
if (x - 1 >= 0) console.log(x - 1, y); // 왼쪽
if (y + 1 < m) console.log(x, y + 1);  // 아래
if (y - 1 >= 0) console.log(x, y - 1); // 위
```

방향마다 경계 검사와 처리 코드가 반복된다. 대각선까지 8방향이 되면 같은 모양의 조건문이 8개가 되고, 처리 코드를 고칠 때 8군데를 모두 고쳐야 한다.

dx dy 기법을 쓰면 반복문 하나로 끝난다.

```js
const dx = [1, -1, 0, 0]; // x(열) 변화량
const dy = [0, 0, 1, -1]; // y(행) 변화량

for (let dir = 0; dir < 4; dir++) {
  const nx = x + dx[dir];
  const ny = y + dy[dir];

  if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue; // 격자 밖이면 건너뜀
  console.log(nx, ny);
}
```

경계 검사가 한 줄로 모이고, 방향을 바꾸거나 늘릴 때는 두 배열만 고치면 된다. 3열 2행 격자(`n = 3`, `m = 2`)의 왼쪽 위 칸 `(0, 0)` 에서 실행하면 격자 밖인 왼쪽과 위는 건너뛰고 `1 0`, `0 1` 두 칸만 출력된다.

<br/>

## 좌표 순서 주의
2차원 배열은 보통 `arr[행][열]`, 즉 `arr[y][x]` 로 읽는다. x를 먼저 쓰는 수학 좌표 `(x, y)` 와 순서가 반대라서 자주 헷갈린다.

- y는 행(row)이고 아래로 갈수록 커진다
- x는 열(column)이고 오른쪽으로 갈수록 커진다
- 그래서 dy가 1이면 아래, -1이면 위다

문제마다 행을 x, 열을 y로 쓰는 경우도 있으니, 풀기 전에 어느 변수가 행인지 먼저 정하고 경계 검사(`n`, `m`)도 거기에 맞춘다.

<br/>

## 방향 배열 정하기
### 4방향
시계 방향(오른쪽, 아래, 왼쪽, 위)으로 놓으면 "오른쪽으로 90도 돌기"를 `dir = (dir + 1) % 4`, "왼쪽으로 돌기"를 `dir = (dir + 3) % 4` 로 쓸 수 있다. 방향을 바꿔 가며 움직이는 시뮬레이션 문제에서 유용하다.

| 방향 | dx | dy | 다음 칸 |
| --- | --- | --- | --- |
| 오른쪽 | 1 | 0 | (x+1, y) |
| 아래 | 0 | 1 | (x, y+1) |
| 왼쪽 | -1 | 0 | (x-1, y) |
| 위 | 0 | -1 | (x, y-1) |

```js
const dx = [1, 0, -1, 0];
const dy = [0, 1, 0, -1];
```

### 8방향 (대각선 포함)
```js
const dx = [1, 1, 0, -1, -1, -1, 0, 1];
const dy = [0, 1, 1, 1, 0, -1, -1, -1];

for (let dir = 0; dir < 8; dir++) {
  const nx = x + dx[dir];
  const ny = y + dy[dir];

  if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
  console.log(nx, ny);
}
```

이 순서는 4방향과 같이 오른쪽에서 시작해 오른쪽 아래, 아래, 왼쪽 아래, 왼쪽, 왼쪽 위, 위, 오른쪽 위로 도는 시계 방향이다. 짝수 번째(0, 2, 4, 6)만 고르면 4방향 순서와 같아진다. 3×3 격자 가운데 `(1, 1)` 에서 실행하면 주변 8칸이 모두 출력된다. 방향을 돌릴 때는 4방향처럼 `(dir + 1) % 8` 이 45도 회전이 된다.
