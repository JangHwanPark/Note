## 탐색 범위가 범위가 명확할 때 완전 탐색
```text
세 자리 자연수 중 두 숫자의 합이, 
나머지 다른 숫자가 되는 서로 다른 숫자의 개수를 구해보세요.

예를 들어 숫자 312는 1 + 2 = 3 이므로 조건을 만족합니다.
```

이 문제는 단순하게, 가능한 모든 범위에 대해 일일이 따져보는 완전탐색을 진행해 볼 수 있습니다. 범위 안의 특정 숫자를 정해본 뒤, 해당 숫자가 조건을 만족하는지 확인해보면 됩니다.

```js
let cnt = 0;
for (let i = 100; i < 1000; i++) {
    const [d1, d2, d3] = Array.from(String(i), Number);
    if (d1 + d2 === d3 || d1 + d3 === d2 || d2 + d3 === d1) {
        cnt += 1;
    }
}

console.log(cnt);

// 126
```
이처럼 탐색 범위가 직접 주어진 경우라면, 해당 범위 내의 숫자들을 일일이 살펴보며 진행하는 방식의 완전탐색을 이용하여 문제를 깔끔하게 해결할 수 있습니다.

## 탐색 범위가 애매한 경우의 완전 탐색
```text
A, B 앞에 카드가 단 한 장만 놓여있습니다.
A의 경우 카드에 적혀있는 숫자가 10보다 작으면 5점을, 10 이상이며 20 미만이면 8점을,
그렇지 않다면 10점을 얻게 됩니다.
B의 경우  카드에 적혀있는 숫자가 6보다 작으면 12점을, 6 이상이며 15 미만이면 10점을,
그렇지 않다면 6점을 얻게 됩니다.

예를 들어, 카드에 적혀 있는 숫자가 9였다면, A는 5점을, B는 10점을 얻게 되어 총
15점을 얻게 됩니다.

A, B가 얻을 수 있는 점수의 합 중 가능한 최댓값은 무엇일까요?
```

이 문제에서는 카드에 적혀 있을 수 있는 숫자의 범위가 주어져있지 않습니다. 다만, 카드의 숫자가 0보다 작거나 넉넉잡아 30보다 큰 경우는 굳이 살펴볼 필요가 없다는 것을 어렵지 않게 알 수 있습니다. 그 이유는 해당 범위를 벗어나는 경우라면 숫자가 0 혹은 30
일 때와 동일한 점수를 얻게 되기 때문입니다.

따라서 이 문제는 단순하게, 0에서 30 사이의 숫자들에 대해 일일이 점수를 따져보는 완전탐색을 진행해 볼 수 있습니다.

코드는 다음과 같이 작성해볼 수 있습니다.
```js
let maxScore = 0;

function getScoreA(num) {
    if (num < 10) {
        return 5;
    } else if (num < 20) {
        return 8;
    } else {
        return 10;
    }
}

function getScoreB(num) {
    if (num < 6) {
        return 12;
    } else if (num < 15) {
        return 10;
    } else {
        return 6;
    }
}

for (let i = 0; i < 31; i++) {
    scoreA = getScoreA(i);
    scoreB = getScoreB(i);
    maxScore = Math.max(maxScore, scoreA + scoreB);
}

console.log(maxScore);

// 18
```
이처럼 탐색 범위가 직접 주어지지 않은 경우라도, 꼭 탐색이 필요한 범위를 잘 지정하여 해당범위 내의 숫자들을 일일이 살펴보며 진행하는 방식의 완전탐색을 이용하여 문제를 깔끔하게 해결할 수 있습니다.
