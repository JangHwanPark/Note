## 구간 단위로 완전탐색 (Brute Force by Range)
### 구간 정하기
> 핵심 질문: 구간이란 무엇인가?

구간은 말 그대로 `시작점과 끝점 사이의 연속된 범위`로 완전탐색에서는 `모든 가능한 시작점 i와 끝점 j를 시도`해서
그 안에 있는 원소들을 검사한다.

단순히 모든 조합을 보는 게 아니라 배열 내에서 연속된 부분(구간)을 하나씩 정해서 그 안의 합, 최댓값, 조건 등을 전부 확인 하는 방식이다.

모든 가능한 `시작 인덱스, 끝 인덱스`쌍을 전부 고려하는 방식이다. (즉, 한 배열에서 `시작점 i`를 정하면 `끝점 j`를 오른쪽으로 밀면서 가능한 모든 구간을 다 본다.)

```js
for (let i = 0; i < n; i++) {   // 시작점 고정
  for (let j = i; j < n; j++) { // 끝점 이동 (i부터 끝까지)
    // [i, j] 구간
  }
}
```
```text
n = 5 일떄 출력 예시
[0 ~ 0], [0 ~ 1], [0 ~ 2], [0 ~ 3], [0 ~ 4]
[1 ~ 1], [1 ~ 2], [1 ~ 3], [1 ~ 4]
[2 ~ 2], [2 ~ 3], [2 ~ 4]
[3 ~ 3], [3 ~ 4]
[4 ~ 4]
```

| 루프           | 역할                   | 비유                           |
| ------------ | -------------------- | ---------------------------- |
| **바깥 루프(i)** | 구간의 시작점을 정한다.      | 어디서부터 시작할지 정하는 사람          |
| **내부 루프(j)** | 끝점을 늘려가며 구간을 확장한다. | 시작한 곳에서 오른쪽으로 걸어가며 확인하는 사람 |

- 이때 i = 0, j = 0이면 길이 1짜리 구간 
- i = 0, j = 1이면 길이 2짜리 구간 
- 이렇게 모든 구간을 시도한다.

### 구간 개수 공식과 `n - k + 1`의 의미
> 핵심 질문: 길이가 k인 구간을 배열 길이 n에서 몇 개 만들 수 있을까?

배열의 인덱스는 0부터 n - 1까지로 길이가 k인 구간을 잡으면
구간의 시작점`i`와 끝점`j(i + k - 1)`은 다음과 같이 대응된다.

| 시작 i | 끝 j | 포함 인덱스           | 길이  |
| ---- | --- | ---------------- | --- |
| 0    | k-1 | [0, 1, ..., k-1] | k   |
| 1    | k   | [1, 2, ..., k]   | k   |
| 2    | k+1 | [2, 3, ..., k+1] | k   |
| ...  | ... | ...              | ... |
| n-k  | n-1 | [n-k, ..., n-1]  | k   |

구간이 유효하려면 끝 인덱스 `j = i + k - 1`이 배열의 마지막 인덱스`n - 1`을 넘어가면 안 된다.
```text
i + k - 1 <= n - 1
= i <= n - k
```

```js
const n = 6;
const k = 3;

// 가능한 모든 길이 3짜리 구간 출력
for (let i = 0; i <= n - k; i++) {
  console.log(`[${i} ~ ${i + k - 1}]`);
}
```
출력 결과: 총 4개 = n - k + 1개의 구간
```text
[0 ~ 2]
[1 ~ 3]
[2 ~ 4]
[3 ~ 5]
```

| 구간 길이 k | 배열 길이 n | 가능한 구간 수 | i의 범위   |
| ------- | ------- | -------- | ------- |
| 1       | n       | n        | 0 ~ n-1 |
| 2       | n       | n-1      | 0 ~ n-2 |
| 3       | n       | n-2      | 0 ~ n-3 |
| …       | …       | …        | …       |
| k       | n       | n-k+1    | 0 ~ n-k |

### 배열 기록 후 구간 정하기 (좌표형 문제로 확장)
> 핵심 질문: 단순 배열이 아니라 `위치(pos)`가 있을 땐 어떻게 구간을 정할까?

1. 입력이 (pos, 값) 형태일 경우 먼저 pos 기준으로 정렬해야 한다. 
2. 이후 arr[i].pos ~ arr[j].pos 를 `구간의 양끝`으로 본다. 
3. 이 구간 안에서 조건(예: G/H 개수 비교)을 확인한다.
```js
people.sort((a, b) => a.pos - b.pos);

for (let i = 0; i < n; i++) {
  let g = 0, h = 0;
  for (let j = i; j < n; j++) {
    if (people[j].letter === 'G') g++;
    else h++;
    if (g === h) res = Math.max(res, people[j].pos - people[i].pos);
  }
}
```

### 모든 구간 정하기 (완전탐색의 본질)
> 핵심 질문: `모든 구간`을 어떻게 전부 검사하나?

1. 모든 시작점 i를 잡는다. 
2. i에서부터 끝까지 확장하며 j를 늘린다. 
3. 각 구간에서 조건(개수, 합, 거리 등)을 검사한다.

즉, `i를 고정하고, j를 움직이며 가능한 모든 구간을 본다.`
