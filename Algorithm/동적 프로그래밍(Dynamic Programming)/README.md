## DP(동적 프로그래밍)란 ?
- 큰 문제를 작은 문제로 쪼개 풀고, 작은 문제의 답을 저장해 두었다가 다시 쓰는 풀이 방법
- 특정 알고리즘이라기보다는 문제를 푸는 방식에 가깝다
- 저장해 둔 값을 꺼내 쓰기 때문에 같은 계산을 두 번 하지 않는다

동적 프로그래밍(Dynamic Programming)의 programming은 코드를 짠다는 뜻이 아니라 계획을 세운다, 표를 채운다는 뜻에 가깝다. 작은 문제의 답을 표(DP 배열)에 하나씩 채워 가며 큰 문제의 답을 만든다는 의미로 이어진다.

<br/>

## 왜 필요할까
피보나치 수열은 앞의 두 수를 더해 다음 수를 만든다. `fib(n) = fib(n-1) + fib(n-2)`를 재귀로 그대로 옮기면 아래와 같다.

```js
let calls = 0;
const fib = (n) => {
  calls++;
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
};

console.log(fib(10)); // 55
console.log(calls);   // 177
```

`fib(10)` 하나를 구하는데 함수가 177번 호출된다. `fib(8)`은 `fib(10)`에서도, `fib(9)`에서도 불려서 같은 계산을 여러 번 반복하기 때문이다. n이 커지면 호출 횟수가 지수적으로 늘어 O(2^n)에 가까워진다.

이미 구한 `fib(8)`의 답을 어딘가 적어 두면 다시 계산할 필요가 없다. 이것이 DP의 핵심이다.

<br/>

## DP를 쓸 수 있는 조건
### 겹치는 부분 문제 (Overlapping Subproblems)
같은 작은 문제가 여러 번 반복해서 나와야 한다. 피보나치처럼 `fib(8)`을 여러 곳에서 다시 구해야 저장해 두는 의미가 있다. 작은 문제가 겹치지 않으면 그냥 분할 정복이다.

### 최적 부분 구조 (Optimal Substructure)
작은 문제의 답을 모으면 큰 문제의 답이 되어야 한다. `fib(10)`은 `fib(9)`와 `fib(8)`의 답만 알면 바로 구할 수 있다.

<br/>

## 탑다운 (Top-down)
큰 문제에서 시작해 작은 문제로 내려가는 방식이다. 재귀로 구현하고, 구한 답을 메모해 두었다가 같은 문제가 다시 오면 메모에서 꺼낸다. 이 메모를 메모이제이션(Memoization)이라고 한다.

```js
const memo = [];
let calls = 0;
const fib = (n) => {
  calls++;
  if (n <= 1) return n;
  if (memo[n] !== undefined) return memo[n]; // 이미 구했으면 꺼내 쓴다
  memo[n] = fib(n - 1) + fib(n - 2);
  return memo[n];
};

console.log(fib(10)); // 55
console.log(calls);   // 19
```

호출 횟수가 177번에서 19번으로 줄었다. 각 n을 한 번씩만 계산하므로 O(n)이다. 다만 n이 아주 크면 재귀가 깊어져 스택 오버플로가 날 수 있다.

<br/>

## 바텀업 (Bottom-up)
가장 작은 문제부터 시작해 n까지 차례로 표를 채우는 방식이다. 반복문으로 구현한다.

```js
const fib = (n) => {
  const dp = [0, 1];
  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }
  return dp[n];
};

console.log(fib(10)); // 55
console.log(fib(50)); // 12586269025
```

재귀를 쓰지 않아 스택 걱정이 없고, 코테에서는 이쪽을 더 자주 쓴다. 탑다운과 마찬가지로 O(n)이다.

<br/>

## DP 문제 푸는 순서
1. DP 배열의 한 칸이 무엇을 뜻하는지 정한다. (예: `dp[i]`는 i번째 피보나치 수)
2. 큰 문제를 작은 문제로 나타내는 점화식을 세운다. (예: `dp[i] = dp[i-1] + dp[i-2]`)
3. 더 쪼갤 수 없는 초기값을 채운다. (예: `dp[0] = 0`, `dp[1] = 1`)
4. 작은 값부터 n까지 채우고 `dp[n]`을 답으로 쓴다.

점화식을 세우는 1, 2단계가 가장 어렵다. 처음에는 n이 작은 경우를 손으로 몇 개 써 보고 규칙을 찾는 것이 빠르다.
