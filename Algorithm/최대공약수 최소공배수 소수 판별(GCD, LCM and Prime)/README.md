## 최대공약수 (GCD)
### 최대공약수 (Greatest Common Divisor)
두 수를 모두 나누어떨어지게 하는 수(공약수) 중 가장 큰 수다. 12와 18의 공약수는 1, 2, 3, 6이고 최대공약수는 6이다.

가로 12, 세로 18인 바닥을 같은 크기의 정사각형 타일로 빈틈없이 덮을 때 쓸 수 있는 가장 큰 타일의 한 변 길이와 같다.

### 유클리드 호제법 (Euclidean Algorithm)
호제(互除)는 서로 나눈다는 뜻이다. 두 수를 번갈아 나누며 나머지를 구하는 방식이라 이런 이름이 붙었다.

`a` 를 `b` 로 나눈 몫을 `q`, 나머지를 `r` 이라 하면 `a = b * q + r` 이다. 이때 `gcd(a, b) = gcd(b, r)` 이 성립한다. a와 b를 모두 나누는 수는 `r = a - b * q` 도 나누고, 반대로 b와 r을 모두 나누는 수는 `a = b * q + r` 도 나누기 때문이다. 두 쌍의 공약수가 똑같으니 최대공약수도 같다.

이 과정을 나머지가 0이 될 때까지 반복하면, 그때 남은 수가 최대공약수다.

```text
gcd(48, 18)
48 = 18 * 2 + 12  → gcd(18, 12)
18 = 12 * 1 + 6   → gcd(12, 6)
12 = 6 * 2 + 0    → 나머지 0, 답은 6
```

```js
function gcd(a, b) {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    const r = a % b;
    a = b;
    b = r;
  }
  return a;
}

gcd(48, 18); // 6
gcd(18, 48); // 6
gcd(0, 5);   // 5
gcd(-12, 8); // 4
```

`a` 가 `b` 보다 작아도 된다. 첫 반복에서 `18 % 48` 이 18이 되어 두 수가 저절로 자리를 바꾼다. 두 번 나눌 때마다 큰 쪽 수가 절반 이하로 줄어들기 때문에 반복 횟수는 O(log(min(a, b)))다.

## 최소공배수 (LCM)
### 최소공배수 (Least Common Multiple)
두 수의 공통 배수 중 가장 작은 양수다. 6과 8의 공배수는 24, 48, ...이고 최소공배수는 24다.

두 수의 곱은 최대공약수와 최소공배수의 곱과 같다(`a * b = gcd(a, b) * lcm(a, b)`). 두 수가 함께 가진 인수(최대공약수)가 곱 안에 두 번 들어 있으므로, 한 번 나눠 주면 최소공배수가 남는다.

```text
lcm(6, 8) = (6 * 8) / gcd(6, 8) = 48 / 2 = 24
```

```js
function lcm(a, b) {
  if (a === 0 || b === 0) return 0;
  return Math.abs(a / gcd(a, b) * b);
}

lcm(6, 8); // 24
lcm(4, 6); // 12
```

`a * b` 를 먼저 계산하지 않고 `a / gcd(a, b)` 를 먼저 하는 것은 중간값이 커지는 것을 막기 위해서다. 자바스크립트의 숫자는 64비트 부동 소수점이라 정수가 넘쳐서 음수가 되지는 않지만, `Number.MAX_SAFE_INTEGER`(2^53 - 1)를 넘으면 정확한 정수를 표현하지 못한다. 예를 들어 `a = 2**30 + 1`, `b = (2**30 + 1) * 3` 은 둘 다 안전한 정수지만 곱 `a * b` 는 2^53을 넘어 정확하지 않다. 순서를 바꿔 `a / gcd(a, b) * b` 로 계산하면 중간값이 작게 유지되어 정답 3221225475가 나온다(`BigInt` 로 계산한 값과 같다). 결과 자체가 2^53을 넘을 수 있으면 처음부터 `BigInt` 로 계산한다.

## 소수 판별 (O(√n))
### 소수 (Prime Number)
1보다 크고, 1과 자기 자신으로만 나누어떨어지는 수다. 2, 3, 5, 7, 11, ...이 소수이고, 1은 소수가 아니다.

### 왜 √n까지만 볼까
n이 `n = a × b` 로 나타난다면 a와 b 중 하나는 반드시 √n 이하다. 둘 다 √n보다 크면 곱이 n보다 커지기 때문이다. 그래서 √n 이하의 수로 나눠 보고 하나도 나누어떨어지지 않으면 소수다.

판별 순서는 아래와 같다.

1. n이 2보다 작으면 소수가 아니다
2. 2는 소수이고, 2가 아닌 짝수는 소수가 아니다
3. 3부터 √n까지 홀수로 나눠 보고, 하나라도 나누어떨어지면 소수가 아니다

`i * i <= n` 처럼 √n 자신까지 포함해야 한다. 49는 √49 = 7로 나누어떨어지는데, `i * i < n` 으로 쓰면 7을 검사하지 않아 49를 소수로 잘못 판단한다.

```js
function isPrime(n) {
  if (n < 2) return false;
  if (n === 2) return true;
  if (n % 2 === 0) return false;
  for (let i = 3; i * i <= n; i += 2) {
    if (n % i === 0) return false;
  }
  return true;
}

[0, 1, 2, 3, 4, 9, 25, 49, 97, 100].filter(isPrime); // [2, 3, 97]
```

## 여러 수를 한꺼번에: 에라토스테네스의 체
1부터 N까지 소수를 모두 구하거나 개수를 셀 때는 수마다 `isPrime` 을 부르는 것보다 체(Sieve of Eratosthenes)가 빠르다. 2부터 시작해 소수를 하나 찾을 때마다 그 배수를 모두 지운다. 끝까지 지워지지 않은 수가 소수다.

```js
function sieve(N) {
  const isPrime = new Array(N + 1).fill(true);
  isPrime[0] = isPrime[1] = false;
  for (let i = 2; i * i <= N; i++) {
    if (!isPrime[i]) continue;
    for (let j = i * i; j <= N; j += i) isPrime[j] = false; // i의 배수 지우기
  }
  return isPrime;
}

sieve(100).filter(Boolean).length; // 25 (100 이하 소수의 개수)
```

배수 지우기를 `i * i` 부터 시작하는 것은 그보다 작은 배수(`2i`, `3i`, ...)가 이미 더 작은 소수의 배수로 지워졌기 때문이다. 시간 복잡도는 O(N log log N)으로 알려져 있다.
