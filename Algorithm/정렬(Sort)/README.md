## 정렬이란 ?
- 값들을 정해 둔 기준(크기, 이름, 날짜 등)에 따라 차례대로 늘어놓는 일
- 정렬해 두면 이분 탐색, 중복 찾기, 가장 큰 값 몇 개 고르기처럼 많은 문제가 쉬워진다
- 코딩 테스트에서는 대부분 자바스크립트의 `sort()` 로 정렬하고, 정렬 알고리즘 자체를 묻는 문제에서만 직접 구현한다
