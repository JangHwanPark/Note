## dx dy 기법이란?
dx/dy 패턴이란 2차원 배열(격자)에서 인접한 위치를 탐색할 때, 방향을 미리 배열로 정의해두고 이를 반복문으로 처리하는 기법을 말한다.
이를 사용하면 조건문을 여러 번 쓰지 않고도 상하좌우(또는 대각선 등)의 인접 칸을 간결하게 탐색할 수 있어 코드가 **간결하고 유지보수성이 높으며**  
2차원 배열이나 시뮬레이션 문제, BFS/DFS 같은 그래프 탐색에서 표준적으로 사용된다.

<br/>

## 왜 dx dy 기법을 사용할까?
### 조건문 사용(상하좌우 탐색)
```js
if (x + 1 < n) console.log(x + 1, y); // 오른쪽
if (x - 1 >= 0) console.log(x - 1, y); // 왼쪽
if (y + 1 < m) console.log(x, y + 1); // 아래
if (y - 1 >= 0) console.log(x, y - 1); // 위
```
조건문만 사용하여 탐색할 때(상하좌우 탐색)코드가 길고 지저분하며 방향이 늘어나면 조건문이 그만큼 증가한다.

### dx/dy 패턴 사용 (상하좌우 탐색)
```js
const dx = [1, -1, 0, 0]; // x축 이동
const dy = [0, 0, 1, -1]; // y축 이동

for (let dir = 0; dir < 4; dir++) {
  const nx = x + dx[dir];
  const ny = y + dy[dir];

  if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
  console.log(nx, ny);
}
```
반복문 한 번으로 네 방향을 처리 가능하며 방향을 바꿀 때 배열만 수정하면 된다.

### dx dy를 사용했을때 장점
코드 간결성: if문 여러 개 대신 반복문 한 번으로 처리 가능

유지보수성: 방향을 바꿀 때 dx/dy 배열만 수정하면 됨

표준성: BFS, DFS 같은 탐색 문제에서 널리 사용되는 기법이라 협업 시에도 직관적

> Tip - 좌표계 컨벤션
> 보통 2차원 배열은 `arr[y][x]` 형태로 접근한다.
> y: 행(row, 세로 방향)
> x: 열(column, 가로 방향)
> dx는 열(좌우), dy는 행(상하)를 이동한다.

<br/>

## 어떻게 사용할까?
### 기본 4방향 (시계방향)
| 방향 | dx | dy | 의미       |
| -- | -- | -- | -------- |
| 우  | 1  | 0  | (x+1, y) |
| 하  | 0  | 1  | (x, y+1) |
| 좌  | -1 | 0  | (x-1, y) |
| 상  | 0  | -1 | (x, y-1) |

### 8방향 탐색 (대각선 포함)
```js
const dx = [-1, -1, -1, 0, 1, 1, 1, 0];
const dy = [-1, 0, 1, 1, 1, 0, -1, -1];

for (let dir = 0; dir < 8; dir++) {
  const nx = x + dx[dir];
  const ny = y + dy[dir];

  if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;

  console.log(nx, ny);
}
```
