## for와 while은 언제 쓸까
- 반복 횟수가 정해져 있으면 `for`, 언제 끝날지 미리 모르면 `while` 을 쓴다
- 둘 다 같은 일을 할 수 있지만, 고르는 기준을 정해 두면 종료 조건을 잘못 적는 실수가 줄어든다
- 반복문으로 자주 푸는 패턴(개수 세기, 합, 곱, 하나라도와 모두)은 [반복문의 활용](./반복문의%20활용(Loop%20Patterns)/README.md)에 정리했다

### 반복 (Loop)
loop의 사전적 의미는 고리, 둥근 테다. 끝이 처음으로 이어져 계속 도는 모양이다.
프로그래밍에서는 같은 코드 묶음을 조건이 맞는 동안 되풀이하는 구조를 말한다. 고리를 언제 끊을지(종료 조건)를 정하는 것이 반복문의 핵심이다.

<br/>

## 고르는 기준
`for` 는 반복 횟수가 정해져 있을 때 쓴다. 명령 N개를 차례로 처리하거나 카드를 정해진 횟수만큼 섞는 것처럼, 미리 주어진 횟수를 다 돌면 끝난다.

`while` 은 끝나는 시점을 미리 모를 때 쓴다. 숫자가 1이 될 때까지, 빙산이 둘로 나뉠 때까지처럼 상태가 바뀌다가 조건을 만족하는 순간 끝난다.

### for를 쓰는 경우
반복 횟수가 문제에 주어진다. "명령 N개를 순서대로 처리한다"면 N번 돌면 끝이므로 횟수를 세는 변수가 곧 종료 조건이다.

```js
for (let i = 0; i < n; i++) {
  // i번째 명령 처리
}
```

### while을 쓰는 경우
반복이 끝나는 시점이 상태에 달려 있다. Collatz 문제(짝수면 2로 나누고 홀수면 3을 곱해 1을 더하기를 n이 1이 될 때까지 되풀이)는 몇 번 돌지 미리 알 수 없다.

```js
let n = 6;
let steps = 0;
while (n !== 1) {
  n = n % 2 === 0 ? n / 2 : 3 * n + 1;
  steps++;
}
console.log(steps); // 8 (6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1)
```

`while` 은 조건 안의 값이 반복 중에 반드시 바뀌어야 한다. 바뀌지 않으면 끝나지 않는 무한 루프가 된다.
