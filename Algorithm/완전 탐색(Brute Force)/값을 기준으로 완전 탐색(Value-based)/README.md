## 값 기준 완전 탐색이란 ?
- 답이 될 수 있는 값을 범위 안에서 하나씩 정해 보고, 그 값이 조건을 만족하는지 확인하는 방식
- 범위가 문제에 주어지면 그대로 쓰고, 주어지지 않으면 살펴볼 필요가 있는 범위를 직접 정한다
- 범위를 정할 때는 그 밖의 값이 범위 끝의 값과 결과가 같다는 근거가 있어야 한다

### 탐색 범위 (Search Space)
범위의 사전적 의미는 일정하게 한정된 영역이다.
값 기준 완전 탐색에서 탐색 범위는 답이 될 수 있는 값을 모두 담은 구간을 말한다. 이 범위를 빠짐없이, 그러나 필요 이상으로 넓지 않게 정하는 것이 풀이의 대부분이다.

자물쇠 번호를 000부터 999까지 차례로 돌려 보는 것과 같다. 어느 번호부터 어느 번호까지 돌릴지만 정하면 나머지는 기계적으로 확인하면 된다.

<br/>

## 탐색 범위가 주어질 때
```text
세 자리 자연수 중 두 숫자의 합이,
나머지 다른 숫자가 되는 서로 다른 숫자의 개수를 구해보세요.

예를 들어 숫자 312는 1 + 2 = 3 이므로 조건을 만족합니다.
```

세 자리 자연수라는 범위(100부터 999까지)가 이미 주어졌다. 이 범위의 숫자를 하나씩 정해 보고, 각 자리 숫자로 조건을 확인하면 된다.

```js
let cnt = 0;
for (let i = 100; i < 1000; i++) {
  const [d1, d2, d3] = Array.from(String(i), Number);
  if (d1 + d2 === d3 || d1 + d3 === d2 || d2 + d3 === d1) {
    cnt += 1;
  }
}

console.log(cnt); // 126
```

`Array.from(String(i), Number)` 는 숫자를 문자열로 바꾼 뒤 한 글자씩 꺼내 다시 숫자로 바꾼다. `312` 는 `[3, 1, 2]` 가 된다. 확인하는 수는 900개뿐이라 시간 걱정이 없다.

## 탐색 범위가 애매할 때
```text
A, B 앞에 카드가 단 한 장만 놓여있습니다.
A의 경우 카드에 적혀있는 숫자가 10보다 작으면 5점을, 10 이상이며 20 미만이면 8점을,
그렇지 않다면 10점을 얻게 됩니다.
B의 경우 카드에 적혀있는 숫자가 6보다 작으면 12점을, 6 이상이며 15 미만이면 10점을,
그렇지 않다면 6점을 얻게 됩니다.

예를 들어, 카드에 적혀 있는 숫자가 9였다면, A는 5점을, B는 10점을 얻게 되어 총
15점을 얻게 됩니다.

A, B가 얻을 수 있는 점수의 합 중 가능한 최댓값은 무엇일까요?
```

카드 숫자의 범위가 주어지지 않았다. 하지만 점수가 바뀌는 경계는 6, 10, 15, 20뿐이다. 20 이상이면 어떤 숫자든 점수가 같고, 0보다 작은 숫자도 0일 때와 점수가 같다. 그래서 0부터 30까지만 보면 모든 경우를 본 것과 같다. 30은 마지막 경계 20보다 넉넉하게 잡은 값이다.

```js
function getScoreA(num) {
  if (num < 10) return 5;
  if (num < 20) return 8;
  return 10;
}

function getScoreB(num) {
  if (num < 6) return 12;
  if (num < 15) return 10;
  return 6;
}

let maxScore = 0;
for (let i = 0; i <= 30; i++) {
  const scoreA = getScoreA(i);
  const scoreB = getScoreB(i);
  maxScore = Math.max(maxScore, scoreA + scoreB);
}

console.log(maxScore); // 18
```

카드 숫자가 10부터 14 사이일 때 A는 8점, B는 10점으로 합이 18점이 되어 가장 크다. 실행해 보면 10, 11, 12, 13, 14에서 모두 18이 나온다.

`scoreA`, `scoreB` 는 `const` 로 선언했다. 선언 없이 `scoreA = ...` 로 쓰면 일반 스크립트에서는 전역 변수가 생기고, strict 모드나 ES 모듈에서는 `ReferenceError` 가 난다.

<br/>

## 체크리스트에 대입하기
[완전 탐색](../README.md)의 "풀기 전에 확인할 것"을 카드 문제에 대입하면 다음과 같다.

- 탐색 공간: 0부터 30까지. 점수가 바뀌는 마지막 경계가 20이라 그 밖은 결과가 같다
- 조건 판별: `getScoreA`, `getScoreB` 로 떼어 냈다
- 중복: 카드는 한 장이라 고를 것이 하나뿐이다
- 시간: 31개 × 판별 O(1)
