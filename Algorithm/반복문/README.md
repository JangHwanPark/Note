## 참고 (for vs while 차이)

| 구분             | 사용하는 경우                | 종료 기준               | 예시                                         |
| -------------- | ---------------------- | ------------------- | ------------------------------------------ |
| **`while` 루프** | "끝 조건이 **언제 될지 모를 때**" | 상태가 변하다가 특정 조건 만족 시 | Collatz(3n+1) 문제, 빙산 녹이기, 시뮬레이션 종료 시점이 불명확 |
| **`for` 루프**   | "반복 횟수가 **정해져 있을 때**"  | 미리 주어진 횟수(N번 등)     | 야바위 문제, 카드 섞기, 일정 횟수 게임 시뮬레이션              |
