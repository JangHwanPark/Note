# Open Source Contributions
PR 한 줄보다, 그 한 줄을 만들기까지의 판단을 기록합니다.

이 문서는 실무와 사이드 프로젝트에서 매일 사용하는 오픈소스 라이브러리들에 직접 기여한 과정과 회고를 정리한 저장소입니다.

단순히 `어떤 PR이 머지되었다`는 사실보다, 거대한 코드베이스에서 기여할 자리를 어떻게 식별하는지, 리뷰 피드백을 어떻게 해석해 의사결정에 반영하는지, 한 PR의 스코프를 어떻게 지켜내는지를 중심에 두었습니다. 매번의 기여에서 얻은 감각을 다음 기여로 이어가는 과정 자체를 기록하는 것이 이 저장소의 목적입니다.
