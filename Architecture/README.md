## 아키텍처란 ?
- 아키텍처(Architecture)의 사전적 의미는 건축 양식, 건물의 구조다
- 공학적으로는 소프트웨어를 어떤 부분으로 나누고, 그 부분들이 서로 어떻게 연결되는지를 정한 구조를 말한다
- 이 폴더는 서비스 구조(BFF, SaaS)와 코드베이스 구조(FSD, 모노레포)를 정리한다

<br/>

## 목차
- [아키텍처 종류](./아키텍처%20종류(Architecture%20Types)) : 시스템 아키텍처와 폴더, 코드 구조에 초점을 둔 아키텍처 용어 구분
- [BFF (Backend For Frontend)](./BFF(Backend%20For%20Frontend)) : 프론트엔드 전용 백엔드 계층, Next.js와 Spring 기반 예시
- [SaaS (Software as a Service)](./SaaS(Software%20as%20a%20Service)) : 설치하지 않고 인터넷으로 쓰는 서비스형 소프트웨어와 그 특징
- [FSD (Feature-Sliced Design)](./FSD(Feature-Sliced%20Design)) : 기능 단위로 프론트엔드 폴더를 나누는 설계 방법
- [모노레포 (Monorepo)](./모노레포(Monorepo)) : pnpm workspace로 모노레포를 만드는 기본 방법
