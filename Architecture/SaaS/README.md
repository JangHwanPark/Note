## SaaS (Software as a Service)
**SaaS(Software as a Service)** 는 "서비스형 소프트웨어"를 뜻하며, 소프트웨어를 설치하거나 직접 소유하지 않고 인터넷을 통해 구독 형식으로 사용하는 서비스 방식입니다.

## 예시
Gmail, Notion, Figma, Slack, Dropbox, Salesforce 등

## SaaS의 특징
- 인터넷 기반: 웹 브라우저만 있으면 언제 어디서나 사용 가능
- 구독 과금 모델: 월별/연별 요금으로 사용
- 중앙에서 유지관리: 사용자는 설치/업데이트 신경 안 써도 됨
- 확장성: 사용자 수나 기능을 쉽게 조절 가능

## SaaS와 다른 개념과의 차이
| 구분       | 설명                           |
|------------|--------------------------------|
| SaaS       | 사용자가 인터넷을 통해 소프트웨어를 "사용" |
| PaaS       | 애플리케이션 개발을 위한 플랫폼 제공     |
| IaaS       | 서버, 스토리지 등 인프라 자원 제공      |
