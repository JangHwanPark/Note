## MDA 프레임워크란 ?
- 게임을 메커닉스(Mechanics, 규칙), 다이내믹스(Dynamics, 규칙이 만드는 판의 흐름), 에스테틱스(Aesthetics, 플레이어가 느끼는 감정) 세 레이어(Layer)로 나눠 보는 틀이다. 레이어의 사전적 의미는 겹, 층이다
- 세 레이어는 원인과 결과로 이어진다. 규칙이 흐름을 만들고, 흐름이 감정을 만든다. 그래서 원하는 감정이 안 나오면 규칙으로 돌아가 고친다
- 출처는 로빈 휴니키(Robin Hunicke), 마크 르블랑(Marc LeBlanc), 로버트 주벡(Robert Zubek)의 2004년 논문 「MDA: A Formal Approach to Game Design and Game Research」다. 2001년부터 2004년까지 게임 개발자 콘퍼런스(GDC)의 Game Design and Tuning Workshop에서 가르친 내용이다

### 프레임워크 (Framework)
사전적 의미는 뼈대, 골조다. 설계에서는 무엇을 어떤 순서로 따질지 정해 주는 생각의 틀을 말한다. MDA도 정답을 주는 공식이 아니라 게임을 나눠 보고 이야기하는 틀이다.

<br/>

## 1. 왜 나왔나
- "재미있다", "재미없다"로는 무엇을 고칠지 알 수 없다. 논문은 게임을 이야기하기 어려운 이유가 어휘가 좁기 때문이라고 하며, "재미"나 "게임플레이"보다 구체적인 말이 필요하다고 쓴다
- 게임은 책이나 영화와 달리 완성된 뒤에도 실제로 무슨 일이 벌어질지 정해져 있지 않다. 규칙이 플레이어와 만나 그때그때 다른 판을 만든다
- 게임은 프로그래머, 디자이너, 연구자처럼 배경이 다른 사람이 함께 만든다. 코드의 작은 결정이 플레이 경험까지 번지고, 원하는 경험은 결국 어딘가의 코드로 구현돼야 한다

그래서 MDA는 규칙(코드)과 경험(감정) 사이를 오가며 같은 말로 이야기하게 해 주는 틀로 나왔다.

<br/>

## 2. 세 레이어
같은 게임을 세 레이어로 나눠 본다. 아래 표의 Quake와 모노폴리는 논문에 나오는 게임이지만, 세 레이어를 한 줄로 짝지은 것은 내 정리다. Quake 줄의 메커닉스와 다이내믹스는 논문이 슈팅 게임 일반의 예로 든 것이고, 모노폴리 줄의 땅과 임대료는 게임 규칙을 덧붙인 것이다.

| 레이어 | 논문의 정의 | 쉽게 말하면 | Quake | 모노폴리 |
|----|------------|-----------|-------|---------|
| 메커닉스 | 데이터 표현과 알고리즘 수준의 게임 구성 요소. 플레이어에게 주어지는 행동, 동작, 조작 장치 | 디자이너가 직접 정하는 규칙과 부품 | 무기, 탄약, 부활 지점 | 주사위 두 개, 땅, 임대료와 독점 규칙 |
| 다이내믹스 | 메커닉스가 플레이어의 입력과 서로의 출력에 반응하며 시간에 따라 만드는 실행 중의 행동 | 규칙대로 실제로 굴러가는 판의 흐름 | 한자리에서 기다리기(캠핑), 저격 | 부자는 더 부자가 되고 가난한 사람은 더 가난해짐 |
| 에스테틱스 | 플레이어가 게임과 주고받을 때 일어나기를 바라는 감정 반응 | 플레이어가 느끼는 재미의 종류 | 도전, 감각, 경쟁, 판타지 | 격차가 벌어지면 긴장과 내가 판을 움직인다는 느낌이 사라짐 |

### 메커닉스 (Mechanics)
- 사전적 의미는 역학, 기계가 돌아가는 짜임새다. 게임에서는 게임이 돌아가는 짜임새, 곧 규칙과 부품이다
- MDA의 흐름에서 디자이너가 직접 정하는 레이어다. 다이내믹스와 에스테틱스는 메커닉스를 거쳐 간접적으로 바뀐다
- 콘텐츠(레벨, 에셋 등)와 함께 다이내믹스를 받친다. [4장](../04.시스템과%20콘텐츠란(Systems%20and%20Content)/README.md)의 시스템과 콘텐츠 구분과 같은 짝이다

### 다이내믹스 (Dynamics)
- 사전적 의미는 동역학, 힘을 받아 시간에 따라 변하는 움직임이다. 게임에서는 규칙이 플레이어를 만나 실제로 움직이는 모습이다
- 규칙에 직접 적혀 있지 않은 행동이 여기서 생긴다. 카드 게임의 섞기, 트릭 따기, 베팅이라는 규칙에서 블러핑이 생기는 것이 논문의 예다
- 디자이너는 다이내믹스를 직접 만들 수 없고, 메커닉스를 통해 간접적으로만 바꾼다

### 에스테틱스 (Aesthetics)
- 사전적 의미는 미학, 아름다움을 느끼는 감각이다. MDA에서는 뜻을 넓혀 플레이어에게 일어나기를 바라는 감정 반응을 말한다
- "재미"를 대신할 구체적인 이름들이다. 종류는 3절에 정리했다

<br/>

## 3. 에스테틱스의 여덟 가지
논문은 "재미"를 대신할 어휘로 여덟 가지를 든다. 이것이 전부는 아니라고 밝힌다.

| 에스테틱스 | 논문의 설명 | 풀어 쓰면 | 그 감정을 만드는 다이내믹스의 예(논문) |
|-----------|-------------|-----------|--------------------------------------|
| 감각 (Sensation) | Game as sense-pleasure | 보고 듣고 손으로 느끼는 즐거움 | |
| 판타지 (Fantasy) | Game as make-believe | 다른 세계, 다른 존재가 되어 보는 즐거움 | |
| 서사 (Narrative) | Game as drama | 이야기가 펼쳐지는 즐거움 | 긴장이 오르고, 풀리고, 마무리되는 흐름 |
| 도전 (Challenge) | Game as obstacle course | 장애물을 넘는 즐거움 | 시간 압박, 상대의 플레이 |
| 동료애 (Fellowship) | Game as social framework | 사람들과 함께하는 즐거움 | 한 팀끼리만 정보 공유, 혼자서는 어려운 승리 조건(적 기지 점령 등) |
| 발견 (Discovery) | Game as uncharted territory | 모르는 곳을 알아내는 즐거움 | |
| 표현 (Expression) | Game as self-discovery | 나를 드러내고 알아 가는 즐거움 | 아이템을 사고 짓고 얻는 시스템, 레벨과 세계를 만드는 시스템, 나만의 캐릭터 만들기 |
| 시간 보내기 (Submission) | Game as pastime | 별생각 없이 시간을 맡기는 즐거움 | |

- 빈칸은 논문이 다이내믹스 예를 들지 않은 항목이다
- 서사 줄의 예는 논문이 극적 긴장(Dramatic tension)이라는 이름으로 든 것이다. 서사와 같은 항목으로 묶은 것은 내 정리다

한 게임은 여러 에스테틱스를 함께 노린다. 논문의 예는 아래와 같다.

| 게임 | 에스테틱스 |
|------|-----------|
| Charades (몸짓으로 단어 맞히기) | 동료애, 표현, 도전 |
| Quake (1인칭 슈팅) | 도전, 감각, 경쟁, 판타지 |
| The Sims | 발견, 판타지, 표현, 서사 |
| Final Fantasy | 판타지, 서사, 표현, 발견, 도전, 시간 보내기 |

Quake의 경쟁(Competition)은 여덟 항목에 없는 말이다. 목록이 닫혀 있지 않다는 예다.

<br/>

## 4. 세 레이어를 보는 방향
### 디자이너와 플레이어는 반대쪽에서 본다
```mermaid
flowchart LR
    M["메커닉스<br/>규칙"] --> D["다이내믹스<br/>판의 흐름"] --> A["에스테틱스<br/>감정"]
```

- 디자이너는 왼쪽에서 오른쪽으로 만든다. 규칙을 정하면 흐름이 생기고, 흐름에서 감정이 나온다
- 플레이어는 오른쪽에서 왼쪽으로 겪는다. 분위기를 먼저 느끼고, 흐름을 보고, 마지막에 규칙을 안다
- 요리와 같다. 요리사는 재료와 조리법을 고르지만 손님은 맛부터 느낀다

### 세 레이어는 렌즈다
- 논문은 세 레이어를 게임을 보는 각각의 렌즈(lens)라고 한다. 셋은 따로 떨어져 있지만 원인과 결과로 이어져 있다("separate, but causally linked")
- 두 방향을 함께 보면 한 레이어의 작은 변화가 다른 레이어로 번지는 것을 볼 수 있다
- 플레이어 쪽에서 보면 기능이 아니라 경험을 중심으로 설계하게 된다

<br/>

## 5. MDA로 게임 고치기
### 순서
1. 노릴 에스테틱스를 정한다 (예: 경쟁의 긴장)
2. 그 감정을 만드는 다이내믹스를 정한다 (예: 끝까지 누가 이길지 모르는 판)
3. 그 다이내믹스가 나오도록 메커닉스를 고친다
4. 플레이테스트를 하며 값을 다듬는다(튜닝)

논문은 이 순서를 에스테틱스 목표를 정하고, 그 목표를 받치는 다이내믹스를 끌어낸 뒤, 거기에 맞춰 메커닉스의 범위를 정하라고 표현한다.

### 예 : 모노폴리
| 단계 | 내용 |
|------|------|
| 문제 (에스테틱스) | 긴 판에서 몇 사람(때로는 한 사람)만 판에 마음을 쏟고, 긴장과 내가 판을 움직인다는 느낌이 사라진다 |
| 원인 (다이내믹스) | 부자일수록 남에게 더 큰 손해를 입히고, 가난한 사람은 더 가난해진다. 격차가 스스로 커지는 고리다 |
| 고치기 1 (메커닉스) | 뒤처진 사람 돕기. 가난한 사람에게 보조금, 부자에게 세금을 준다. 출발 칸을 지날 때, 감옥에서 나올 때, 일정 금액 이상의 독점을 행사할 때 계산한다 |
| 고치기 2 (메커닉스) | 시간 압박. 일정 비율 세금으로 돈을 빨리 쓰게 하기, 독점 수익 두 배, 일정 가치 이하 땅을 무작위로 나눠 주기로 게임을 빨리 끝낸다 |
| 튜닝 | 벌칙의 크기, 세율, 기준값을 되풀이해 다듬는다. 세금 계산이 너무 복잡하면 돈과 순위를 따라가기 어려워져 오히려 판에 마음을 쏟는 느낌을 해칠 수 있다 |

논문은 이렇게 고치면 독점의 현실을 재현하는 힘은 약해질 수 있지만 "현실이 늘 재미있지는 않다"고 덧붙인다.

### 에스테틱스가 바뀌면 모든 레이어가 바뀐다
논문은 술래잡기 기반의 아기 돌보기 게임을 대상만 바꿔 세 번 설계한다.

- 3~7세용 : 탐험과 발견이 중요하다. 아기가 놀람과 기대를 드러내게 하고, 숨을 곳은 미리 정해 둔다
- 7~12세용 : 더 도전적으로 한다. 9시 전에 모두 재우기 같은 시간 압박을 넣고, 아기가 숨을 곳을 스스로 고른다
- 14~35세용 : Splinter Cell이나 Thief 같은 잠입 게임이 된다. 판타지와 긴장이 중심이고, 적의 시야와 소리 감지가 필요하다

노리는 감정이 바뀌자 규칙과 AI까지 모두 바뀌었다. 설계를 에스테틱스에서 시작해야 하는 이유다.

## 6. 한계
MDA는 널리 쓰인 만큼 비판도 받았다. 원문을 읽은 두 글의 요지다.

- 볼프강 워크(Wolfgang Walk), 「From MDA to DDE」(2015)
  - 메커닉스가 너무 넓다. 그래픽 스타일처럼 규칙이 아닌 것까지 들어가, 사실상 디자이너가 만드는 모든 것을 뜻하게 된다
  - 에스테틱스라는 말이 일상적인 의미의 미학과 섞인다. 경험(Experience)이라는 말을 쓰자고 한다
  - 이야기(내러티브) 설계를 다룰 자리가 없다
  - 대안으로 DDE(Design, Dynamics, Experience)를 제안한다
- 루이스 클라우디우 실베이라 두아르트(Luiz Claudio Silveira Duarte), 「Revisiting the MDA framework」(2015)
  - 플레이어가 늘 에스테틱스부터 만나지는 않는다. 보드게임은 규칙서부터 읽으므로 메커닉스부터 만난다
  - 그래도 MDA가 망가진 것은 아니며, 순서에 묶이지 말고 유연하게 쓰자고 한다

두 비판 모두 세 레이어가 원인과 결과로 이어진다는 핵심은 버리지 않는다(해석).

<br/>

## 7. 정리
- MDA는 게임을 규칙(메커닉스), 판의 흐름(다이내믹스), 감정(에스테틱스)으로 나눠 보는 틀이다
- 디자이너는 규칙만 직접 고칠 수 있고, 감정은 흐름을 거쳐 간접적으로 만들어진다
- "재미"를 감각, 판타지, 서사, 도전, 동료애, 발견, 표현, 시간 보내기처럼 나눠 부르면 무엇을 노리고 무엇을 고칠지 말할 수 있다
- 설계는 노릴 감정에서 시작해 흐름, 규칙 순으로 내려가고, 플레이테스트로 다듬는다
- 메커닉스가 무엇까지 가리키는지, 플레이어가 어떤 순서로 게임을 만나는지는 게임마다 다를 수 있다는 점을 함께 기억한다
