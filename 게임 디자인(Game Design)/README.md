## 게임 디자인이란 ?
- 게임의 규칙, 목표, 진행 방식을 정해 플레이어가 겪을 경험을 설계하는 일이다
- 디자이너가 직접 정하는 것은 규칙이고, 재미는 플레이어가 그 규칙과 주고받는 동안 생긴다. 그래서 게임 디자인은 규칙을 통해 경험을 간접적으로 만드는 일이다
- 이 폴더는 재미와 놀이에 대한 이론에서 출발해, 게임을 보는 나의 관점(게임관)을 세우는 순서로 정리한다

<br/>

## 이 노트를 읽는 법
- 장으로 나눠 순서대로 정리했다. 앞 장의 내용을 알고 있다고 보고 다음 장을 쓰므로 1장부터 차례로 읽는다
- 각 장 끝에 목차, 이전 장, 다음 장으로 가는 링크가 있다
- 확인하지 못한 내용은 본문에 확인 필요로 적었고, 원문을 읽지 못한 자료는 참고 자료에 그렇게 밝혔다

<br/>

## 목차
1. [재미란 무엇인가](./01.재미란%20무엇인가(What%20Is%20Fun)) : 사람의 재미 일반. 놀이 이론(하위징아와 카유아), 도파민과 예측 오차, 원함과 좋아함, 플로, 자기결정이론
2. [게임에서 재미란](./02.게임에서%20재미란(Fun%20in%20Games)) : 게임이 재미를 만드는 방법. MDA와 여덟 가지 재미, 코스터의 재미 이론, 목표, 피드백, 불확실성, 알맞은 어려움, 흥미로운 선택, 자기결정이론의 게임 적용
3. [게임관이란 무엇인가](./03.게임관이란%20무엇인가(What%20Is%20a%20Game%20Philosophy)) : 게임을 보는 생각의 틀. 게임의 정의(율), 게임관을 이루는 다섯 질문, 결정에 드러나는 게임관, 내 게임관을 쓸 때의 틀
4. [시스템과 콘텐츠란](./04.시스템과%20콘텐츠란(Systems%20and%20Content)) : 규칙이 맞물려 플레이를 만드는 시스템과 미리 만들어 담는 콘텐츠, 율의 창발과 진행, 겉 요소가 맡는 피드백, 시스템 중심과 콘텐츠 중심의 득실
