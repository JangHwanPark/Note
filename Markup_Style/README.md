## 마크업과 스타일이란 ?
- 마크업(Markup)은 HTML처럼 문서의 구조와 의미를 표시하는 일이고, 스타일(Style)은 CSS로 그 문서의 모양을 정하는 일이다
- 이 폴더는 CSS 정렬과 애니메이션, Canvas, 웹 접근성을 정리한다
