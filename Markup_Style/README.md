## 마크업과 스타일이란 ?
- 마크업(Markup)은 HTML처럼 문서의 구조와 의미를 표시하는 일이고, 스타일(Style)은 CSS로 그 문서의 모양을 정하는 일이다
- 이 폴더는 CSS 정렬과 애니메이션, Canvas, 웹 접근성을 정리한다

<br/>

## CSS
- [세로 가운데 정렬](./CSS/세로%20가운데%20정렬(Vertical%20Centering)/README.md) : flex, grid, position과 transform, vertical-align, line-height로 세로 가운데 정렬하는 방법과 각각 깨지는 경우
- [트랜지션과 애니메이션](./CSS/트랜지션과%20애니메이션(Transition%20and%20Animation)/README.md) : transition과 keyframes의 차이, transform 함수, animation-fill-mode, 타이밍 함수
- [Tailwind 그리드 정렬](./CSS/Tailwind%20그리드%20정렬(Tailwind%20Grid%20Alignment)/README.md) : items, justify-items, place-items와 self 계열로 칸 안 위치 정하기, row-span과 col-span

<br/>

## Canvas
- [Canvas와 GSAP](./Canvas/Canvas와%20GSAP(Canvas%20and%20GSAP)/README.md) : DOM으로 만들지 Canvas에 그릴지 고르는 기준, 파티클 예제, GSAP으로 Canvas 그림 움직이기
- [Canvas 애니메이션 유형](./Canvas/Canvas%20애니메이션%20유형(Canvas%20Animation%20Types)/README.md) : 파티클, 웨이브, 물리, 보이드 등 자주 쓰는 유형과 움직임을 만드는 계산
