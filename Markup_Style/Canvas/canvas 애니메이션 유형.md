## Canvas에서 많이 쓰이는 대표적인 애니메이션 유형
애니메이션 유형	설명	사용 사례
Particle Animation (파티클 애니메이션)	작은 점(입자)들이 움직이며 다양한 효과를 만듦	불꽃 효과, 폭발, 입자 충돌, 네온 효과
Wave Animation (웨이브 애니메이션)	물결처럼 부드럽게 움직이는 애니메이션	오디오 비주얼라이저, 배경 효과
Fireworks (불꽃놀이 애니메이션)	폭발하면서 다양한 색상의 입자가 퍼지는 애니메이션	새해 불꽃놀이, 축제 효과
Text Animation (텍스트 애니메이션)	글자가 움직이거나 변형되는 애니메이션	로딩 화면, 글자 타이핑 효과
Morphing Shapes (형태 변형 애니메이션)	도형이 변형되면서 부드럽게 변환됨	로고 애니메이션, UI 트랜지션
Perlin Noise Animation (펄린 노이즈 애니메이션)	유기적으로 변화하는 랜덤 패턴	자연스러운 움직임 (구름, 연기, 물결 등)
Fire / Smoke Simulation (불, 연기 시뮬레이션)	불꽃과 연기가 실제처럼 움직이도록 시뮬레이션	게임 내 이펙트, 배경 효과
Fluid Simulation (유체 시뮬레이션)	물이나 공기가 자연스럽게 흐르는 애니메이션	물결 효과, 바람, 가스 시뮬레이션
Boids (떼 지어 움직이는 애니메이션)	여러 개의 객체가 군집을 이루며 이동	새 떼, 물고기 떼, AI 시뮬레이션
Physics-based Animation (물리 기반 애니메이션)	중력, 탄성, 충돌, 마찰 등을 적용하여 자연스럽게 움직이도록 구현	공 튀기기, 로프 시뮬레이션, 충돌 감지
Noise & Glitch Effect (노이즈 & 글리치 효과)	화면이 왜곡되거나 흔들리는 효과	해킹 애니메이션, SF UI
Starfield Animation (별 이동 애니메이션)	별들이 우주 공간을 빠르게 지나가는 효과	우주 배경, 게임 배경
Rain / Snow Effect (비/눈 내리는 애니메이션)	비나 눈이 떨어지는 듯한 애니메이션	겨울 배경, 날씨 애니메이션
Clock Animation (시계 애니메이션)	실제 시계처럼 초침, 분침, 시침이 움직이는 애니메이션	UI 컴포넌트, 대시보드
3D-like Depth Effect (3D 원근감 애니메이션)	캔버스를 활용하여 3D처럼 보이는 효과 구현	배경 레이어 효과, 인터랙티브 디자인
