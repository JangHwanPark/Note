## 컴포넌트 구조 패턴
### 컴포넌트 합성(Component Composition)
여러 작은 컴포넌트를 조합해 복잡한 UI 구성

### 컨테이너/프레젠테이션 패턴(Container/Presentational Pattern)
로직과 UI를 분리

### 렌더 프롭 패턴(Render Props)
컴포넌트 간 코드 재사용을 위한 패턴

### 고차 컴포넌트(HOC, Higher-Order Components)
컴포넌트를 인자로 받아 새 컴포넌트 반환

### 훅 기반 컴포넌트(Hook-based Components)
함수형 컴포넌트와 훅을 사용한 로직 구성


## 상태 관리 패턴
### 리덕스 패턴(Redux Pattern)
중앙 집중식 상태 관리

### 컨텍스트 API(Context API)
전역 상태를 하위 컴포넌트에 전달

### Zustand/Jotai/Recoil
경량 상태 관리 라이브러리 패턴

### 커스텀 훅(Custom Hooks)
상태 로직을 재사용 가능한 훅으로 분리

### 상태 머신(State Machines)
XState 같은 라이브러리로 복잡한 상태 흐름 관리


## 성능 최적화 패턴
### 메모이제이션(Memoization)
React.memo, useMemo, useCallback으로 불필요한 리렌더링 방지

### 가상화(Virtualization)
대량의 데이터를 효율적으로 렌더링(react-window, react-virtualized)

### 코드 스플리팅(Code Splitting)
React.lazy와 Suspense로 필요할 때만 코드 로드

### 번들 최적화(Bundle Optimization)
번들 크기 최소화로 초기 로딩 속도 개선

### 이미지 최적화(Image Optimization)
지연 로딩과 최적화된 이미지 포맷 사용


## 데이터 페칭 패턴
### 리액트 쿼리(React Query)
서버 상태 관리 및 캐싱

### SWR(Stale-While-Revalidate)
캐시 데이터 표시 후 재검증

### Suspense 기반 데이터 로딩
비동기 데이터 로딩을 위한 Suspense 활용

### Axios 인스턴스(Axios Instances)
중앙화된 API 클라이언트 설정

### 그래프큐엘(GraphQL)/아폴로(Apollo)
데이터 요청 최적화


## UI/UX 패턴
### 모달/다이얼로그(Modal/Dialog)
오버레이를 통한 임시 컨텐츠 표시

### 포털(Portals)
DOM 계층 구조 외부에 요소 렌더링

### 토스트/스낵바(Toast/Snackbar)
간단한 알림 표시

### 스켈레톤 로딩(Skeleton Loading)
데이터 로딩 중 UI 윤곽 표시

### 무한 스크롤/페이지네이션(Infinite Scroll/Pagination)
대량 데이터 효율적 로딩

### 다크 모드 전환(Dark Mode Toggle)
테마 전환 기능


## 폼 관리 패턴
### 제어 컴포넌트(Controlled Components)
React 상태로 폼 요소 제어

### 비제어 컴포넌트(Uncontrolled Components)
DOM 자체 상태 활용

### Formik/React Hook Form폼
상태 및 유효성 검사 관리

### Yup/Zod스키마
기반 폼 유효성 검사


## 라우팅 패턴
### 중첩 라우팅(Nested Routing)
계층적 라우트 구조

### 레이아웃 라우팅(Layout Routing)
공통 레이아웃을 공유하는 라우트

### 보호된 라우트(Protected Routes)
인증 기반 접근 제어

### 동적 라우팅(Dynamic Routing)
URL 파라미터 기반 동적 콘텐츠


## 코드 구조화 패턴
### 기능별 구조화(Feature-based Structure)
기능별로 코드 구성

### 아토믹 디자인(Atomic Design)
원자, 분자, 유기체 등 단계별 컴포넌트 구성

### 컴포넌트 스토리북(Component Storybook)
독립적인 컴포넌트 개발 및 문서화

### 모노레포(Monorepo)
여러 패키지를 하나의 저장소로 관리
