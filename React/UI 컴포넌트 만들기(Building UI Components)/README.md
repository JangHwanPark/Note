## 이 묶음에서 만드는 것
- 스텝퍼, 캐러셀, 페이지네이션, 프로그래스 바처럼 화면에서 자주 쓰는 부품을 React로 직접 만들어 보는 노트 모음
- 부품마다 무엇을 상태로 두는지, 상태가 바뀌면 화면의 어디가 바뀌는지를 중심으로 정리한다
- 스텝퍼와 프로그래스 바 예시의 `className` 은 Tailwind CSS 클래스다. 스타일은 바꿔도 상태를 다루는 방식은 같다

### UI (User Interface)
Interface의 사전적 의미는 두 영역이 맞닿는 면, 경계면이다.
공학적으로 UI는 사람과 프로그램이 맞닿는 부분, 즉 사용자가 보고 누르는 화면을 말한다. 여기서 만드는 컴포넌트는 그 화면을 이루는 부품이다.

부품을 직접 만들어 보면 라이브러리 컴포넌트를 쓸 때도 안에서 어떤 상태가 돌아가는지 짐작할 수 있다. 가구를 한 번 조립해 본 사람이 완제품 가구의 구조도 금방 알아보는 것과 같다.
