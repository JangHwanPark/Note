## 리액트란 ?
- 리액트(React)는 화면을 컴포넌트 단위로 만들고, 상태가 바뀌면 화면을 다시 그려 주는 UI 라이브러리다
- react의 사전적 의미는 반응하다로, 데이터가 바뀌는 데 반응해 화면이 바뀐다는 뜻이다
- 이 폴더는 프레임워크 없이 쓰는 React 자체의 개념을 정리한다. Next.js 고유의 내용은 [NextJS](../NextJS) 폴더에 둔다

<br/>
