로딩 상태 표시 예제

각 상자의 버튼을 눌러 기다리는 동안 화면이 어떻게 바뀌는지 봅니다. 기다리는 시간은 모두 흉내 낸 것입니다.

응답 속도

스피너, 스켈레톤, 버튼, 좋아요 예제에 적용됩니다. 표시는 0.5초가 지나도 끝나지 않을 때만 띄우고, 한 번 띄우면 0.2초 이상 유지합니다.

스피너

얼마나 남았는지 모를 때 일하는 중이라는 사실만 알립니다. 빠른 응답에서는 스피너가 나타나지 않습니다.

    진행 표시줄

    파일 개수를 세는 동안은 비확정형으로, 전체 양을 알게 되면 확정형으로 바꿉니다. 예제라서 걸리는 시간을 줄였습니다.

    스켈레톤 화면

    들어올 글 목록과 같은 모양의 뼈대를 먼저 그려 무엇이 어디에 나타날지 보여 줍니다.

    버튼 안의 로딩 상태

    누르는 즉시 저장 중으로 바뀝니다. 끝나기 전에 여러 번 누르거나 Enter를 눌러도 한 번만 저장됩니다.

    실제로 저장된 횟수: 0번

    낙관적 업데이트

    누르면 저장을 기다리지 않고 바로 반영합니다. 저장에 실패하면 원래대로 되돌리고 알립니다.

    저장 중

    준비된 것부터 보여 주기

    세 영역이 준비되는 대로 따로 채워집니다. 새로 고칠 때는 이전 내용을 지우지 않고 흐리게 남겨 둡니다.
