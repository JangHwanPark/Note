## 프론트엔드란 ?
- 프론트엔드(Frontend)는 사용자가 직접 보고 조작하는 화면 쪽을 만드는 일이다
- front의 사전적 의미는 앞, 정면으로, 사용자와 마주하는 앞쪽이라는 뜻이다. 그 뒤에서 데이터를 처리하는 서버 쪽을 백엔드(Backend)라고 부른다
- 이 폴더는 특정 라이브러리에 묶이지 않는 화면 설계 개념을 정리한다. React 구현은 React 폴더, 마크업과 스타일은 Markup_Style 폴더에 둔다

<br/>

## 목차
- [알림과 피드백](./알림과%20피드백(Notifications%20and%20Feedback)) : 토스트, 스낵바, 배너, 모달, 바텀 시트, 인라인 오류, 툴팁, 코치마크, 배지의 쓰임과 고르는 기준, 접근성
- [로딩 상태 표시](./로딩%20상태%20표시(Loading%20Indicators)) : 응답 시간의 세 한계, 스피너, 진행 표시줄, 스켈레톤 화면, 버튼 로딩 상태, 낙관적 업데이트, 준비된 것부터 보여 주기, 움직임과 접근성
- [빈 상태](./빈%20상태(Empty%20State)) : 처음 사용, 다 비웠을 때, 검색 결과 없음, 오류와 권한 없음의 종류, 빈 상태를 이루는 요소와 문구, 로딩과 오류 상태와 구분하기, 접근성
- [오류 상태](./오류%20상태(Error%20State)) : 화면이 구분해야 할 실패의 종류, 오류를 보여 주는 범위, 담을 것, 다시 시도 설계, 오류 문구, 404와 500 페이지, 오류 경계, 접근성
