## 프론트엔드란 ?
- 프론트엔드(Frontend)는 사용자가 직접 보고 조작하는 화면 쪽을 만드는 일이다
- front의 사전적 의미는 앞, 정면으로, 사용자와 마주하는 앞쪽이라는 뜻이다. 그 뒤에서 데이터를 처리하는 서버 쪽을 백엔드(Backend)라고 부른다
- 이 폴더는 특정 라이브러리에 묶이지 않는 화면 설계 개념을 정리한다. React 구현은 React 폴더, 마크업과 스타일은 Markup_Style 폴더에 둔다

- [폼 설계](./폼%20설계(Form%20Design)) : 라벨과 플레이스홀더, 필수와 선택 표시, 힌트, 입력란 고르기와 자동 완성, 묶고 배치하기, 제출 전에 오류 막기, 검사 시점, 브라우저 기본 검증, 접근성
- [되돌리기와 확인 대화 상자](./되돌리기와%20확인%20대화%20상자(Undo%20and%20Confirmation%20Dialogs)) : 확인 대화 상자만으로 부족한 이유, 둘 중 고르는 기준, 되돌리기를 만드는 두 방식, 휴지통, 확인 대화 상자에 담을 것, `<dialog>` 로 만들기, 저장하지 않은 변경 사항 지키기, 접근성
- [화면 전환 시 제목과 포커스 옮기기](./화면%20전환%20시%20제목과%20포커스%20옮기기(Title%20and%20Focus%20on%20Route%20Change)) : 페이지를 새로 열 때 브라우저가 해 주던 일, 제목 바꾸기, 포커스를 옮길 곳, 화면 이름 알리기, 스크롤 위치, 늦게 도착한 화면 버리기, 프레임워크가 해 주는 것
