## any와 never의 차이점 요약
| 특성         | `any`                  | `never`                       |
|--------------|------------------------|-------------------------------|
| 의미         | 모든 타입을 허용       | 절대 발생하지 않는 타입       |
| 유연성       | 매우 유연 (타입 검사 비활성화) | 타입 안전성 강화 (정확한 검사) |
| 사용 목적    | 타입을 모르거나 유연함이 필요할 때 | 불가능한 코드나 반환이 없는 함수에 사용 |
| 할당 가능성  | 어떤 타입에도 할당 가능 | 어떤 타입에도 할당 불가능     |
| 예시 함수    | 값을 반환할 수 있음     | 절대 반환하지 않음 (throw, 무한 루프 등) |

- **any**는 타입 안전성을 포기하면서 어떤 값이든 허용합니다.
- **never**는 논리적으로 불가능한 코드 경로를 나타내며, 타입 검사를 엄격하게 합니다. 
- any는 가능한 피해야 하지만, never는 코드의 정확성과 타입 안정성을 높이는 데 도움이 됩니다.

<br/>

## any 타입
**any**는 모든 타입을 허용하는 유연한 타입입니다.
타입 검사를 비활성화하며, 타입 안전성을 보장하지 않습니다.
컴파일러는 any로 지정된 변수에 대해서는 어떤 값이든 허용하고, 타입 오류를 무시합니다.

### 특징
어떤 타입의 값이든 할당할 수 있습니다.
다른 타입에 any 값을 할당해도 타입 오류가 발생하지 않습니다.
```ts
let value: any;

value = 10;       // 숫자
value = "hello";  // 문자열
value = true;     // 불리언

let anotherValue: number = value; // 문제 없이 할당 가능
```

<br/>

## never 타입
**never**는 절대로 발생할 수 없는 값을 나타내는 타입입니다.
함수가 절대 반환하지 않는 경우나, 불가능한 코드 경로에서 사용됩니다.

### 특징
never 타입에는 어떤 값도 할당할 수 없습니다.
주로 함수가 오류를 발생시키거나 무한 루프에 빠지는 경우에 사용됩니다.

### 예제
함수가 절대 반환하지 않는 경우
```ts
function throwError(message: string): never {
  throw new Error(message); // 이 함수는 반환되지 않습니다.
}
```

### 타입 가드에서 사용
```ts
type A = string | number;

function checkType(value: A) {
  if (typeof value === "string") {
    console.log("문자열입니다.");
  } else if (typeof value === "number") {
    console.log("숫자입니다.");
  } else {
    // 이 지점은 절대 실행될 수 없습니다.
    const impossible: never = value;
  }
}
```
