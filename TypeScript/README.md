## 타입스크립트(TypeScript)란 ?
- 자바스크립트에 타입을 더한 프로그래밍 언어로, Microsoft가 만들었다
- 타입스크립트 컴파일러는 타입을 검사하고, 타입을 지운 자바스크립트를 만든다. 실제로 실행되는 것은 이 자바스크립트다
- 기본 설정에서는 타입 오류가 있어도 자바스크립트가 만들어진다. 타입 오류는 실행을 막는 것이 아니라 잘못된 값을 넘기는 실수를 실행 전에 미리 알려 주는 역할을 한다

### 타입 (Type)
사전적 의미는 유형, 종류다. 같은 성질을 가진 것들의 묶음을 말한다.
프로그래밍에서 타입은 값이 어떤 종류인지, 그래서 그 값으로 무엇을 할 수 있는지를 정한 것이다. 숫자에는 `toFixed` 를 쓸 수 있고 문자열에는 `toUpperCase` 를 쓸 수 있는 것처럼, 타입을 알면 쓸 수 있는 동작이 정해진다.

<br/>

## 이 노트를 읽는 법
- 주제마다 폴더를 하나씩 두었다. 순서 없이 필요한 주제부터 읽어도 된다
- 예시 코드는 TypeScript 5.6.3에서 `--strict` 옵션으로 검사하고, 출력을 적은 코드는 실행해 확인했다. 오류 메시지 문구는 버전에 따라 다를 수 있다
