## Testea 기록이란 ?
- Testea는 QA로 일한 경험을 살려 가볍게 쓸 수 있는 테스트 케이스 관리 도구를 만들고 싶어 시작한 사이드 프로젝트다. Next.js App Router와 Server Actions로 만들었다
- 이 폴더는 프로젝트를 시작한 이유와 기록 습관을 적은 개발일지, 보안 대응과 장애, 성능 개선, 배포 문제를 정리한 개발노트를 모아 둔다
- 각 글은 따로 읽어도 되고, 번호는 쓴 순서를 따른다

<br/>
