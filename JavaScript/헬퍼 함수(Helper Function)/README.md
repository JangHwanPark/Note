## 헬퍼 함수란 ?
- 큰 로직(메인 작업) 안에서 특정한 역할 하나만 떼어 내 도와주는 작은 함수
- 도우미 함수라고도 부른다. 함수 안에서 반복되거나 복잡한 판단을 따로 빼낼 때 자주 쓴다
- 언어 문법이 아니라 코드를 나누는 습관에 붙인 이름이다

### 헬퍼 (Helper)
사전적 의미는 돕는 사람, 조수다.
프로그래밍에서는 혼자 결과를 내는 함수가 아니라 다른 함수가 일을 잘 하도록 한 부분을 맡아 주는 함수를 말한다. 주인공은 메인 함수이고, 헬퍼 함수는 그 함수가 부르는 조수다.

주방장과 보조 요리사로 생각하면 된다. 주방장(메인 함수)은 요리 순서만 챙기고, 채소 손질(헬퍼 함수)은 보조에게 맡긴다. 손질 방법이 바뀌어도 주방장의 순서는 그대로다.

<br/>

## 왜 쓸까
한 함수에 판단과 흐름이 모두 들어 있으면, 조건이 늘어날수록 무엇을 하려는 함수인지 읽기 어려워진다. 판단 부분을 이름 붙은 함수로 빼면 아래 이점이 생긴다.

- 메인 함수에는 큰 흐름만 남아 읽기 쉬워진다
- 같은 판단이 필요한 다른 곳에서도 다시 부를 수 있다
- 떼어 낸 함수만 따로 실행해 보며 확인할 수 있다
- 판단 기준이 바뀌면 헬퍼 함수 하나만 고치면 된다

보통 한 가지 역할만 맡게 작게 만든다. 단일 책임 원칙(SRP, Single Responsibility Principle)과 비슷한 생각이다. 이름만 보고 무엇을 하는지 알 수 있게 짓는 것이 중요하다. `isOnjeon` 처럼 참과 거짓을 돌려주는 함수는 `is` 로 시작하면 의도가 잘 드러난다.

<br/>

## 예시
아래 예시는 a부터 b까지의 수 중에서 세 가지 조건을 모두 피한 수를 센다. 이 예시에서는 이런 수를 온전수라고 부르기로 한다. 이름은 예시를 위해 붙인 것이다.

### 메인 함수 안에 전부 몰아넣은 경우
조건이 많아질수록 반복문 안이 복잡해진다.

```js
function countOnjeon(a, b) {
  let cnt = 0;
  for (let i = a; i <= b; i++) {
    if (i % 2 === 0) continue;                // 조건 1: 짝수 제외
    if (i % 10 === 5) continue;               // 조건 2: 일의 자리가 5면 제외
    if (i % 3 === 0 && i % 9 !== 0) continue; // 조건 3: 3의 배수 중 9의 배수가 아니면 제외
    cnt++;
  }
  return cnt;
}
```

### 헬퍼 함수로 분리한 경우
메인 함수에는 `isOnjeon` 으로 걸러서 센다는 흐름만 남는다.

```js
// 헬퍼 함수: 숫자가 온전수인지 판별
function isOnjeon(n) {
  if (n % 2 === 0) return false;
  if (n % 10 === 5) return false;
  if (n % 3 === 0 && n % 9 !== 0) return false;
  return true;
}

// 메인 함수: 개수 세기
function countOnjeon(a, b) {
  let cnt = 0;
  for (let i = a; i <= b; i++) {
    if (isOnjeon(i)) cnt++;
  }
  return cnt;
}

console.log(countOnjeon(1, 30)); // 10
```

두 버전 모두 1부터 30까지에서 10을 돌려준다(1, 7, 9, 11, 13, 17, 19, 23, 27, 29). 결과는 같고 코드의 짜임만 달라졌다. `isOnjeon` 은 따로 불러 볼 수 있어서 `isOnjeon(15)` 가 `false`, `isOnjeon(9)` 가 `true` 인 것처럼 수 하나씩 바로 확인할 수 있다. Node.js v22.13.0에서 실행했다.
