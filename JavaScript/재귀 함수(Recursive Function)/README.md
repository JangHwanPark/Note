## 재귀 함수란 ?
- 함수 안에서 자기 자신을 다시 호출하는 함수
- 큰 문제를 같은 모양의 더 작은 문제로 나누고, 가장 작은 문제에서 멈춘다
- 멈추는 조건인 기저 조건(Base Case)이 반드시 있어야 한다. 없으면 호출이 끝없이 쌓여 스택 오버플로(Stack Overflow)가 난다. 함수 호출 정보를 쌓아 두는 공간인 콜스택이 정해진 크기를 넘쳐 프로그램이 오류로 멈추는 것을 말한다

### 재귀 (Recursion)
사전적 의미는 원래 자리로 되돌아감이다. 영어 recur도 되돌아오다, 다시 일어나다라는 뜻이다.
프로그래밍에서는 함수가 실행 도중 자기 자신으로 되돌아가 다시 실행되는 것을 말한다. 되돌아갈 때마다 문제를 조금씩 줄여서, 언젠가 바로 답할 수 있는 크기에 닿게 만든다.

러시아 인형 마트료시카를 여는 것과 같다. 인형을 열면 더 작은 인형이 나오고, 같은 동작을 반복하다가 더 열리지 않는 가장 작은 인형(기저 조건)에서 멈춘다.

<br/>

## 어떻게 동작할까
1부터 n까지 더하는 함수로 보면 아래와 같다.

```js
function sumTo(n) {
  if (n === 0) return 0;   // 기저 조건: 더 줄일 수 없으면 바로 답한다
  return n + sumTo(n - 1); // 한 단계 작은 문제를 자기 자신에게 맡긴다
}

console.log(sumTo(5)); // 15
```

`sumTo(5)` 는 `5 + sumTo(4)` 를 계산하려고 `sumTo(4)` 를 부르고, 이렇게 `sumTo(0)` 까지 내려간다. 호출할 때마다 콜스택에 실행 정보가 하나씩 쌓이고, `sumTo(0)` 이 0을 돌려주면 쌓인 순서의 반대로 하나씩 계산이 끝나며 15가 된다. 콜스택은 [콜스택과 실행 순서](../콜스택과%20실행%20순서(Call%20Stack)) 노트에서 다룬다.

### 기저 조건이 없으면
```js
function noBase(n) {
  return noBase(n + 1);
}

noBase(0); // RangeError: Maximum call stack size exceeded
```

콜스택에 쌓을 수 있는 양에는 한계가 있다. 끝나지 않는 재귀는 이 한계를 넘어 `RangeError` 를 낸다. 메시지는 Node.js v22.13.0에서 실행한 결과다.

<br/>

## 재귀 호출 인자에 증감 연산자 쓰지 않기
재귀 호출 인자에 증감 연산자를 직접 쓰면 의도와 다르게 동작해 무한 재귀가 나기 쉽다.

### 왜 문제가 될까
```js
function rec(a) {
  if (a === 0) return;
  console.log(a);
  rec(a--); // 위험
}
```

후위 연산자 `a--` 는 지금 값 `a` 를 먼저 넘기고 그다음에 `a` 를 줄인다. 그래서 다음 호출은 매번 같은 값을 받고 기저 조건에 닿지 못한다. `rec(3)` 은 3을 계속 출력하다가 스택 오버플로로 끝난다. 호출 횟수를 세는 변수를 넣어 여섯 번째 호출에서 멈추게 하고 그때의 `a` 를 출력해 보니 여전히 3이었다. 멈추는 장치 없이 실행하면 1,000번 넘게 호출된 뒤 `RangeError: Maximum call stack size exceeded` 로 끝났다(Node.js v22.13.0).

### 안전한 방법
인자로 넘길 때는 계산한 새 값을 그대로 쓴다.

```js
rec(a - 1);
```

전위 연산자 `--a` 는 줄인 값을 넘기므로 동작은 한다. 하지만 지금 함수의 `a` 까지 바꿔 버려서, 호출 뒤에 `a` 를 다시 쓰는 코드가 있으면 헷갈린다. 읽기에도 `a - 1` 이 더 분명하다.

```js
rec(--a); // 동작은 하지만 a 자체가 바뀐다
```
