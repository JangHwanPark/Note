## 재귀함수 (Recursive Fn)
함수 내부에서 자기 자신을 호출하는 함수로 어떤 문제를 더 작고 간단한 하위 문제로 분할하여 자신을 호출한다.
재귀함수는 반드시 기저조건(Base Case)를 가지고 있어야하며 이는 재귀함수를 멈추는 조건이다.

만약 기저조건이 없다면 함수는 자기자신을 무한히 호출하며 스택 오버플로우가 발생한다.

<br/>

## 증감 연산자 주의
재귀호출 인자에 증감연산자를 직접쓰면 의도랑 다르게 동작해서 무한루프가 잘터짐

### 재귀에서 문제 되는 이유
```js
function rec(a) {
  if (a === 0) return;
  console.log(a);
  rec(a--);   // 위험
}
```
a--는 현재 값 a를 인자로 전달하고, 그 후에야 a가 줄어듦

즉, 재귀에 들어갈 때는 여전히 같은 a 값 → 무한 재귀 발생

### 안전한 방법
인자로 넘길 때는 계산된 새 값을 명시
```js
rec(a - 1);   // 깔끔
```

혹은 전위 연산자 써도 되지만 가독성이 안 좋아서 추천 안 함
```js
rec(--a);     // 동작은 하지만 a가 바뀌면서 들어감
```
