## 자바스크립트와 비동기
자바스크립트는 한번에 하나의 일만 처리할수 있는 싱글 쓰레드다.

자바스크립트는 기본적으로 동기적(순차적)으로 실행됨

이게 왜 문제가 되냐면 특정 함수에서 작업이 오래 걸리게되면 그 함수 또는 로직으로 인해 어플리케이션이 전반적으로 느려지게 되기 떄문이다.

<br/>

## 콜스택
- 콜스택은 함수 실행순서를 기억한다.
- 스택 자료구조 (LIFO, 후입선출)로 동작한다.
- 마지막에 들어간 함수가 제일 먼저 실행을 끝내고 나온다.

```js
function a() {
  return 1;
}

function b() {
  return a() + 1;
}

function c() {
  return b() + 1;
}

const result = c();
console.log(result);
```
c 함수를 호출하면 다음과 같이 실행된다.

1. c 함수가 콜스택에 들어간다.

2. c 함수는 b함수에 1을 더한값을 리턴하므로 b함수를 실행한다. (b함수 콜스택에 삽입)

3. b 함수는 a함수에 1을 더한값을 리턴하므로 a함수를 실행한다. (a함수 콜스택에 삽입)

4. a 함수는 1을 리턴한다. (a함수 콜스택에서 나온다.)

5. b 함수는 a 함수에서 리턴받은 1을 1과 더하여 2를 리턴한다. (b함수도 콜스택에서 나온다)

6. c 함수는 b 함수에서 리턴받은 2를 1과 더해 3을 리턴한다. (c함수도 콜스택에서 나온다.)

### 런타임에러와 콜스택
함수 호출이 너무 깊어지면(재귀에서 탈출 조건 없음) → Maximum call stack size exceeded 에러가 난다. (스택 오버플로우)

즉, 콜스택 크기는 무한하지 않음.
