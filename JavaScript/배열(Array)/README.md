## 배열이란 ?
- 여러 값을 순서대로 담는 자료형. 0부터 시작하는 번호(인덱스)로 값을 꺼낸다
- 자바스크립트 배열은 `map`, `filter`, `reduce`, `sort` 같은 메서드로 값을 바꾸고 모으고 정렬할 수 있다
- 이 노트는 그중 값을 하나로 모으는 `reduce` 와 순서를 바꾸는 `sort` 를 다룬다. 예시 데이터는 같은 폴더의 [method01.js](./method01.js)에 있다

### 배열 (Array)
사전적 의미는 정렬, 배치, 죽 늘어놓은 것이다.
프로그래밍에서는 값을 한 줄로 늘어놓고 자리마다 번호를 붙인 자료형을 말한다. 늘어놓은 순서가 있기 때문에 몇 번째 값인지로 꺼낼 수 있다.

<br/>

## reduce: 여러 값을 하나로 모으기
### 리듀스 (Reduce)
사전적 의미는 줄이다, 축소하다이다.
배열 메서드 `reduce` 는 배열의 값 여러 개를 하나의 결과로 줄인다. 합계, 개수 세기, 객체로 묶기처럼 결과가 하나인 계산에 쓴다.

장바구니 계산대와 같다. 물건을 하나씩 찍을 때마다 합계(누적값)가 바뀌고, 마지막 물건을 찍고 나면 합계 하나만 남는다.

### 어떻게 동작할까
```js
const numbers = [1, 2, 3, 4, 5];

numbers.reduce((acc, number) => acc + number, 0); // 15
```

- 두 번째 인자 `0` 이 누적값(`acc`)의 처음 값이다
- 콜백은 값마다 한 번씩 불리고, 돌려준 값이 다음 호출의 `acc` 가 된다
- 0 + 1, 1 + 2, 3 + 3, 6 + 4, 10 + 5 순서로 계산해 15가 남는다

처음 값은 되도록 적는다. 빈 배열에 처음 값 없이 쓰면 오류가 난다.

```js
[].reduce((acc, n) => acc + n, 0); // 0
[].reduce((acc, n) => acc + n);    // TypeError: Reduce of empty array with no initial value
```

### 객체 배열에서 쓰기
`method01.js` 의 `users` 처럼 객체가 담긴 배열에서도 같은 방식으로 모은다.

```js
users.reduce((sum, user) => sum + user.age, 0); // 140

users.reduce((acc, user) => {
  acc[user.role] = (acc[user.role] ?? 0) + 1;
  return acc;
}, {}); // { admin: 1, user: 3, moderator: 1 }
```

두 번째 예시는 처음 값을 빈 객체로 두고, 역할(role)마다 사람 수를 센다. 콜백이 `acc` 를 꼭 돌려줘야 다음 값으로 이어진다.

## sort: 순서 바꾸기
### 정렬 (Sort)
sort의 사전적 의미는 종류별로 나누다, 분류하다이다. 물건을 기준에 따라 골라 늘어놓는 일이다.
배열 메서드 `sort` 도 정해 둔 비교 기준에 따라 값을 골라 순서대로 다시 늘어놓는다.

### 기본 정렬은 문자열 순서다
비교 함수를 넘기지 않으면 값을 문자열로 바꾼 뒤 UTF-16 코드 단위 순서로 비교한다. 사전 순서와 비슷해 보이지만 글자의 코드 값 순서라서, 숫자 배열이 기대와 다르게 정렬되고 대문자가 소문자보다 먼저 온다. `undefined` 는 비교하지 않고 맨 뒤로 보낸다.

```js
[10, 9, 1].sort(); // [1, 10, 9]
```

`'10'` 과 `'9'` 를 문자열로 비교하면 첫 글자 `'1'` 이 `'9'` 보다 앞이라 10이 9보다 앞에 온다.

```js
['B', 'a', 'A', undefined, 'b'].sort(); // ['A', 'B', 'a', 'b', undefined]
```

### 비교 함수 넘기기
`sort(compareFn)` 의 비교 함수는 두 값 `a`, `b` 를 받아 숫자를 돌려준다. 음수면 `a` 를 앞에, 양수면 `b` 를 앞에 둔다. 0이면 둘의 원래 순서를 그대로 둔다. ES2019부터 `sort` 는 안정 정렬(Stable Sort)이어야 한다고 명세에 정해져서, 비교 결과가 같은 값끼리는 원래 순서가 지켜진다.

```js
[10, 9, 1].sort((a, b) => a - b); // [1, 9, 10] 오름차순
[10, 9, 1].sort((a, b) => b - a); // [10, 9, 1] 내림차순

[...users].sort((a, b) => a.age - b.age).map((u) => u.name);
// ['Charlie', 'Alice', 'Eve', 'Bob', 'David']
```

문자열은 빼기를 할 수 없으므로 `a.localeCompare(b)` 로 비교한다.

### 원본 배열이 바뀐다
`sort` 는 새 배열을 만들지 않고 원본의 순서를 바꾼 뒤 그 원본을 돌려준다. 원본을 지키려면 복사본을 정렬하거나 `toSorted` 를 쓴다.

```js
const original = [3, 1, 2];
const result = original.sort();
result === original; // true, original도 [1, 2, 3]이 됐다

const list = [3, 1, 2];
list.toSorted(); // [1, 2, 3]
list;            // [3, 1, 2] 그대로
```

`toSorted` 는 ES2023에 들어온 메서드다. 위 예시는 모두 Node.js v22.13.0에서 실행한 결과다.
