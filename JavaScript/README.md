## 자바스크립트란 ?
- 자바스크립트(JavaScript)는 웹 브라우저에서 화면을 움직이게 하려고 만들어진 프로그래밍 언어다
- 지금은 Node.js 같은 실행 환경 덕분에 서버와 도구 개발에도 쓰인다
- 이 폴더는 스코프, 클로저, 비동기 같은 코어 개념과 내장 객체, 자료구조를 정리한다
