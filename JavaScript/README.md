## 자바스크립트란 ?
- 자바스크립트(JavaScript)는 웹 페이지를 움직이게 하려고 만들어진 프로그래밍 언어다. 1995년 넷스케이프의 브렌던 아이크(Brendan Eich)가 만들었다
- HTML이 페이지의 구조, CSS가 모양을 맡는다면, 자바스크립트는 버튼을 누르거나 데이터를 받아 왔을 때 화면이 바뀌는 동작을 맡는다
- 언어의 표준 이름은 ECMAScript이고, ES2015(ES6)처럼 연도나 판 번호로 버전을 부른다
- 처음에는 브라우저 안에서만 돌았지만, 지금은 Node.js 같은 실행 환경 덕분에 서버와 개발 도구에도 쓰인다
- 이 폴더는 스코프, 클로저, 비동기 같은 코어 개념과 내장 객체, 자료구조를 정리한다

### 이름에 Java가 들어간 이유
자바스크립트와 Java는 이름만 닮은 다른 언어다. 처음 이름은 Mocha, LiveScript였는데, 당시 인기가 많던 Java의 이름을 빌려 JavaScript로 바꿨다고 알려져 있다.

### 실행 환경 (Runtime)
runtime은 실행되는(run) 동안(time)이라는 뜻이다. 공학적으로는 코드가 실행될 때 필요한 것을 갖춘 환경을 말한다.
같은 자바스크립트라도 어디서 실행되는지에 따라 쓸 수 있는 기능이 다르다. 브라우저에서는 `document` 로 화면을 고칠 수 있고, Node.js에서는 `fs` 로 파일을 읽을 수 있다. 언어 자체(변수, 함수, Promise 등)는 같고, 실행 환경이 덧붙여 주는 기능만 다르다.

### 싱글 스레드와 비동기
자바스크립트는 한 번에 한 가지 일만 처리하는 싱글 스레드(Single Thread) 방식으로 동작한다. 그래서 네트워크 요청처럼 오래 걸리는 일을 기다리는 동안 화면이 멈추지 않도록, 일을 맡겨 두고 결과가 오면 이어서 처리하는 비동기 방식을 많이 쓴다. 이 흐름은 아래 [콜스택과 실행 순서](./콜스택과%20실행%20순서(Call%20Stack))와 [프로미스](./프로미스(Promise))에서 다룬다.

## 코어 개념
- [스코프](./스코프(Scope)) : 이름이 보이는 범위(전역, 함수, 블록), 섀도잉과 호이스팅, TDZ
- [클로저](./클로저(Closure)) : 렉시컬 환경과 클로저가 바깥 변수를 기억하는 방식, 데이터 은닉과 반복문에서의 차이
- [콜스택과 실행 순서](./콜스택과%20실행%20순서(Call%20Stack)) : 콜스택이 쌓이고 비는 순서, 이벤트 루프와 마이크로태스크로 정해지는 비동기 실행 순서
- [프로미스](./프로미스(Promise)) : 콜백 헬을 푸는 프로미스의 상태와 체이닝, all, allSettled, race, any로 여러 작업 다루기
- [이터레이션](./이터레이션(Iteration)) : 이터러블과 이터레이터, `Symbol.iterator` 와 `next()` 로 동작하는 방식, 직접 만든 이터러블과 제너레이터
- [클래스](./클래스(Class)) : ES2015 class 문법의 constructor, 메서드, static과 인스턴스의 관계

<br/>

## 함수
- [재귀 함수](./재귀%20함수(Recursive%20Function)) : 자기 자신을 호출하는 함수와 기저 조건, 재귀 인자에 증감 연산자를 쓰면 안 되는 이유
- [헬퍼 함수](./헬퍼%20함수(Helper%20Function)) : 판단 로직을 작은 함수로 떼어 내 메인 흐름을 읽기 쉽게 만들기

## 내장 객체와 값
- [배열](./배열(Array)) : reduce로 값을 하나로 모으기, sort의 기본 문자열 정렬과 비교 함수, 원본을 바꾸는 sort와 toSorted
- [객체](./객체(Object)) : 점 표기법과 대괄호 표기법, 계산된 속성 이름, 없는 키를 읽을 때와 옵셔널 체이닝
- [문자열](./문자열(String)) : substring과 slice로 문자열 자르기, 음수와 순서가 바뀐 인수를 다루는 차이
- [날짜로 진행률 계산하기](./날짜로%20진행률%20계산하기(Date%20Progress)) : 시작일과 종료일로 진행률(%)을 구하는 함수, 기간 0과 시간대 주의점, 진행률 막대 적용
- [부동 소수점](./부동%20소수점(Floating%20Point)) : `0.1 + 0.2` 가 0.3이 아닌 이유와 toFixed, Math.round, 오차 범위 비교, 정수 계산으로 다루는 법
- [콘솔 출력](./콘솔%20출력(console.log%20and%20process.stdout.write)) : console.log와 process.stdout.write의 차이, 출력이 많을 때 모아서 한 번에 쓰기
