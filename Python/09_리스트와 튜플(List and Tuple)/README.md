## 리스트와 튜플이란 ?
- 여러 값을 순서대로 묶어 하나의 값으로 다루는 자료형
- 리스트(list)는 만든 뒤에도 내용을 바꿀 수 있고, 튜플(tuple)은 바꿀 수 없다
- 둘 다 문자열처럼 인덱스와 슬라이싱을 쓸 수 있다

<br/>

## 왜 필요할까
학생 30명의 점수를 `score1`, `score2`, ... 처럼 변수 30개로 만들면 평균 하나 구하는 것도 30개를 일일이 더해야 한다. 하나의 이름 아래 값을 순서대로 묶어 두면 반복문으로 한 번에 다룰 수 있다.

<br/>

## 리스트 (List)
### 정의
사전적 의미는 목록, 명단. 장보기 목록처럼 항목을 차례로 적어 둔 것이다.
공학적으로는 순서가 있고 내용을 바꿀 수 있는 값의 묶음이다. 장바구니처럼 물건을 넣고 빼기 자유롭다. 대괄호 `[]` 로 만들고, 서로 다른 자료형을 섞어 담을 수도 있다.

```python
nums = [3, 1, 2]
mixed = [1, "a", True]
empty = []
```

### 꺼내기
4장의 문자열과 같은 방식으로 인덱스와 슬라이싱을 쓴다.

```python
nums = [10, 20, 30, 40]
nums[0]      # 10
nums[-1]     # 40
nums[1:3]    # [20, 30]
len(nums)    # 4
```

### 바꾸기
문자열과 달리 리스트는 원본을 직접 바꿀 수 있는 가변(mutable) 자료형이다.

```python
nums = [3, 1, 2]
nums[0] = 10       # 값 바꾸기 [10, 1, 2]
nums.append(4)     # 끝에 추가 [10, 1, 2, 4]
nums.insert(0, 9)  # 0번 자리에 추가 [9, 10, 1, 2, 4]
nums.remove(9)     # 값 9를 찾아 제거 [10, 1, 2, 4]
nums.pop()         # 마지막 값을 꺼내고 제거, 4를 돌려준다
del nums[0]        # 0번 자리 제거 [1, 2]
```

### 정렬
`sort()` 는 원본을 정렬하고 아무것도 돌려주지 않는다(`None`). 원본은 두고 정렬된 새 리스트가 필요하면 `sorted()` 를 쓴다.

```python
nums = [3, 1, 2]
sorted(nums)               # [1, 2, 3], nums는 그대로 [3, 1, 2]
nums.sort()                # nums가 [1, 2, 3]으로 바뀜
nums.sort(reverse=True)    # [3, 2, 1]
```

`nums = nums.sort()` 처럼 쓰면 `nums` 에 `None` 이 들어가니 주의한다.

### 자주 쓰는 함수
```python
nums = [3, 1, 2]
sum(nums)    # 6
max(nums)    # 3
min(nums)    # 1
nums.index(1)   # 1 (값 1이 있는 자리)
nums.count(3)   # 1 (값 3의 개수)
```

### 리스트 컴프리헨션 (List Comprehension)
comprehension은 포함, 내포라는 뜻이다. 수학에서 집합을 `{x² | x는 0 이상 5 미만}` 처럼 조건으로 적는 방식에서 왔다.
리스트를 만들면서 반복과 조건을 한 줄로 적는다. `for` 문으로 빈 리스트에 `append` 하는 코드를 짧게 쓴 것과 같다.

```python
# for 문으로 쓰면
squares = []
for x in range(5):
    squares.append(x ** 2)

# 리스트 컴프리헨션으로 쓰면
squares = [x ** 2 for x in range(5)]          # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
```

한 줄이 너무 길어지거나 조건이 복잡해지면 오히려 읽기 어려우므로 그때는 `for` 문으로 쓴다.

### 2차원 리스트
리스트 안에 리스트를 넣으면 표처럼 행과 열로 다룰 수 있다.

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
]
grid[1][2]   # 6 (1번 행의 2번 열)
```

## 튜플 (Tuple)
### 정의
수학에서 순서가 정해진 값의 묶음을 부르는 말이다. 2개면 pair, 3개면 triple, 5개면 quintuple처럼 개수에 따라 부르던 이름의 끝부분 -tuple에서 왔다.
공학적으로는 순서가 있지만 한 번 만들면 바꿀 수 없는 값의 묶음이다. 소괄호 `()` 로 만든다. 내용물을 확인할 수는 있지만 열어서 바꿀 수 없는 봉인된 상자와 같다.

```python
point = (3, 5)
point[0]       # 3
point[0] = 1   # TypeError
single = (1,)  # 값 하나짜리 튜플은 쉼표가 필요하다. (1)은 그냥 숫자 1
```

### 왜 바꿀 수 없는 묶음이 필요할까
좌표, 날짜, 설정값처럼 묶음 자체가 하나의 의미를 가지고 바뀌면 안 되는 값이 있다. 튜플로 만들면 코드 어딘가에서 실수로 바꾸는 일을 막을 수 있다. 또 바뀌지 않는 값이라 10장에서 볼 딕셔너리의 키나 집합의 원소로 쓸 수 있다. 리스트는 쓸 수 없다.

### 언패킹 (Unpacking)
묶인 값을 변수 여러 개로 한 번에 풀어 받는 것이다. 2장의 `a, b = 1, 2` 도 오른쪽이 튜플로 묶였다가 풀린 것이다. 리스트에도 쓸 수 있다.

```python
point = (3, 5)
x, y = point     # x는 3, y는 5

first, *rest = [1, 2, 3, 4]   # first는 1, rest는 [2, 3, 4]
```

## 리스트와 튜플 비교
| 항목 | 리스트 | 튜플 |
| --- | --- | --- |
| 기호 | `[]` | `()` |
| 순서 | 있음 | 있음 |
| 수정 | 가능 | 불가 |
| 딕셔너리 키로 사용 | 불가 | 가능 |
| 주 용도 | 늘어나고 줄어드는 목록 | 고정된 값의 묶음 |
