## 함수란 ?
- 특정 작업을 하는 코드 묶음에 이름을 붙인 것
- 값을 받아(입력) 정해진 작업을 하고 결과를 돌려준다(출력)
- 파이썬은 `def` 로 정의하고 `return` 으로 결과를 돌려준다

<br/>

## 함수 (Function)
사전적 의미는 기능, 작용. 수학에서는 입력 x를 넣으면 정해진 규칙에 따라 y가 하나 나오는 관계다.
공학적으로는 입력을 받아 정해진 작업을 하고 결과를 돌려주는 코드 묶음이다. 재료를 넣으면 정해진 과정을 거쳐 결과가 나오는 믹서기와 같다. 안에서 무슨 일이 일어나는지 몰라도 무엇을 넣으면 무엇이 나오는지만 알면 쓸 수 있다.

### 왜 필요할까
같은 계산을 여러 곳에서 하려고 코드를 복사해 두면, 고칠 일이 생겼을 때 복사한 곳을 전부 찾아 고쳐야 하고 하나라도 놓치면 버그가 된다. 함수로 만들어 두면 이름만 불러 다시 쓸 수 있고, 고칠 때는 한 곳만 고치면 된다. 긴 코드를 작업 단위로 나눠 이름을 붙이면 전체 흐름을 읽기도 쉬워진다.
지금까지 쓴 `print()`, `len()`, `input()` 도 파이썬이 미리 만들어 둔 함수(내장 함수)다.

<br/>

## 정의와 호출
`def` 는 define(정의하다)의 줄임말이다. `def 함수이름(매개변수):` 로 정의하고, 들여쓴 블록이 함수 본문이 된다. 정의만 해서는 실행되지 않고, `함수이름()` 으로 호출해야 실행된다.

```python
def add(a, b):
    return a + b

result = add(2, 3)   # 5
```

### 매개변수와 인자
함수를 정의할 때 받는 이름(`a`, `b`)을 매개변수(Parameter), 호출할 때 넘기는 실제 값(`2`, `3`)을 인자(Argument)라 한다. 매개변수는 빈칸이 있는 주문서의 칸 이름이고, 인자는 그 칸에 실제로 적어 넣는 내용이다.

### return
`return` 은 결과를 호출한 곳으로 돌려주고 함수를 즉시 끝낸다. `return` 뒤의 코드는 실행되지 않는다. `return` 이 없거나 값 없이 `return` 만 쓰면 `None` 을 돌려준다.

```python
def check(n):
    if n < 0:
        return "음수"
    return "0 이상"

def hello():
    print("hi")

x = hello()   # hi 출력, x는 None
```

`print()` 는 화면에 보여 줄 뿐 값을 돌려주지 않는다. 함수의 결과를 다른 계산에 쓰려면 `print` 가 아니라 `return` 해야 한다.

## 인자를 넘기는 여러 방법
### 기본값
매개변수에 기본값을 주면 호출할 때 생략할 수 있다. 기본값이 있는 매개변수는 없는 매개변수보다 뒤에 와야 한다.

```python
def greet(name, greeting="안녕"):
    return f"{greeting}, {name}"

greet("kim")              # '안녕, kim'
greet("kim", "반가워")    # '반가워, kim'
```

### 키워드 인자
호출할 때 매개변수 이름을 붙여 넘기면 순서와 상관없이 전달된다. 인자가 많을 때 무엇을 넘기는지 드러나서 읽기 쉽다.

```python
greet(greeting="hi", name="lee")   # 'hi, lee'
```

### 가변 인자 (*args, **kwargs)
인자 개수를 정하지 않고 받을 때 쓴다. `*args` 는 위치 인자를 튜플로, `**kwargs` 는 키워드 인자를 딕셔너리로 모아 받는다. `args`, `kwargs` 는 관례적인 이름이고 핵심은 `*`, `**` 기호다.

```python
def total(*args):
    return sum(args)

total(1, 2, 3)   # 6

def show(**kwargs):
    print(kwargs)

show(a=1, b=2)   # {'a': 1, 'b': 2}
```

## 여러 값 돌려주기
쉼표로 여러 값을 돌려주면 튜플로 묶여 나온다. 받는 쪽에서 9장의 언패킹으로 나눠 받는다.

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4])   # 1, 4
```

## 변수의 범위 (Scope)
scope는 시야, 범위라는 뜻이다. 변수를 볼 수 있는 영역을 말한다.

### 지역 변수와 전역 변수
함수 안에서 만든 변수는 함수 안에서만 쓸 수 있다(지역 변수). 함수 실행이 끝나면 사라진다. 함수 밖에서 만든 변수는 함수 안에서도 읽을 수 있다(전역 변수).
그런데 함수 안에서 바깥 변수와 같은 이름에 대입하면, 바깥 변수를 바꾸는 것이 아니라 같은 이름의 새 지역 변수가 생긴다.

```python
count = 0

def increase():
    count = 10   # 바깥 count가 아니라 새 지역 변수

increase()
print(count)     # 0
```

함수 안에서 전역 변수를 바꾸려면 `global` 선언이 필요하다. 하지만 함수가 바깥 상태를 바꾸면 어디서 값이 바뀌었는지 따라가기 어려워진다. 보통은 필요한 값을 인자로 받고 결과를 `return` 으로 돌려주는 방식을 쓴다.

```python
def increase(n):
    return n + 1

count = increase(count)   # 1
```

## 람다 (lambda)
이름 없이 한 줄로 쓰는 작은 함수다. 이름은 수학자 알론조 처치(Alonzo Church)의 람다 대수(Lambda Calculus)에서 왔다. 함수를 수학적으로 다루기 위해 그리스 문자 λ(람다)로 함수를 표기한 이론이다.
`lambda 매개변수: 식` 형태로 쓰고, 식의 결과가 자동으로 돌려진다. 정렬 기준처럼 잠깐 쓰고 말 함수를 다른 함수에 넘길 때 주로 쓴다.

```python
words = ["banana", "kiwi", "apple"]
words.sort(key=lambda w: len(w))   # 글자 수 기준 정렬 ['kiwi', 'apple', 'banana']

users = [("kim", 30), ("lee", 20)]
sorted(users, key=lambda u: u[1])  # 나이 기준 [('lee', 20), ('kim', 30)]
```

여러 줄이 필요하거나 여러 곳에서 다시 쓸 함수라면 `def` 로 이름을 붙여 정의한다.
