## 파이썬이란 ?
- 1991년 귀도 반 로섬(Guido van Rossum)이 발표한 범용 프로그래밍 언어
- 문법이 짧고 영어 문장에 가까워 읽기 쉽고, 코드 블록을 중괄호 대신 들여쓰기로 구분한다
- 코드를 한 줄씩 해석해 실행하는 인터프리터 방식이라 작성한 코드를 바로 실행해 볼 수 있다
- 배우기 쉬워 첫 언어로 많이 쓰이고, 데이터 분석, 자동화 스크립트, 웹 서버, 인공지능 등 쓰이는 곳이 넓다

코드를 실행하는 방법은 [1장 파이썬 시작하기](./01_파이썬%20시작하기(Getting%20Started))에서 다룬다.

<br/>

## 이 노트를 읽는 법
- 파이썬 문법을 책처럼 장으로 나눠 순서대로 정리했다. 변수와 자료형에서 시작해 클래스, 제너레이터, 데코레이터, 타입 힌트까지 다룬다
- 앞 장의 내용을 알고 있다고 보고 다음 장을 쓰므로 처음 읽을 때는 1장부터 차례로 읽는다
- 각 장 끝에 목차, 이전 장, 다음 장으로 가는 링크가 있다
- 예시 코드의 결과는 Python 3.13에서 실행한 값이다
