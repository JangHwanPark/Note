## 연산자란 ?
- 값을 계산하거나 비교하라고 지시하는 기호나 단어
- `+`, `==`, `and` 처럼 생겼고, 연산자로 계산되는 값을 피연산자(Operand)라 한다
- 연산자와 피연산자가 모인 `1 + 2` 같은 것을 식(Expression)이라 하고, 식은 계산되어 값 하나가 된다

<br/>

## 연산자 (Operator)
사전적 의미로 operate는 작동시키다, 조작하다. operator는 기계를 다루는 조작자, 교환원이다.
공학적으로는 피연산자에 어떤 연산을 할지 정하는 기호다. 계산기의 `+`, `=` 버튼처럼 값 자체가 아니라 값에 무엇을 할지를 나타낸다.

<br/>

## 산술 연산자
| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` `-` `*` | 더하기, 빼기, 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 (결과는 항상 float) | `6 / 2` | `3.0` |
| `//` | 몫 | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

`%` 는 짝수 홀수 판별(`n % 2 == 0`)이나 몇 개씩 묶을 때처럼 반복되는 주기를 다룰 때 자주 쓴다.
계산 순서는 수학과 같아서 `**`, 그다음 `*` `/` `//` `%`, 그다음 `+` `-` 순서다. 헷갈리면 괄호로 묶는다.

### 복합 대입 연산자
변수에 계산 결과를 다시 넣는 일이 많아서 줄여 쓰는 문법이 있다.

```python
a = 10
a += 1   # a = a + 1
a -= 2   # a = a - 2
a *= 3   # a = a * 3
```

파이썬에는 다른 언어의 `++`, `--` 연산자가 없다. `a += 1` 을 쓴다.

<br/>

## 비교 연산자
두 값을 비교하고 결과로 `True` 나 `False` 를 돌려준다. `==`, `!=`, `>`, `<`, `>=`, `<=` 가 있다.
`=` 는 대입, `==` 는 같은지 비교다. 헷갈리기 쉬운 부분이다.

파이썬은 비교를 이어 쓸 수 있어서 범위를 수학식처럼 한 번에 적을 수 있다.

```python
x = 5
0 < x < 10        # True (0 < x and x < 10 과 같다)
"a" < "b"         # True (문자열은 사전 순서로 비교)
```

<br/>

## 논리 연산자
여러 조건을 묶는다. 다른 언어의 `&&`, `||`, `!` 대신 영어 단어를 쓴다.

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `and` | 둘 다 참이면 참 | `True and False` | `False` |
| `or` | 하나라도 참이면 참 | `True or False` | `True` |
| `not` | 참과 거짓을 뒤집음 | `not True` | `False` |

```python
age = 25
age >= 20 and age < 30   # True
```

### 단락 평가 (Short-circuit Evaluation)
`and` 는 앞이 거짓이면 뒤를 볼 필요 없이 거짓이고, `or` 는 앞이 참이면 뒤를 볼 필요 없이 참이다. 그래서 파이썬은 결과가 정해지면 뒤쪽 식을 아예 계산하지 않는다. 회로에서 전기가 중간에 지름길로 빠져 끝까지 흐르지 않는 것에 빗대 short-circuit이라 부른다.

```python
nums = []
len(nums) > 0 and nums[0] > 10   # False. 앞이 거짓이라 nums[0]은 실행되지 않아 에러가 나지 않는다
```

<br/>

## 멤버십 연산자 (in)
값이 안에 들어 있는지 확인한다. 문자열, 리스트, 딕셔너리 등에 쓸 수 있다. 반대는 `not in` 이다.

```python
"py" in "python"     # True
3 in [1, 2, 3]       # True
4 not in [1, 2, 3]   # True
```
