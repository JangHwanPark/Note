## 조건문이란 ?
- 조건에 따라 실행할 코드를 고르는 문법
- 조건이 참이면 해당 블록을 실행하고, 거짓이면 건너뛴다
- 파이썬은 `if`, `elif`, `else` 를 쓴다

<br/>

## 조건문 (Conditional Statement)
사전적 의미로 condition은 조건, 전제. 무언가가 일어나기 위해 먼저 갖춰져야 하는 것이다.
공학적으로는 주어진 조건이 참인지 거짓인지에 따라 프로그램의 흐름을 나누는 문장이다. 갈림길에서 표지판을 보고 길을 고르는 것과 같다.

### 왜 필요할까
지금까지의 코드는 위에서 아래로 모든 줄을 실행했다. 하지만 비밀번호가 맞을 때만 로그인시키거나, 점수에 따라 다른 등급을 주려면 상황에 따라 실행할 코드가 달라져야 한다. 조건문이 이 분기를 만든다.

<br/>

## if
조건 뒤에 콜론(`:`)을 붙이고, 실행할 코드는 들여써서 블록으로 만든다. 조건이 거짓이면 블록 전체를 건너뛴다.

```python
age = 20
if age >= 20:
    print("성인")
    print("입장 가능")
print("끝")   # 들여쓰지 않았으므로 조건과 상관없이 실행
```

## else
조건이 거짓일 때 실행할 블록이다.

```python
if age >= 20:
    print("성인")
else:
    print("미성년")
```

## elif
else if의 줄임말이다. 조건을 여러 개 이어서 검사한다. 필요한 만큼 쓸 수 있다.

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(grade)  # B
```

<br/>

## 동작 순서
1. 위에서부터 조건을 하나씩 검사한다
2. 처음으로 참인 조건을 만나면 그 블록만 실행한다
3. 나머지 `elif`, `else` 는 검사하지 않고 건너뛴다
4. 모든 조건이 거짓이면 `else` 블록을 실행하고, `else` 가 없으면 아무것도 하지 않는다

그래서 위 예시에서 85점은 `score >= 80` 과 `score >= 70` 이 둘 다 참이지만 먼저 만난 `B` 만 실행된다. 범위를 나누는 조건은 좁은 쪽(큰 점수)부터 쓰는 것이 이 때문이다.

<br/>

## 중첩 조건문
조건문 안에 조건문을 넣을 수 있다. 다만 깊어질수록 읽기 어려워지므로 `and` 로 합칠 수 있으면 합친다.

```python
# 중첩
if age >= 20:
    if has_ticket:
        print("입장")

# and로 합친 형태
if age >= 20 and has_ticket:
    print("입장")
```

<br/>

## 조건부 표현식
값 하나를 조건에 따라 고를 때는 한 줄로 쓸 수 있다. 다른 언어의 삼항 연산자(`조건 ? A : B`)와 같은 역할이다. 파이썬은 `참일 때 값 if 조건 else 거짓일 때 값` 순서로 쓴다.

```python
result = "성인" if age >= 20 else "미성년"
```

<br/>

## pass
블록 안에 아무것도 쓰지 않으면 문법 오류가 난다. 나중에 채울 자리를 비워 둘 때 `pass` 를 쓴다. 아무 일도 하지 않는 문장이다.

```python
if age >= 20:
    pass   # TODO: 나중에 작성
```
