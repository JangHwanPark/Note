## 파이썬 기초란 ?
- 파이썬으로 프로그램을 쓰기 위해 먼저 알아야 하는 문법을 순서대로 정리한 노트
- 앞 장의 내용을 알고 있다고 보고 다음 장을 쓰므로 처음 읽을 때는 1장부터 차례로 읽는다
- 각 장 끝에 이전 장, 다음 장으로 가는 링크가 있다

<br/>

7. [조건문](./07_조건문(Conditional%20Statement)) : if, elif, else

13. [모듈과 패키지](./13_모듈과%20패키지(Module%20and%20Package)) : import, 표준 라이브러리, pip, 가상환경
