## 파이썬이란 ?
- 1991년 귀도 반 로섬(Guido van Rossum)이 발표한 범용 프로그래밍 언어
- 문법이 짧고 영어 문장에 가까워 읽기 쉽고, 코드 블록을 중괄호 대신 들여쓰기로 구분한다
- 코드를 한 줄씩 읽어 실행하는 인터프리터(Interpreter) 방식이라 작성한 코드를 바로 실행해 볼 수 있다

<br/>

## 실행해 보기
### 인터프리터 (Interpreter)
사전적 의미는 통역사. 말을 듣는 즉시 상대 언어로 옮겨 전달하는 사람이다.
공학적으로는 소스 코드를 미리 기계어로 바꿔 두지 않고, 실행하면서 한 줄씩 해석해 처리하는 프로그램을 말한다. 통역사가 문장마다 바로 옮겨 주듯 코드를 고치고 바로 결과를 볼 수 있다. 대신 미리 번역해 두는 컴파일(Compile) 언어보다 실행 속도는 느린 편이다.

터미널에서 `python` 을 입력하면 한 줄씩 입력하고 결과를 바로 보는 대화형 모드가 열린다. 파일로 저장한 코드는 `python 파일명.py` 로 실행한다.

```python
print("Hello, Python")
```

### 들여쓰기
파이썬은 들여쓰기 자체가 문법이다. 같은 깊이로 들여쓴 줄들이 하나의 블록이 된다. 보통 공백 4칸을 쓰고, 깊이가 어긋나면 `IndentationError` 가 난다.

```python
if True:
    print("블록 안")
    print("같은 블록")
print("블록 밖")
```

### 주석 (Comment)
`#` 뒤의 내용은 실행하지 않는다. 코드에 설명을 남길 때 쓴다.

```python
# 한 줄 주석
x = 1  # 줄 끝에도 쓸 수 있다
```

## 변수
### 변수 (Variable)
사전적 의미는 변할 수 있는 수. 수학에서 x, y처럼 여러 값이 들어갈 수 있는 자리다.
공학적으로는 값에 붙이는 이름이다. 값이 메모리 어딘가에 저장되고, 변수는 그 값을 가리키는 이름표 역할을 한다. 물건에 이름표를 붙여 두면 나중에 이름만 불러서 꺼낼 수 있는 것과 같다.

파이썬은 변수를 만들 때 자료형을 따로 적지 않는다. `=` 로 값을 대입하면 그때 변수가 생기고, 자료형은 들어간 값을 보고 정해진다. 이를 동적 타이핑(Dynamic Typing)이라 한다.

```python
name = "kim"
age = 20
age = "스무 살"  # 같은 변수에 다른 자료형도 넣을 수 있다
```

### 여러 변수에 한 번에 대입
```python
a, b = 1, 2
a, b = b, a  # 값 교환. a는 2, b는 1
x = y = 0    # 같은 값 대입
```

### 이름 짓는 규칙
- 영문자, 숫자, 밑줄(`_`)을 쓸 수 있고 숫자로 시작할 수 없다
- 대소문자를 구분한다 (`age` 와 `Age` 는 다른 변수)
- `if`, `for`, `class` 같은 예약어는 쓸 수 없다
- 관례적으로 단어 사이를 밑줄로 잇는 스네이크 케이스(snake_case)를 쓴다 (`user_name`)

## 자료형
### 자료형 (Data Type)
값의 종류를 말한다. 같은 `+` 라도 숫자끼리는 더하기, 문자열끼리는 이어 붙이기가 되는 것처럼, 자료형에 따라 할 수 있는 연산이 달라진다. `type()` 으로 확인할 수 있다.

```python
type(10)       # <class 'int'>
type(3.14)     # <class 'float'>
type("hi")     # <class 'str'>
type(True)     # <class 'bool'>
type(None)     # <class 'NoneType'>
```

### 숫자 (int, float)
정수는 `int`, 소수점이 있는 수는 `float` 다. 파이썬의 정수는 크기 제한 없이 아주 큰 수도 다룰 수 있다.
`float` 는 컴퓨터가 소수를 2진수로 근사해 저장하기 때문에 `0.1 + 0.2` 가 정확히 `0.3` 이 되지 않는다.

```python
0.1 + 0.2          # 0.30000000000000004
2 ** 100           # 1267650600228229401496703205376
```

### 문자열 (str)
작은따옴표나 큰따옴표로 감싼 글자들이다. 여러 줄은 따옴표 세 개로 감싼다.
문자열은 순서가 있어서 인덱스(Index)로 한 글자씩 꺼낼 수 있다. 인덱스는 0부터 시작하고, 음수는 뒤에서부터 센다.

```python
s = "python"
s[0]      # 'p'
s[-1]     # 'n'
s[1:4]    # 'yth' (1번부터 4번 앞까지 자르기, 슬라이싱)
len(s)    # 6
```

문자열 안에 변수를 넣을 때는 f-string을 쓴다. 따옴표 앞에 `f` 를 붙이고 중괄호 안에 변수나 식을 적는다.

```python
name = "kim"
age = 20
print(f"{name}은 {age}살, 내년에 {age + 1}살")
```

자주 쓰는 메서드는 아래와 같다. 문자열은 바꿀 수 없는(immutable) 자료형이라 메서드는 원본을 고치지 않고 새 문자열을 돌려준다.

```python
"  hi  ".strip()          # 'hi' (양끝 공백 제거)
"a,b,c".split(",")        # ['a', 'b', 'c']
"-".join(["a", "b"])      # 'a-b'
"hello".replace("l", "L") # 'heLLo'
"Hello".upper()           # 'HELLO'
```

### 불리언 (bool)
참 `True` 와 거짓 `False` 두 값만 있다. 조건문에서 주로 쓴다.
파이썬은 불리언이 아닌 값도 조건에 넣을 수 있는데, `0`, `""`, `[]`, `None` 처럼 비어 있는 값은 거짓으로, 나머지는 참으로 취급한다.

### None
값이 없음을 나타내는 특별한 값이다. 아직 값을 정하지 않은 변수나, 돌려줄 값이 없는 함수의 결과로 쓰인다.

### 형 변환
자료형을 다른 자료형으로 바꾼다. `input()` 으로 받은 값은 항상 문자열이라 숫자로 쓰려면 변환이 필요하다.

```python
int("10")      # 10
float("3.5")   # 3.5
str(10)        # '10'
int(3.9)       # 3 (반올림이 아니라 소수점 아래를 버린다)
```

## 연산자
### 산술 연산자
| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` `-` `*` | 더하기, 빼기, 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 (결과는 항상 float) | `7 / 2` | `3.5` |
| `//` | 몫 | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

`a = a + 1` 은 `a += 1` 처럼 줄여 쓸 수 있다. 파이썬에는 `++` 연산자가 없다.

### 비교 연산자
`==`, `!=`, `>`, `<`, `>=`, `<=` 가 있고 결과는 불리언이다. 파이썬은 비교를 이어 쓸 수 있어서 `0 < x < 10` 처럼 범위를 한 번에 적을 수 있다.

### 논리 연산자
기호 대신 영어 단어를 쓴다. `and` 는 둘 다 참일 때, `or` 는 하나라도 참일 때, `not` 은 참과 거짓을 뒤집는다.

```python
age = 25
age >= 20 and age < 30   # True
not True                 # False
```

### 멤버십 연산자 (in)
값이 안에 들어 있는지 확인한다. 문자열, 리스트, 딕셔너리 등에 쓸 수 있다.

```python
"py" in "python"     # True
3 in [1, 2, 3]       # True
```

## 입력과 출력
### print()
값을 화면에 출력한다. 여러 값을 쉼표로 넘기면 공백으로 이어 출력하고, 출력 뒤에는 줄바꿈이 붙는다. `sep` 과 `end` 로 구분자와 끝 문자를 바꿀 수 있다.

```python
print("a", "b")              # a b
print("a", "b", sep="-")     # a-b
print("a", end="")           # 줄바꿈 없이 출력
```

### input()
사용자가 키보드로 입력한 한 줄을 문자열로 돌려준다.

```python
name = input("이름: ")
age = int(input("나이: "))   # 숫자로 쓰려면 변환
```

## 조건문
### 조건문 (Conditional Statement)
조건에 따라 실행할 코드를 고른다. 갈림길에서 표지판을 보고 길을 고르는 것과 같다. 위에서부터 조건을 확인하다가 처음 참인 블록 하나만 실행하고 나머지는 건너뛴다.

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

print(grade)  # B
```

`elif` 는 else if의 줄임말이다. 필요한 만큼 쓸 수 있고 `elif` 와 `else` 는 생략할 수 있다.

### 조건부 표현식
값 하나를 조건에 따라 고를 때는 한 줄로 쓸 수 있다. 다른 언어의 삼항 연산자와 같은 역할이다.

```python
result = "성인" if age >= 20 else "미성년"
```

## 반복문
### 반복문 (Loop)
같은 코드를 여러 번 실행한다. 사전적 의미의 loop는 고리, 둥근 테두리다. 실행 흐름이 고리처럼 돌아 다시 처음으로 돌아오는 모양에서 이름이 왔다.

### for 문
리스트나 문자열처럼 여러 값이 모인 것에서 값을 하나씩 꺼내 반복한다. 출석부를 위에서부터 한 명씩 부르는 것과 같다.

```python
for fruit in ["사과", "배", "귤"]:
    print(fruit)
```

정해진 횟수만큼 반복할 때는 `range()` 를 쓴다. `range(시작, 끝, 간격)` 이고 끝 값은 포함하지 않는다.

```python
for i in range(5):         # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 10, 2):  # 1, 3, 5, 7, 9
    print(i)
```

순번과 값이 함께 필요하면 `enumerate()` 를 쓴다.

```python
for i, fruit in enumerate(["사과", "배"]):
    print(i, fruit)   # 0 사과, 1 배
```

### while 문
조건이 참인 동안 계속 반복한다. 반복 횟수를 미리 알 수 없을 때 쓴다. 조건이 끝까지 참이면 영원히 끝나지 않으므로(무한 루프) 블록 안에서 조건이 바뀌도록 써야 한다.

```python
n = 3
while n > 0:
    print(n)
    n -= 1
```

### break, continue
`break` 는 반복을 즉시 끝내고, `continue` 는 이번 차례만 건너뛰고 다음 반복으로 넘어간다.

```python
for i in range(10):
    if i == 5:
        break      # 5에서 반복 종료
    if i % 2 == 0:
        continue   # 짝수는 건너뜀
    print(i)       # 1, 3
```

## 자료구조
여러 값을 하나로 묶어 다루는 자료형이다. 파이썬에 기본으로 들어 있는 네 가지를 먼저 알면 된다.

| 자료형 | 기호 | 순서 | 수정 | 중복 | 비유 |
| --- | --- | --- | --- | --- | --- |
| 리스트 (list) | `[]` | 있음 | 가능 | 허용 | 장바구니 |
| 튜플 (tuple) | `()` | 있음 | 불가 | 허용 | 봉인된 상자 |
| 딕셔너리 (dict) | `{키: 값}` | 넣은 순서 유지 | 가능 | 키는 불가 | 사전 |
| 집합 (set) | `{}` | 없음 | 가능 | 불가 | 출석 명단 |

### 리스트 (list)
순서가 있고 내용을 바꿀 수 있는 값의 묶음이다. 물건을 넣고 빼기 자유로운 장바구니와 같다. 문자열과 마찬가지로 인덱스와 슬라이싱을 쓸 수 있다.

```python
nums = [3, 1, 2]
nums.append(4)     # 끝에 추가 [3, 1, 2, 4]
nums.insert(0, 9)  # 0번 자리에 추가 [9, 3, 1, 2, 4]
nums.remove(9)     # 값 9를 찾아 제거 [3, 1, 2, 4]
nums.pop()         # 마지막 값을 꺼내고 제거, 4를 돌려준다
nums.sort()        # 원본을 정렬 [1, 2, 3]
nums[0] = 10       # 값 바꾸기 [10, 2, 3]
```

리스트를 만들면서 반복과 조건을 한 줄로 적는 리스트 컴프리헨션(List Comprehension)도 자주 쓴다.

```python
squares = [x ** 2 for x in range(5)]          # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
```

### 튜플 (tuple)
리스트와 같이 순서가 있지만 한 번 만들면 바꿀 수 없다. 내용이 바뀌면 안 되는 값을 묶을 때 쓴다. 좌표, 함수에서 여러 값을 돌려줄 때가 대표적이다.

```python
point = (3, 5)
x, y = point     # 언패킹(Unpacking): 묶인 값을 변수 여러 개로 풀기
point[0] = 1     # TypeError
```

### 딕셔너리 (dict)
사전적 의미는 사전. 단어를 찾으면 뜻이 나오는 책이다.
공학적으로는 키(Key)와 값(Value)을 짝지어 저장하는 자료형이다. 사전에서 단어로 뜻을 찾듯 키로 값을 바로 찾는다. 키는 중복될 수 없고, 같은 키에 다시 넣으면 값이 덮어써진다.

```python
user = {"name": "kim", "age": 20}
user["name"]            # 'kim'
user["email"] = "a@b"   # 새 키 추가
user.get("phone")       # None (없는 키를 []로 꺼내면 KeyError, get은 None)

for key, value in user.items():
    print(key, value)
```

### 집합 (set)
수학의 집합과 같다. 중복을 허용하지 않고 순서가 없다. 출석 명단처럼 같은 이름은 한 번만 적힌다. 중복 제거와 교집합, 합집합 계산에 쓴다.

```python
s = set([1, 2, 2, 3])   # {1, 2, 3}
a = {1, 2, 3}
b = {2, 3, 4}
a & b    # {2, 3} 교집합
a | b    # {1, 2, 3, 4} 합집합
a - b    # {1} 차집합
```

빈 집합은 `set()` 으로 만든다. `{}` 는 빈 딕셔너리가 된다.

## 함수
### 함수 (Function)
사전적 의미는 기능, 작용. 수학에서는 입력 x를 넣으면 정해진 규칙에 따라 y가 나오는 관계다.
공학적으로는 특정 작업을 하는 코드 묶음에 이름을 붙인 것이다. 재료를 넣으면 정해진 과정을 거쳐 결과가 나오는 믹서기와 같다. 같은 코드를 여러 곳에 복사하는 대신 이름만 불러 다시 쓸 수 있고, 고칠 일이 생기면 한 곳만 고치면 된다.

`def` 로 정의하고, `return` 으로 결과를 돌려준다. `return` 이 없으면 `None` 을 돌려준다.

```python
def add(a, b):
    return a + b

result = add(2, 3)   # 5
```

함수를 정의할 때 받는 이름(`a`, `b`)을 매개변수(Parameter), 호출할 때 넘기는 실제 값(`2`, `3`)을 인자(Argument)라 한다.

### 기본값과 키워드 인자
매개변수에 기본값을 주면 호출할 때 생략할 수 있다. 호출할 때 이름을 붙여 넘기면(키워드 인자) 순서와 상관없이 전달된다.

```python
def greet(name, greeting="안녕"):
    return f"{greeting}, {name}"

greet("kim")                     # '안녕, kim'
greet("kim", greeting="반가워")  # '반가워, kim'
greet(greeting="hi", name="lee") # 'hi, lee'
```

### 여러 값 돌려주기
쉼표로 여러 값을 돌려주면 튜플로 묶여 나온다. 받는 쪽에서 언패킹으로 나눠 받는다.

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4])   # 1, 4
```

### 가변 인자 (*args, **kwargs)
인자 개수를 정하지 않고 받을 때 쓴다. `*args` 는 위치 인자를 튜플로, `**kwargs` 는 키워드 인자를 딕셔너리로 모아 받는다. `args`, `kwargs` 는 관례적인 이름이고 핵심은 `*`, `**` 기호다.

```python
def total(*args):
    return sum(args)

total(1, 2, 3)   # 6

def show(**kwargs):
    print(kwargs)

show(a=1, b=2)   # {'a': 1, 'b': 2}
```

### 변수의 범위 (Scope)
함수 안에서 만든 변수는 함수 안에서만 쓸 수 있다(지역 변수). 함수 밖에서 만든 변수는 함수 안에서 읽을 수 있지만(전역 변수), 함수 안에서 같은 이름에 대입하면 새 지역 변수가 생길 뿐 바깥 변수는 바뀌지 않는다.

```python
count = 0

def increase():
    count = 10   # 바깥 count가 아니라 새 지역 변수

increase()
print(count)     # 0
```

함수 안에서 전역 변수를 바꾸려면 `global` 선언이 필요하지만, 함수가 바깥 상태에 기대면 흐름을 따라가기 어려워진다. 보통은 값을 인자로 받고 결과를 `return` 으로 돌려주는 방식을 쓴다.

### 람다 (lambda)
이름 없이 한 줄로 쓰는 작은 함수다. 정렬 기준처럼 잠깐 쓰고 말 함수를 넘길 때 주로 쓴다. 이름은 수학자 알론조 처치(Alonzo Church)의 람다 대수(Lambda Calculus)에서 왔다.

```python
words = ["banana", "kiwi", "apple"]
words.sort(key=lambda w: len(w))   # 글자 수 기준 정렬 ['kiwi', 'apple', 'banana']
```
