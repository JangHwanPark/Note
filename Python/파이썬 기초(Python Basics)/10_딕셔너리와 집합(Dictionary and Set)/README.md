## 딕셔너리와 집합이란 ?
- 딕셔너리(dict)는 키(Key)와 값(Value)을 짝지어 저장하고, 키로 값을 찾는 자료형
- 집합(set)은 중복 없이 값을 모아 두는 자료형
- 둘 다 중괄호 `{}` 로 만들고, 인덱스 번호가 아니라 값 자체로 찾는다

<br/>

## 딕셔너리 (Dictionary)
### 정의
사전적 의미는 사전. 단어를 찾으면 뜻이 나오는 책이다.
공학적으로는 키와 값을 짝지어 저장하는 자료형이다. 사전에서 단어(키)로 뜻(값)을 찾듯, 키를 알면 값을 바로 꺼낼 수 있다.

```python
user = {"name": "kim", "age": 20}
```

### 왜 필요할까
사용자 정보를 리스트 `["kim", 20]` 로 저장하면 `user[0]` 이 이름이고 `user[1]` 이 나이라는 것을 따로 기억해야 한다. 딕셔너리로 저장하면 `user["name"]` 처럼 이름으로 꺼내므로 무엇을 꺼내는지가 코드에 드러난다.
또 리스트에서 값을 찾으려면 처음부터 하나씩 비교해야 하지만, 딕셔너리는 키로 바로 찾아가므로 데이터가 많아도 빠르다. 내부적으로 해시 테이블(Hash Table)을 쓰기 때문인데, 동작 원리는 별도 문서로 정리한다.

### 꺼내기
```python
user = {"name": "kim", "age": 20}
user["name"]          # 'kim'
user["phone"]         # KeyError (없는 키)
user.get("phone")     # None (없으면 에러 대신 None)
user.get("phone", "") # '' (없을 때 돌려줄 기본값 지정)
"name" in user        # True (in은 키를 검사한다)
```

### 추가, 수정, 삭제
키는 중복될 수 없다. 이미 있는 키에 값을 넣으면 덮어쓰고, 없는 키면 새로 추가된다.

```python
user = {"name": "kim", "age": 20}
user["email"] = "a@b.com"   # 추가
user["age"] = 21            # 수정
del user["email"]           # 삭제
user.pop("age")             # 꺼내고 삭제, 21을 돌려준다
```

### 반복
```python
user = {"name": "kim", "age": 20}

for key in user:                  # 키만
    print(key)

for value in user.values():       # 값만
    print(value)

for key, value in user.items():   # 키와 값 함께
    print(key, value)
```

### 키로 쓸 수 있는 값
키는 바뀌지 않는(immutable) 값이어야 한다. 문자열, 숫자, 튜플은 되고 리스트는 안 된다. 사전의 표제어가 바뀌면 찾을 수 없게 되는 것과 같다. 값에는 제한이 없어서 리스트나 다른 딕셔너리도 넣을 수 있다.

### 예시: 개수 세기
딕셔너리는 무언가의 개수를 셀 때 자주 쓴다.

```python
words = ["a", "b", "a", "c", "a"]
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
print(count)   # {'a': 3, 'b': 1, 'c': 1}
```

딕셔너리는 파이썬 3.7부터 넣은 순서를 유지한다.

## 집합 (Set)
### 정의
사전적 의미로 set는 한 벌, 세트. 수학의 집합과 같다.
공학적으로는 중복을 허용하지 않고 순서가 없는 값의 모음이다. 출석 명단처럼 같은 이름은 한 번만 적힌다. 순서가 없으므로 인덱스로 꺼낼 수 없다.

```python
s = {1, 2, 2, 3}        # {1, 2, 3}
s = set([1, 2, 2, 3])   # 리스트에서 만들기 {1, 2, 3}
empty = set()           # 빈 집합. {}는 빈 딕셔너리가 된다
```

### 왜 필요할까
중복을 지우거나, 어떤 값이 있는지만 빠르게 확인할 때 쓴다. 리스트에서 `in` 은 처음부터 하나씩 비교하지만, 집합은 딕셔너리처럼 바로 찾아가므로 값이 많을수록 차이가 커진다.

```python
names = ["kim", "lee", "kim"]
unique = list(set(names))   # 중복 제거, 순서는 보장되지 않는다
```

### 추가와 삭제
```python
s = {1, 2}
s.add(3)       # {1, 2, 3}
s.remove(1)    # {2, 3}, 없는 값이면 KeyError
s.discard(9)   # 없는 값이어도 에러 없음
```

### 집합 연산
수학의 교집합, 합집합, 차집합을 연산자로 계산한다. 두 그룹의 공통 회원이나 한쪽에만 있는 회원을 찾을 때 쓴다.

```python
a = {1, 2, 3}
b = {2, 3, 4}
a & b    # {2, 3} 교집합
a | b    # {1, 2, 3, 4} 합집합
a - b    # {1} 차집합
a ^ b    # {1, 4} 대칭차집합 (한쪽에만 있는 값)
```

## 네 가지 묶음 자료형 비교
| 자료형 | 기호 | 순서 | 수정 | 중복 | 비유 |
| --- | --- | --- | --- | --- | --- |
| 리스트 (list) | `[]` | 있음 | 가능 | 허용 | 장바구니 |
| 튜플 (tuple) | `()` | 있음 | 불가 | 허용 | 봉인된 상자 |
| 딕셔너리 (dict) | `{키: 값}` | 넣은 순서 유지 | 가능 | 키는 불가 | 사전 |
| 집합 (set) | `{}` | 없음 | 가능 | 불가 | 출석 명단 |
