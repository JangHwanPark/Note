## 파이썬이란 ?
- 1991년 귀도 반 로섬(Guido van Rossum)이 발표한 범용 프로그래밍 언어
- 문법이 짧고 영어 문장에 가까워 읽기 쉽고, 코드 블록을 중괄호 대신 들여쓰기로 구분한다
- 코드를 한 줄씩 읽어 실행하는 인터프리터(Interpreter) 방식이라 작성한 코드를 바로 실행해 볼 수 있다

<br/>

## 인터프리터
### 인터프리터 (Interpreter)
사전적 의미는 통역사. 말을 듣는 즉시 상대 언어로 옮겨 전달하는 사람이다.
공학적으로는 소스 코드를 미리 기계어로 바꿔 두지 않고, 실행하면서 한 줄씩 해석해 처리하는 프로그램을 말한다. 통역사가 문장마다 바로 옮겨 주듯 코드를 고치고 바로 결과를 볼 수 있다.

### 컴파일 언어와 무엇이 다를까
컴파일(Compile)은 책 한 권을 통째로 번역해 번역본을 만들어 두는 방식이다. 번역에 시간이 들지만 한 번 만들어 두면 빠르게 읽을 수 있다. 인터프리터는 통역처럼 그때그때 옮기므로 바로 시작할 수 있는 대신 실행 속도는 컴파일 언어보다 느린 편이다.
파이썬은 이 빠른 시작과 고치고 바로 확인하는 흐름 덕분에 배우기 쉽고, 데이터 분석이나 자동화 스크립트처럼 빨리 써 보고 고치는 일에 많이 쓰인다.

## 실행해 보기
### 대화형 모드
터미널에서 `python` 을 입력하면 `>>>` 표시가 나오는 대화형 모드가 열린다. 한 줄을 입력하고 엔터를 누르면 바로 결과가 나온다. 짧은 코드를 시험해 볼 때 쓴다. `exit()` 로 빠져나온다.

```python
>>> 1 + 2
3
>>> print("Hello, Python")
Hello, Python
```

### 파일로 실행
코드를 `.py` 확장자 파일로 저장하고 `python 파일명.py` 로 실행한다. 파일 맨 위 줄부터 아래로 차례대로 실행된다.

```python
# hello.py
print("Hello, Python")
```

## 들여쓰기
다른 언어는 중괄호 `{}` 로 코드 블록을 묶지만, 파이썬은 들여쓰기 자체가 문법이다. 같은 깊이로 들여쓴 줄들이 하나의 블록이 된다. 책에서 문단을 들여 써서 구분하는 것과 비슷하다.
보통 공백 4칸을 쓰고, 깊이가 어긋나면 `IndentationError` 가 난다. 들여쓰기를 강제하기 때문에 누가 써도 코드 모양이 비슷해지고 읽기 쉬워진다.

```python
if True:
    print("블록 안")
    print("같은 블록")
print("블록 밖")
```

## 주석
### 주석 (Comment)
사전적 의미는 낱말이나 문장의 뜻을 쉽게 풀이한 글. 책 여백에 적는 풀이와 같다.
공학적으로는 실행되지 않고 사람이 읽기 위해 남기는 설명이다. 파이썬은 `#` 뒤의 내용을 주석으로 본다.

```python
# 한 줄 주석
x = 1  # 줄 끝에도 쓸 수 있다
```
