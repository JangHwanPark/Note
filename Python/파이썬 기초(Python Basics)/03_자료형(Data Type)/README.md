## 자료형이란 ?
- 값의 종류
- 자료형에 따라 할 수 있는 연산이 달라진다. 같은 `+` 라도 숫자끼리는 더하기, 문자열끼리는 이어 붙이기가 된다
- `type()` 으로 어떤 자료형인지 확인할 수 있다

<br/>

## 자료형 (Data Type)
사전적 의미로 type은 유형, 종류다. 그릇에도 국그릇, 접시, 컵처럼 종류가 있고 담을 수 있는 것이 다르다.
공학적으로는 값이 어떤 종류인지, 그래서 어떤 연산을 할 수 있는지를 정하는 분류다. 컴퓨터 안에서는 모든 값이 0과 1로 저장되므로, 같은 0과 1을 숫자로 읽을지 글자로 읽을지 정하는 기준이 필요하다. 그 기준이 자료형이다.

```python
type(10)       # <class 'int'>
type(3.14)     # <class 'float'>
type("hi")     # <class 'str'>
type(True)     # <class 'bool'>
type(None)     # <class 'NoneType'>
```

여러 값을 묶는 자료형(리스트, 튜플, 딕셔너리, 집합)은 9장과 10장에서, 문자열은 4장에서 따로 다룬다.

<br/>

## 숫자
### 정수 (int)
integer의 줄임말. 소수점이 없는 수다. 파이썬의 정수는 크기 제한 없이 아주 큰 수도 다룰 수 있다.

```python
2 ** 100   # 1267650600228229401496703205376
```

### 실수 (float)
floating point(떠다니는 소수점)의 줄임말. 소수점이 있는 수다. 소수점 위치를 고정하지 않고 옮겨 가며 표현하는 방식이라 이런 이름이 붙었다.
컴퓨터는 소수를 2진수로 근사해 저장하기 때문에 계산 결과에 아주 작은 오차가 생길 수 있다. 10진수에서 1/3을 0.333...으로 끝없이 적을 수밖에 없는 것처럼, 0.1은 2진수로 정확히 나타낼 수 없다.

```python
0.1 + 0.2          # 0.30000000000000004
0.1 + 0.2 == 0.3   # False
```

그래서 실수끼리는 `==` 로 바로 비교하지 않고, 반올림하거나 차이가 아주 작은지로 비교한다.

<br/>

## 불리언 (bool)
영국 수학자 조지 불(George Boole)의 이름에서 왔다. 참과 거짓으로 논리를 계산하는 불 대수를 만든 사람이다.
파이썬에서는 참 `True` 와 거짓 `False` 두 값만 있다. 조건문에서 어느 쪽으로 갈지 정할 때 쓴다.

### 참 같은 값, 거짓 같은 값
파이썬은 불리언이 아닌 값도 조건에 넣을 수 있다. `0`, `""`(빈 문자열), `[]`(빈 리스트), `None` 처럼 비어 있는 값은 거짓으로, 나머지는 참으로 취급한다. `bool()` 로 확인할 수 있다.

```python
bool(0)      # False
bool("")     # False
bool("0")    # True (글자가 하나 들어 있으므로)
bool([1])    # True
```

<br/>

## None
값이 없음을 나타내는 특별한 값이다. 빈 상자와 상자 자체가 없는 것은 다른데, `None` 은 아직 아무것도 정해지지 않았다는 표시에 가깝다. 아직 값을 정하지 않은 변수나, 돌려줄 값이 없는 함수의 결과로 쓰인다.
`None` 인지 확인할 때는 `==` 대신 `is` 를 쓰는 것이 관례다.

```python
result = None
if result is None:
    print("아직 결과 없음")
```

<br/>

## 형 변환
자료형을 다른 자료형으로 바꾸는 것이다. 자료형마다 할 수 있는 연산이 다르므로, 다른 자료형끼리 계산하려면 한쪽을 맞춰 줘야 한다. `"10" + 5` 는 문자열과 숫자를 더하려 해서 `TypeError` 가 난다.

```python
int("10")      # 10
float("3.5")   # 3.5
str(10)        # '10'
int(3.9)       # 3 (반올림이 아니라 소수점 아래를 버린다)
int("abc")     # ValueError (숫자로 읽을 수 없는 문자열)
```

6장에서 볼 `input()` 은 입력을 항상 문자열로 돌려주므로 숫자로 쓰려면 이 변환이 필요하다.
