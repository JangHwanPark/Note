## 문자열이란 ?
- 글자들을 순서대로 이어 놓은 값
- 작은따옴표나 큰따옴표로 감싸 만든다
- 한 번 만들면 내용을 바꿀 수 없는 불변(immutable) 자료형이다

<br/>

## 문자열 (String)
사전적 의미로 string은 끈, 줄이다. 구슬을 끈에 꿰어 놓은 모양을 떠올리면 된다.
공학적으로는 글자(문자)를 순서대로 꿰어 놓은 값을 말한다. 구슬 하나하나가 글자이고, 꿰인 순서가 그대로 유지된다.

```python
a = 'hello'
b = "hello"           # 작은따옴표와 큰따옴표는 같다
c = "It's ok"         # 안에 작은따옴표가 있으면 큰따옴표로 감싼다
d = """여러 줄
문자열"""              # 따옴표 세 개는 줄바꿈을 그대로 담는다
```

<br/>

## 인덱스와 슬라이싱
### 인덱스 (Index)
사전적 의미는 색인. 책 뒤에서 단어가 몇 쪽에 있는지 찾아보는 목록이다.
공학적으로는 순서가 있는 값에서 각 자리의 번호를 말한다. 번호로 원하는 자리의 글자를 바로 꺼낼 수 있다. 번호는 0부터 시작하고, 음수는 뒤에서부터 센다.

```python
s = "python"
s[0]      # 'p'
s[5]      # 'n'
s[-1]     # 'n' (뒤에서 첫 번째)
s[6]      # IndexError (없는 자리)
len(s)    # 6
```

| 글자 | p | y | t | h | o | n |
| --- | --- | --- | --- | --- | --- | --- |
| 인덱스 | 0 | 1 | 2 | 3 | 4 | 5 |
| 음수 인덱스 | -6 | -5 | -4 | -3 | -2 | -1 |

### 슬라이싱 (Slicing)
slice는 얇게 썬 조각이다. `[시작:끝]` 으로 문자열의 일부를 잘라 낸다. 시작은 포함하고 끝은 포함하지 않는다. 시작이나 끝을 비우면 처음부터, 끝까지라는 뜻이다.

```python
s = "python"
s[1:4]    # 'yth' (1번부터 4번 앞까지)
s[:2]     # 'py'
s[2:]     # 'thon'
s[::-1]   # 'nohtyp' (세 번째 칸은 간격, -1이면 거꾸로)
```

끝을 포함하지 않는 이유는 `s[:2] + s[2:]` 처럼 같은 숫자로 나눠 붙이면 원래 문자열이 되고, `끝 - 시작` 이 잘라 낸 길이가 되어 계산이 편하기 때문이다.

## 불변 (Immutable)
문자열은 만든 뒤 일부를 바꿀 수 없다. 인쇄된 책의 글자를 고칠 수 없어서 고친 판을 새로 찍는 것과 같다.

```python
s = "python"
s[0] = "P"           # TypeError
s = "P" + s[1:]      # 새 문자열을 만들어 다시 대입한다
```

그래서 문자열 메서드는 원본을 고치지 않고 새 문자열을 돌려준다. 결과를 쓰려면 변수에 다시 받아야 한다.

<br/>

## 자주 쓰는 메서드
메서드(Method)는 값에 딸린 함수다. `값.메서드()` 형태로 부른다. 함수 자체는 11장에서 다룬다.

```python
"  hi  ".strip()          # 'hi' (양끝 공백 제거)
"a,b,c".split(",")        # ['a', 'b', 'c'] (나눠서 리스트로)
"-".join(["a", "b"])      # 'a-b' (리스트를 이어 붙이기)
"hello".replace("l", "L") # 'heLLo'
"Hello".upper()           # 'HELLO'
"Hello".lower()           # 'hello'
"hello".startswith("he")  # True
"hello".find("l")         # 2 (처음 나온 위치, 없으면 -1)
"hello".count("l")        # 2
```

## 문자열 연산과 f-string
### 더하기와 곱하기
`+` 는 이어 붙이고, `*` 는 반복한다.

```python
"py" + "thon"   # 'python'
"ab" * 3        # 'ababab'
```

### f-string
문자열 안에 변수 값을 넣을 때 쓴다. 따옴표 앞에 `f` 를 붙이고 중괄호 안에 변수나 식을 적는다. f는 format(서식)의 앞 글자다. `+` 로 이어 붙이면 숫자를 일일이 `str()` 로 바꿔야 하지만, f-string은 알아서 문자열로 바꿔 넣는다.

```python
name = "kim"
age = 20
print(f"{name}은 {age}살, 내년에 {age + 1}살")   # kim은 20살, 내년에 21살
print(f"{3.14159:.2f}")                          # 3.14 (소수점 둘째 자리까지)
```
