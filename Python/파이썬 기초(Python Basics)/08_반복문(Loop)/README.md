## 반복문이란 ?
- 같은 코드를 여러 번 실행하는 문법
- 파이썬은 값을 하나씩 꺼내 반복하는 `for` 와 조건이 참인 동안 반복하는 `while` 두 가지가 있다
- `break`, `continue` 로 반복 중간에 흐름을 바꿀 수 있다

<br/>

## 반복문 (Loop)
사전적 의미로 loop는 고리, 둥근 테두리다.
공학적으로는 정해진 코드를 되풀이해 실행하는 구조를 말한다. 블록 끝까지 실행한 흐름이 고리처럼 다시 블록 처음으로 돌아오는 모양에서 이름이 왔다.

### 왜 필요할까
학생 30명의 이름을 출력하려고 `print()` 를 30줄 쓸 수는 없다. 학생이 100명으로 늘면 코드를 또 고쳐야 한다. 반복문을 쓰면 몇 명이든 같은 코드 몇 줄로 처리할 수 있다.

<br/>

## for 문
리스트나 문자열처럼 여러 값이 모인 것에서 값을 하나씩 꺼내 변수에 넣고 블록을 실행한다. 값을 다 꺼내면 끝난다. 출석부를 위에서부터 한 명씩 부르는 것과 같다.

```python
for fruit in ["사과", "배", "귤"]:
    print(fruit)

for ch in "abc":
    print(ch)   # a, b, c
```

이렇게 값을 하나씩 꺼낼 수 있는 대상을 반복 가능한 객체(Iterable)라 한다. 문자열, 리스트, 튜플, 딕셔너리, 집합이 모두 해당한다.

### range()
정해진 횟수만큼 반복할 때 쓴다. `range(시작, 끝, 간격)` 이고 끝 값은 포함하지 않는다. 시작을 생략하면 0, 간격을 생략하면 1이다.

```python
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 10, 2):   # 1, 3, 5, 7, 9
    print(i)

for i in range(5, 0, -1):   # 5, 4, 3, 2, 1
    print(i)
```

### enumerate()
순번과 값이 함께 필요할 때 쓴다. enumerate는 하나씩 세다, 열거하다라는 뜻이다.

```python
for i, fruit in enumerate(["사과", "배"]):
    print(i, fruit)   # 0 사과, 1 배
```

<br/>

## while 문
조건이 참인 동안 계속 반복한다. 반복할 때마다 조건을 다시 검사하고, 거짓이 되면 끝난다. 사용자가 그만이라고 입력할 때까지처럼 반복 횟수를 미리 알 수 없을 때 쓴다.

```python
n = 3
while n > 0:
    print(n)   # 3, 2, 1
    n -= 1
```

### 무한 루프
조건이 끝까지 참이면 반복이 영원히 끝나지 않는다. 위 예시에서 `n -= 1` 을 빠뜨리면 `n` 이 계속 3이라 멈추지 않는다. 블록 안에서 조건이 언젠가 거짓이 되도록 써야 한다. 실행 중인 프로그램은 터미널에서 Ctrl + C로 멈출 수 있다.
일부러 `while True:` 로 무한 루프를 만들고, 안에서 조건을 만나면 `break` 로 빠져나오는 방식도 자주 쓴다.

```python
while True:
    cmd = input("명령: ")
    if cmd == "q":
        break
    print(f"입력: {cmd}")
```

### for와 while 중 무엇을 쓸까
반복할 대상이나 횟수가 정해져 있으면 `for`, 어떤 상태가 될 때까지 반복해야 하면 `while` 을 쓴다.

<br/>

## break, continue
- `break` 는 반복을 즉시 끝내고 반복문 다음 줄로 나간다
- `continue` 는 이번 차례의 남은 코드만 건너뛰고 다음 반복으로 넘어간다

```python
for i in range(10):
    if i == 5:
        break      # 5에서 반복 종료
    if i % 2 == 0:
        continue   # 짝수는 건너뜀
    print(i)       # 1, 3
```

<br/>

## 중첩 반복문
반복문 안에 반복문을 넣으면 바깥 반복 한 번마다 안쪽 반복이 처음부터 끝까지 돈다. 시계의 시침이 한 칸 갈 때 분침이 한 바퀴 도는 것과 같다. 구구단이 대표적인 예다.

```python
for i in range(2, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i * j}")
```

`break` 는 자신을 감싼 가장 안쪽 반복문 하나만 빠져나온다.
