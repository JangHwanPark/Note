## 변수란 ?
- 값에 붙이는 이름
- 값은 메모리 어딘가에 저장되고, 변수는 그 값을 가리키는 이름표 역할을 한다
- 이름만 부르면 값을 다시 꺼내 쓸 수 있다

<br/>

## 변수 (Variable)
사전적 의미는 변할 수 있는 수. 수학에서 x, y처럼 여러 값이 들어갈 수 있는 자리다.
공학적으로는 프로그램이 다루는 값에 붙인 이름이다. 물건에 이름표를 붙여 두면 나중에 이름만 불러 꺼낼 수 있는 것과 같다. 이름표는 다른 물건에 옮겨 붙일 수도 있어서, 같은 변수에 나중에 다른 값을 넣을 수 있다.

### 왜 필요할까
`3.14 * 5 * 5` 처럼 값을 그대로 쓰면 각 숫자가 무엇인지 알기 어렵고, 같은 값을 여러 곳에서 쓰다가 바꿔야 할 때 모두 찾아 고쳐야 한다. 변수로 이름을 붙이면 코드가 무엇을 하는지 드러나고, 값을 한 곳에서만 바꾸면 된다.

```python
pi = 3.14
radius = 5
area = pi * radius * radius
```

<br/>

## 대입
`=` 는 수학의 같다가 아니라 오른쪽 값을 왼쪽 이름에 연결하라는 뜻이다. 이를 대입(Assignment)이라 한다. 그래서 `count = count + 1` 처럼 자기 자신을 이용해 새 값을 넣는 것도 가능하다. 오른쪽을 먼저 계산하고 그 결과를 왼쪽에 넣는다.

```python
count = 0
count = count + 1   # 1
```

### 동적 타이핑 (Dynamic Typing)
파이썬은 변수를 만들 때 자료형을 따로 적지 않는다. 대입하는 순간 변수가 생기고, 자료형은 들어간 값을 보고 정해진다. 같은 변수에 다른 자료형의 값을 다시 넣을 수도 있다.

```python
name = "kim"
age = 20
age = "스무 살"   # 숫자를 넣었던 변수에 문자열도 넣을 수 있다
```

편하지만 변수에 지금 어떤 자료형이 들어 있는지 코드만 보고 알기 어려워질 수 있다. 이를 보완하는 타입 힌트(Type Hint)는 [19장](../19_타입%20힌트(Type%20Hint))에서 다룬다.

### 여러 변수에 한 번에 대입
```python
a, b = 1, 2
a, b = b, a   # 값 교환. a는 2, b는 1
x = y = 0     # 같은 값 대입
```

다른 언어에서는 두 값을 바꿀 때 임시 변수가 필요하지만, 파이썬은 `a, b = b, a` 한 줄로 바꿀 수 있다. 오른쪽의 `b, a` 를 먼저 묶어 두고 왼쪽에 차례로 풀어 넣기 때문이다.

<br/>

## 이름 짓는 규칙
### 지켜야 하는 규칙
- 영문자, 숫자, 밑줄(`_`)을 쓸 수 있고 숫자로 시작할 수 없다
- 대소문자를 구분한다 (`age` 와 `Age` 는 다른 변수)
- `if`, `for`, `class` 같은 예약어는 쓸 수 없다

### 관례
- 단어 사이를 밑줄로 잇는 스네이크 케이스(snake_case)를 쓴다 (`user_name`)
- 바꾸지 않을 값(상수)은 대문자로 쓴다 (`MAX_SIZE = 100`). 파이썬이 막아 주지는 않고 사람끼리의 약속이다
- `a`, `tmp` 보다 `user_count` 처럼 무엇을 담는지 드러나는 이름을 쓴다
