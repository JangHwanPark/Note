## 입력과 출력이란 ?
- 입력(Input)은 프로그램 밖에서 안으로 값이 들어오는 것, 출력(Output)은 프로그램 안의 값을 밖으로 내보내는 것
- 줄여서 입출력, 영어로 I/O라 부른다
- 이 장에서는 키보드로 입력받고 화면에 출력하는 가장 기본적인 방법인 `input()` 과 `print()` 를 다룬다

<br/>

## 왜 필요할까
입력이 없으면 프로그램은 매번 같은 값으로만 동작하고, 출력이 없으면 계산을 해도 결과를 볼 수 없다. 자판기가 버튼(입력)을 받아 음료(출력)를 내주듯, 프로그램도 입력과 출력이 있어야 사용자와 주고받을 수 있다.

<br/>

## print()
### 기본 사용
값을 화면에 출력한다. 여러 값을 쉼표로 넘기면 공백으로 이어 출력하고, 출력이 끝나면 줄바꿈이 붙는다.

```python
print("hello")         # hello
print("a", "b", 1)     # a b 1
print()                # 빈 줄
```

### sep, end
`sep` 은 값 사이에 넣을 구분자(separator), `end` 는 맨 끝에 붙일 문자다. 기본값은 각각 공백과 줄바꿈(`\n`)이다.

```python
print("a", "b", sep="-")   # a-b
print("a", end="")         # 줄바꿈 없이 출력
print("b")                 # 앞 줄에 이어서 ab
```

### 이스케이프 문자 (Escape Character)
escape는 탈출하다라는 뜻. 백슬래시(`\`) 뒤의 글자는 원래 뜻에서 벗어나 특별한 의미가 된다.

```python
print("첫 줄\n둘째 줄")   # \n 줄바꿈
print("이름\t나이")       # \t 탭
print("\"따옴표\"")       # \" 따옴표 자체
```

## input()
### 기본 사용
사용자가 키보드로 한 줄을 입력하고 엔터를 칠 때까지 기다렸다가, 입력한 내용을 돌려준다. 괄호 안의 문자열은 입력 전에 보여 줄 안내 문구다.

```python
name = input("이름: ")
print(f"안녕, {name}")
```

### 항상 문자열로 돌려준다
`input()` 은 숫자를 입력해도 문자열을 돌려준다. 키보드로 들어오는 것은 결국 글자이기 때문이다. 숫자로 계산하려면 3장의 형 변환을 거친다.

```python
age = input("나이: ")        # "20"
age + 1                      # TypeError
age = int(input("나이: "))   # 20
age + 1                      # 21
```

### 한 줄에 여러 값 받기
공백으로 구분해 입력받고 `split()` 으로 나눈다. 코딩 테스트에서 자주 쓰는 형태다.

```python
a, b = input().split()           # "3 5" 입력 시 a는 '3', b는 '5'
a, b = map(int, input().split()) # 숫자로 바꿔 받기
```

`map(int, ...)` 은 나눈 값 하나하나에 `int` 를 적용한다는 뜻이다. `map` 은 함수와 반복을 배운 뒤 다시 보면 이해가 쉽다.
