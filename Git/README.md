## Git이란 ?
- 파일이 바뀐 기록을 저장해 두고, 원하는 시점으로 돌아가거나 여러 사람의 작업을 합칠 수 있게 하는 버전 관리 도구
- 저장소 전체 기록을 각자의 컴퓨터에 두는 분산 방식이라, 원격 저장소 없이도 기록을 남길 수 있다

<br/>
