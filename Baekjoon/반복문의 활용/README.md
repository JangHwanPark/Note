## 카운트 변수 사용하기 (개수 세기)
- 배열이나 구간 안에서 “조건을 만족하는 원소가 몇 개인지” 세기 위해
- 루프는 원소를 하나씩 보니까, 개수를 세려면 cnt라는 누적 변수가 필요
```js
let cnt = 0;
for (let i = a; i <= b; i++) {
  if (i % 2 === 0) cnt++;   // 조건 만족 시 카운트
}
```

<br/>

## 조건을 만족하는 합 구하기 (조건 만족 값들의 총합)
- 조건을 만족하는 값들의 합을 내야 할 때
- 루프는 값을 하나씩 처리하므로, 더해야 할지 말지를 조건으로 걸어 sum에 누적
```js
let sum = 0;
for (let i = a; i <= b; i++) {
  if (i % 3 === 0) sum += i;
}
```

<br/>

## 조건을 만족하는 곱 구하기 (조건 만족 값들의 곱)
- 곱셈은 더하기와 달리 기본값이 1이고, 조건에 따라 계속 곱을 누적해야 하기 때문
- 팩토리얼, 조합 계산, 배수 곱 등
```js
let prod = 1;
for (let i = 1; i <= n; i++) {
  prod *= i;  // 팩토리얼
}
```

<br/>

## 무한루프 (Infinite Loop)
### 종료 시점을 모를 때, break로 직접 제어
- 입력 개수를 미리 알 수 없거나, 특정 조건이 만족될 때까지 반복을 이어가야 할 때
- 종료 시점은 루프가 아니라 break로 제어
```js
while (true) {
  let x = input[i++];
  if (x === 0) break;   // 종료조건
}
```

<br/>

## 언제 끝날지 모르는 상황에서의 루프
### 반복 횟수가 아닌 상황으로 제어
- 예를 들어 EOF(파일 끝)까지 읽거나, 외부 이벤트(사용자 입력, 서버 응답)에 따라 반복이 끝날 수 있음
- “반복 횟수” 대신 “상황”으로 반복 제어
```js
while (someCondition()) {
  // 조건이 깨질 때까지 계속
}
```

<br/>

## 단 하나라도 만족하는 경우
### 최소 한 개만 찾으면 되므로 break 최적화
- “조건을 만족하는 게 하나라도 있으면 된다”는 문제
- 루프 중간에 조건이 만족되면 더 볼 필요 없으므로 break
```js
let found = false;
for (let x of arr) {
  if (x === target) { found = true; break; }
}
```

<br/>

## 모두 만족하는 경우
### 전부 확인해야 하는데, 하나라도 실패하면 곧바로 탈출
- “모든 원소가 조건을 만족해야 한다”는 문제
- 루프 중 하나라도 조건이 깨지면 결과는 false → break
```js
let allEven = true;
for (let x of arr) {
  if (x % 2 !== 0) { allEven = false; break; }
}
```
