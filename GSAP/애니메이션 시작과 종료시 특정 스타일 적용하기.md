## onComplete를 사용해서 position: relative로 변경하기
- `onComplete`는 **애니메이션이 끝났을 때 실행할 함수**를 지정할 수 있음.
- 애니메이션 시작 시 `position: fixed`, 종료 후 `position: relative`로 변경.

### 예제
```js
gsap.to(headerRef.current, {
  y: -100, // 위로 이동
  duration: 1.2,
  onStart: () => {
    headerRef.current.style.position = "fixed"; // 애니메이션 시작 시 fixed 적용
  },
  onComplete: () => {
    headerRef.current.style.position = "relative"; // 애니메이션 완료 후 relative로 변경
  },
  scrollTrigger: {
    trigger: headerRef.current,
    start: "top 100px",
    end: "top 50px",
    scrub: true,
  }
});
```

### 실행 흐름
- 애니메이션이 시작될 때 → position: fixed 적용
- y: -100까지 이동한 후 → position: relative로 변경됨

<br/>

## ScrollTrigger의 toggleClass를 사용해서 자동 변경하기
- toggleClass를 사용하면 특정 스크롤 구간에서 자동으로 fixed → relative 전환 가능
- CSS를 활용해서 position 속성을 전환하는 것이 더 깔끔한 방법

### 예제
```js
gsap.to(headerRef.current, {
  y: -100,
  duration: 1.2,
  scrollTrigger: {
    trigger: headerRef.current,
    start: "top 100px",
    end: "top 50px",
    scrub: true,
    toggleClass: { targets: headerRef.current, className: "relative-header" },
  }
});
```

#### CSS 추가
```css
.relative-header {
  position: relative !important;
}
```
| 장점                       | 단점                     |
|--------------------------|------------------------|
| CSS로 스타일을 제어하므로 유지보수가 쉬움 | JS에서 직접 제어하려면 추가 코드 필요 |

<br/>

## ScrollTrigger 이벤트 리스너 활용하기
onEnter, onLeave 등의 이벤트를 활용하여 스크롤 위치에 따라 스타일 동적 변경 가능
### 예제
```js
ScrollTrigger.create({
  trigger: headerRef.current,
  start: "top 100px",
  end: "top 50px",
  scrub: true,
  onEnter: () => {
    headerRef.current.style.position = "fixed";
  },
  onLeave: () => {
    headerRef.current.style.position = "relative";
  },
  onLeaveBack: () => {
    headerRef.current.style.position = "fixed";
  },
  onEnterBack: () => {
    headerRef.current.style.position = "fixed";
  }
});
```

#### 이벤트 동작 방식
| 이벤트         | 설명                        |
|-------------|---------------------------|
| onEnter     | 스크롤이 지정 위치에 도달하면 fixed 적용 |
| onLeave     | 해당 위치를 지나면 relative 적용    |
| onLeaveBack | 뒤로 스크롤할 때 다시 fixed 적용     |
| onEnterBack | 다시 위로 올라가면 fixed 유지       |

<br/>

## 어떤 방법이 가장 좋을까?
| 방법                    | 	장점	                   | 단점                   |
|-----------------------|------------------------|----------------------|
| onComplete            | 	GSAP 내부에서 깔끔하게 처리 가능  | 	스크롤 이벤트와 연결되지 않음    |
| toggleClass           | 	CSS로 깔끔하게 관리 가능       | 	JS에서 제어하려면 추가 코드 필요 |
| ScrollTrigger 이벤트 리스너 | 	스크롤 이벤트에 맞춰 정밀한 제어 가능 | 	코드가 조금 더 길어짐        |

### 추천
- 애니메이션이 끝난 후 relative가 되어야 한다면 → 방법 1 (onComplete)
- 스크롤이 특정 구간을 지날 때 자동으로 바뀌어야 한다면 → 방법 2 (toggleClass)
- 스크롤 상태에 따라 동적 제어가 필요하면 → 방법 3 (ScrollTrigger 이벤트 리스너)
