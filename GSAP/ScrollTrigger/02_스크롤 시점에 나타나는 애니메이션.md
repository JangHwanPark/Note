## Scroll-triggered Animation (스크롤 트리거 애니메이션)
스크롤 위치에 따라 특정 요소가 **시간에 맞춰 자연스럽게 변화**하는 애니메이션 기법입니다.  
GSAP의 `ScrollTrigger`와 함께 사용하여 **사용자의 스크롤 동작에 맞춰 요소가 점진적으로 변경되는 효과**를 구현할 수 있습니다.

---


## 주요 특징
1. **스크롤 위치 기반 애니메이션**: 사용자가 스크롤할 때 요소가 등장, 사라짐, 이동하는 효과 적용.
2. **스크롤 비율에 따라 진행**: `scrub: true` 설정 시 스크롤 이동에 맞춰 애니메이션 진행.
3. **GSAP ScrollTrigger 활용**: `start`, `end`, `scrub`, `markers` 등의 옵션을 사용하여 세밀한 조정 가능.
4. **패럴랙스 효과(Parallax)**, **타임라인 효과(Timeline Scroll Animation)** 등과 결합 가능.

---

## 적용 사례
- 스크롤 진행 시 타임라인 효과
- 패럴랙스(Parallax) 스크롤 애니메이션
- 스티키 섹션(Sticky Section) 애니메이션
- 스크롤을 통한 Reveal 효과 (Scroll Reveal Animation)

---

## 예제 코드 (GSAP ScrollTrigger)
```tsx
import { useRef } from "react";
import gsap from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import { useGSAP } from "@gsap/react";

gsap.registerPlugin(ScrollTrigger);

const ScrollAnimation = () => {
  const timelineRef = useRef(null);
  const dotRef = useRef(null);

  useGSAP(() => {
    gsap.fromTo(
      timelineRef.current,
      { height: "0%", opacity: 0 },
      {
        height: "100%",
        opacity: 1,
        ease: "none",
        scrollTrigger: {
          trigger: timelineRef.current,
          start: "top center",
          end: "300% bottom",
          scrub: 3, // 🎯 스크롤 진행 비율에 따라 점진적 변화
        },
      }
    );

    gsap.fromTo(
      dotRef.current,
      { y: 20, opacity: 0 },
      {
        y: 0,
        opacity: 1,
        ease: "power2.out",
        scrollTrigger: {
          trigger: timelineRef.current,
          start: "top center",
          end: "300% bottom",
          scrub: 3,
        },
      }
    );
  }, []);

  return (
    <section className="relative flex flex-col items-center py-20">
      <h2 className="text-5xl text-center text-transparent bg-gradient-to-b from-purple-500 to-white bg-clip-text">
        Scroll-triggered Animation
      </h2>

      {/* 타임라인 */}
      <div className="relative w-[3px] bg-gradient-to-t from-purple-500 via-purple-300 to-transparent mt-10 h-[500px]">
        <div ref={timelineRef} className="absolute left-0 top-0 w-full bg-purple-500"></div>
        <div ref={dotRef} className="absolute bottom-0 left-1/2 transform -translate-x-1/2 w-4 h-4 bg-purple-500 rounded-full shadow-lg"></div>
      </div>
    </section>
  );
};

export default ScrollAnimation;
```
