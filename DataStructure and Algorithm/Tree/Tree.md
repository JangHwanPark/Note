# 트리 자료구조
- 트리는 비선형 계층 구조를 나타내는데 사용된다.
- 회사 조직도, 파일 시스템, 웹 사이트 메뉴구조등에 적용되어 있다.

## 트리 용어
### 노드(Node)
트리를 구성하는 요소

### 루트 노드(RootNode)
트리 최상단에 위치한 노드 (부모가 없음)

### 자식 노드(Child Node)
어떤 노드 아래에 연결된 노드

### 부모 노드(Parent Node)
어떤 노드 위에 연결된 노드

### 형제 노드(Sibling Node)
같은 부모를 가지는 노드들

### 리프 노드(Leaf Node)
자식이 없는 노드

### 간선(Edge)
노드와 노드를 연결하는 선

### 깊이(Depth)
루트 노드부터 어떤 노드까지의 간선 수

### 높이(Height)
- 어떤 노드부터 리프노드까지의 가장 긴 간선 수
- 트로 높이는 루트 노드의 높이

### 서브트리(Subtree)
특정 노드와 그 자손들로 구성된 부분 트리
