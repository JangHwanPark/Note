## 한 경로를 끝까지 탐색 (깊이를 우선시하여 탐색)
- BFS는 층별, DFS는 가지별로 탐색한다.
- 하나의 노드에서 시작하여 더이상 갈 수 없을때 까지 최대한 깊게 들어간 후, 다시 돌아와(백트래킹: backtracking)다른경로를 탐색한다.


DFS의 핵심 원리: '한 경로'를 끝까지 탐색
DFS(깊이 우선 탐색)는 말 그대로 '깊이'를 우선하여 탐색하는 방식입니다. 한 노드에서 시작하여, 더 이상 갈 수 없을 때까지 최대한 깊게 들어간 후, 다시 돌아와(backtracking) 다른 경로를 탐색합니다.

BFS가 층별로 탐색했다면, DFS는 가지별로 탐색하는 방식입니다.

DFS는 크게 두 가지 방식으로 구현할 수 있습니다.

재귀 함수(Recursion): 가장 직관적이고 일반적인 방법. 함수 호출 스택이 스택 자료구조의 역할을 대신합니다.

스택(Stack) 자료구조: 재귀 함수를 사용하지 않고 반복문으로 구현할 때 사용.

우리는 재귀 함수를 사용해서 먼저 이해하고, 스택을 사용한 반복문 구현도 함께 살펴볼게요.

왜 DFS는 재귀 함수나 스택을 사용할까?
DFS의 탐색 원리인 **'가장 최근에 방문한 노드의 자식을 먼저 탐색'**하는 특성 때문입니다. 이는 LIFO (Last-In, First-Out), 즉 가장 나중에 들어온 것이 먼저 나가는 스택의 동작 방식과 정확히 일치합니다.

이전에 사용했던 트리를 예시로 들어볼게요.

      A (Level 0)
     / \
B (Level 1)  C (Level 1)
/ \     
D (Level 2) E (Level 2)
참고: 이 트리에서는 C의 자식이 없다고 가정하고 설명합니다.

1. 재귀 함수를 이용한 DFS 탐색 과정 (스택의 역할을 이해하기)
   컴퓨터의 **함수 호출 스택(Call Stack)**이 스택 자료구조의 역할을 합니다.

dfs(A)를 호출합니다.

스택에 A가 쌓입니다.

A를 방문하고, A의 첫 번째 자식 B를 탐색하기 위해 dfs(B)를 호출합니다.

dfs(B)를 호출합니다.

스택에 B가 쌓입니다.

B를 방문하고, B의 첫 번째 자식 D를 탐색하기 위해 dfs(D)를 호출합니다.

dfs(D)를 호출합니다.

스택에 D가 쌓입니다.

D를 방문하고, D는 자식이 없으므로 함수가 종료됩니다. 스택에서 D가 제거됩니다.

dfs(B)로 돌아옵니다.

B의 다음 자식인 E를 탐색하기 위해 dfs(E)를 호출합니다.

dfs(E)를 호출합니다.

스택에 E가 쌓입니다.

E를 방문하고, E는 자식이 없으므로 함수가 종료됩니다. 스택에서 E가 제거됩니다.

dfs(B)로 돌아옵니다.

B의 모든 자식을 탐색했으므로 함수가 종료됩니다. 스택에서 B가 제거됩니다.

dfs(A)로 돌아옵니다.

A의 다음 자식인 C를 탐색하기 위해 dfs(C)를 호출합니다.

dfs(C)를 호출합니다.

스택에 C가 쌓입니다.

C를 방문하고, C는 자식이 없으므로 함수가 종료됩니다. 스택에서 C가 제거됩니다.

dfs(A)로 돌아옵니다.

A의 모든 자식을 탐색했으므로 함수가 종료됩니다. 스택에서 A가 제거됩니다.

스택이 비었으므로 탐색이 완료됩니다.

이 과정을 통해 노드를 방문한 순서는 A -> B -> D -> E -> C가 됩니다. 최근에 들어간 노드(D, E, C)가 먼저 처리되는 LIFO 원리가 적용된 것을 볼 수 있죠.

2. 스택 자료구조를 이용한 DFS 탐색 과정 (명시적 구현)
   재귀를 사용하지 않고 반복문으로 구현할 때는 직접 스택 배열을 사용합니다.

시작: 루트 노드 A를 스택에 넣습니다.

Stack: [A]

1단계: 스택에서 맨 위의 노드 A를 꺼냅니다. A를 방문합니다. 그리고 A의 자식들(B, C)을 스택에 역순으로 넣습니다. (C -> B 순서)

이유: B가 C보다 먼저 탐색되어야 하기 때문에, B가 스택의 맨 위에 오도록 C를 먼저 넣고, B를 나중에 넣는 것입니다.

Stack: [C, B]

2단계: 스택에서 맨 위의 B를 꺼냅니다. B를 방문합니다. B의 자식들(D, E)을 스택에 역순으로 넣습니다. (E -> D 순서)

Stack: [C, E, D]

3단계: 스택에서 맨 위의 D를 꺼냅니다. D를 방문합니다. D는 자식이 없으므로 스택에 넣을 것이 없습니다.

Stack: [C, E]

4단계: 스택에서 맨 위의 E를 꺼냅니다. E를 방문합니다. E는 자식이 없습니다.

Stack: [C]

5단계: 스택에서 맨 위의 C를 꺼냅니다. C를 방문합니다. C는 자식이 없습니다.

Stack: []

종료: 스택이 비었으므로 탐색을 종료합니다.

마찬가지로 방문 순서는 A -> B -> D -> E -> C가 됩니다.

BFS와 DFS 비교 요약
특징	BFS (너비 우선 탐색)	DFS (깊이 우선 탐색)
탐색 방식	동일 레벨의 노드들을 먼저 탐색	한 경로를 끝까지 깊게 탐색
사용 자료구조	큐(Queue) (FIFO)	재귀 함수 또는 스택(Stack) (LIFO)
장점	최단 경로를 찾기에 용이	모든 경로를 탐색할 때 용이
단점	메모리 사용량이 많을 수 있음	재귀 깊이가 깊어질 시 스택 오버플로우 발생 가능
주요 활용	최단 경로 찾기, 미로 찾기, 네트워크 탐색	모든 경로 탐색, 사이클 감지, 백트래킹 알고리즘

Sheets로 내보내기
DFS는 특정 노드까지의 모든 경로를 탐색하거나, 트리의 깊이를 기준으로 문제를 해결해야 할 때 매우 강력한 도구입니다. 이 동작 원리를 명확하게 이해하고, 재귀와 스택 두 가지 방식으로 모두 구현할 수 있도록 연습하는 것이 중요합니다.
