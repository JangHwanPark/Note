    수신지 IP Address에 대한 물리적 주소(MAC 주소)를 매핑하는 프로토콜은 ARP(Address Resolution Protocol) 입니다.

정답: ② ARP ✅
해설:
✅ (2) ARP (Address Resolution Protocol)
→ IP 주소(논리 주소)를 MAC 주소(물리 주소)로 변환하는 프로토콜
→ 예를 들어, 호스트가 192.168.1.10 IP 주소를 가진 장치의 MAC 주소를 알아내려면 ARP 요청을 보내고, 해당 장치가 ARP 응답을 반환함.

❌ (1) DHCP (Dynamic Host Configuration Protocol)
→ IP 주소를 자동으로 할당하는 프로토콜로, IP와 MAC 주소 매핑과는 무관함.

❌ (3) RARP (Reverse Address Resolution Protocol)
→ MAC 주소 → IP 주소 변환하는 프로토콜(ARP의 반대).
→ 현재는 거의 사용되지 않으며, 대신 DHCP가 사용됨.

❌ (4) DNS (Domain Name System)
→ 도메인 주소(www.example.com) → IP 주소 변환하는 프로토콜.
→ IP ↔ MAC 매핑과는 관련 없음.
