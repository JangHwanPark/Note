## Frontend Knowledge Base
이 저장소는 `기억보단 기록을`이라는 철학을 바탕으로, 프론트엔드 개발자로서 학습한 모든 지식을 기록하고 축적하는 개인 지식 베이스(Personal Knowledge Base)입니다.

모든 노트는 `핵심 개념`, `프레임워크`, `라이브러리/도구`를 명확히 분리하는 것을 원칙으로 합니다.

- [React](./React)
- [인공지능(AI)](./인공지능(Artificial%20Intelligence))

## 폴더 구조 및 원칙
* `Algorithm`: 코딩 테스트 및 알고리즘 문제 풀이, 핵심 개념을 정리합니다.
* `CS_Basic`: 네트워크, 웹, 캐싱, 클라이언트-서버 구조, 서버의 동시 처리, 로드 밸런싱, 함수 설계 원리 등 개발자에게 필요한 CS 기초 지식을 정리합니다.
* `Database` / `SQL`: JOIN 등 SQL 쿼리 관련 지식을 정리합니다. 요구사항 정리, 정규화 같은 데이터베이스 설계는 Database 폴더의 TODO에 남아 있습니다.
* `JavaScript`: 자바스크립트 코어 개념 (비동기와 콜스택, 스코프와 클로저, 함수, 이터레이터, ES2015)과 내장 객체 (Array, Object, String, Date), 자료구조를 정리합니다.
* `TypeScript`: any, never 타입과 제네릭 등 타입스크립트의 타입 문법을 정리합니다.
* `Python`: 파이썬 문법을 책처럼 장으로 나눠 정리합니다. 변수, 자료형, 제어문, 자료구조, 함수에서 시작해 예외 처리, 모듈, 파일 입출력, 클래스, 이터레이터와 제너레이터, 데코레이터, 타입 힌트까지 다룹니다.
* `Markup_Style`: CSS (정렬, 애니메이션, Grid), Canvas, 웹 접근성(Aria) 등 마크업과 스타일링을 정리합니다.
* `React`: **순수 React 라이브러리**의 개념 (Hooks, 컴포넌트 패턴, 배열 상태 다루기)과 자주 만드는 UI 컴포넌트를 정리합니다.
* `NextJS`: **Next.js 프레임워크** 고유의 기능 (CSR과 SSR, 레이아웃, 데이터 패칭 위치)과 풀스택 DTO 설계를 정리합니다.
* `Libraries`: `ReactQuery`, `React Router`, `GSAP`, `Jest`, `Prettier` 등 개별 라이브러리 및 도구의 사용법을 정리합니다.
* `인공지능(Artificial Intelligence)`: 인공지능, 머신러닝, 딥러닝, LLM 등 AI 기초 개념과 용어, 그리고 프롬프트, 컨텍스트, 하네스, 루프 엔지니어링, 워크플로와 에이전트, 스펙 주도 개발과 바이브 코딩, 평가 주도 개발, 토큰과 컨텍스트 창 같은 AI 활용 방법을 정리합니다. 주제마다 공식 문서의 실제 예를 모은 예시 문서를 함께 둡니다.
* `게임 디자인(Game Design)`: 재미란 무엇인가, 게임에서 재미란, 게임관, 시스템과 콘텐츠처럼 게임 디자인 이론을 책처럼 장으로 나눠 정리합니다.
* `Architecture`: `SaaS`, `BFF`, `FSD`, 모노레포 등 소프트웨어 아키텍처와 폴더 구조 설계를 정리합니다.
* `Git` / `배포` / `K8S`: 버전 관리, 배포, 인프라(K8S) 관련 지식을 정리합니다.
* `보안(Security)`: React2Shell, Node2Shell, PHP2Shell, Oracle PeopleSoft 같은 취약점 사건과 공격 방식, 대응 방법을 정리합니다.
* `SoftwareTest`: QA 이론 (테스트 레벨, 테스트 설계 기법, 결함 생명주기 등), Playwright와 테스트 자동화, JMeter, API 테스트 체크리스트를 정리합니다.
* `OpenSource`: 오픈소스에 기여한 과정과 회고를 기록합니다.
* `Project`: '디에듀', 'DataArts-Studio(Testea)' 등 실제 프로젝트 진행 시 발생한 트러블 슈팅, 개발 노트, 회고를 기록합니다.
* `Archive`: 채용 공고 스크랩 등 시의성이 있는 자료를 보관합니다.
* `용어집`: 개발하며 만난 용어를 짧게 풀어 정리합니다.
