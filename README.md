## Frontend Knowledge Base
이 저장소는 `기억보단 기록을`이라는 철학을 바탕으로, 프론트엔드 개발자로서 학습한 모든 지식을 기록하고 축적하는 개인 지식 베이스(Personal Knowledge Base)입니다.

모든 노트는 `핵심 개념`, `프레임워크`, `라이브러리/도구`를 명확히 분리하는 것을 원칙으로 합니다.

## 폴더 구조 및 원칙
* `Algorithm`: 코딩 테스트 및 알고리즘 문제 풀이, 핵심 개념을 정리합니다.
* `CS_Basic`: 네트워크, 웹, 캐싱 등 개발자에게 필요한 CS 기초 지식을 정리합니다.
* `Database` / `SQL`: 데이터베이스 설계 및 SQL 쿼리 관련 지식을 정리합니다.
* `JavaScript`: 자바스크립트 코어 개념 (비동기, 스코프, ES) 및 자료구조를 정리합니다.
* `TypeScript`: 타입스크립트 문법 및 고급 활용법을 정리합니다.
* `Markup_Style`: HTML, CSS, Canvas, 웹 접근성(Aria) 등 마크업과 스타일링을 정리합니다.
* `React`: **순수 React 라이브러리**의 개념 (Hooks, 컴포넌트 패턴, 상태관리)을 정리합니다.
* `NextJS`: **Next.js 프레임워크** 고유의 기능 (렌더링, 라우팅, 데이터 패칭)을 정리합니다.
* `Libraries`: `ReactQuery`, `GSAP`, `Jest`, `Prettier` 등 개별 라이브러리 및 도구의 사용법을 정리합니다.
* `Architecture`: `SaaS` 등 소프트웨어 아키텍처 및 디자인 패턴을 정리합니다.
* `Git` / `배포` / `K8S`: 버전 관리, 배포, 인프라(K8S) 관련 지식을 정리합니다.
* `Project`: '디에듀' 등 실제 프로젝트 진행 시 발생한 트러블 슈팅, 회고를 기록합니다.
* `Archive`: 채용 공고 스크랩 등 시의성이 있는 자료를 보관합니다.
