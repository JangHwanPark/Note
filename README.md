## Frontend Knowledge Base
`기억보단 기록을`이라는 생각으로, 프론트엔드 개발자로서 공부한 것을 기록하고 쌓아 두는 개인 지식 베이스(Personal Knowledge Base)입니다.

노트는 `핵심 개념`, `프레임워크`, `라이브러리/도구`를 나눠서 정리합니다. 아래 목차는 성격이 비슷한 폴더끼리 묶었습니다.
