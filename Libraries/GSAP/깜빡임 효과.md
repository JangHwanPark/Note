GSAP를 활용하는 방법과 Tailwind의 @keyframes을 활용하는 방법이 존재함.

## 언제 어떤 방법이 좋을까?
| 방법                 | 	사용 용도                | 장점                              | 	단점          |
|--------------------|-----------------------|---------------------------------|--------------|
| GSAP               | 	JavaScript로 애니메이션 제어 | 	동적 컨트롤 가능                      | 	추가 라이브러리 필요 |
| Tailwind Keyframes | 	Tailwind 기반 프로젝트     | 	간단한 애니메이션 적용 가능 | Tailwind 설정 필요 |
| CSS Keyframes      | 	일반적인 CSS 적용          | 	브라우저 성능 최적화                    | 	동적 제어 어려움   |


- GSAP → 로딩 진행에 따라 동적 제어 필요할 때
- Tailwind → Tailwind를 사용 중이라면 간편한 방식으로
- CSS Keyframes → 가장 기본적인 깜빡임 효과

## GSAP로 깜빡임 효과 주기
GSAP의 repeat와 yoyo 옵션을 사용하여 요소가 깜빡이도록 만들 수 있습니다.

### GSAP 깜빡임 예제
```tsx
useGSAP(() => {
  gsap.to(cursorRef.current, {
    opacity: 0, // 투명하게 만들었다가
    duration: 0.5, // 0.5초마다 반복
    repeat: -1, // 무한 반복
    yoyo: true, // 깜빡이는 효과 (투명→보임 반복)
    ease: "power1.inOut",
  });
}, []);
```
- opacity: 0 → 완전히 투명하게 만들었다가 다시 보이게 반복
- duration: 0.5 → 0.5초마다 깜빡임
- repeat: -1 → 무한 반복
- yoyo: true → 투명-보임 반복 효과
- ease: "power1.inOut" → 부드럽게 전환

<br/>

## Tailwind + Keyframes로 깜빡임 적용
```tsx
<div ref={cursorRef} className="w-5 h-10 bg-[#eae5ec] rounded-sm animate-blink"></div>
```

<br/>

## CSS @keyframes로 직접 적용
```css
@keyframes blink {
  0%, 50% { opacity: 1; }
  51%, 100% { opacity: 0; }
}

.blink {
  animation: blink 1s infinite;
}
```
```tsx
<div ref={cursorRef} className="w-5 h-10 bg-[#eae5ec] rounded-sm blink"></div>
```
