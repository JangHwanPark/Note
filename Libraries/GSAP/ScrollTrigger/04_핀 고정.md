## GSAP ScrollTrigger를 활용한 스크롤 애니메이션 및 고정 효과
스크롤에 따라 요소가 이동하거나 나타난 후 특정 위치에 고정되는 효과는 일반적으로 "스크롤 트리거 애니메이션(Scroll-triggered animation)"과 "스티키 포지셔닝(Sticky positioning)" 또는 "핀 고정(Pin)" 기법이라고 불립니다. 이 효과들은 모던 웹사이트에서 매우 인기 있는 인터랙션 패턴입니다.

<br/>

## 주요 애니메이션 명칭
| 애니메이션 명칭                  | 설명                              |
|---------------------------|---------------------------------|
| **Reveal on Scroll**      | 스크롤 시 요소가 나타나는 효과               |
| **Parallax Scrolling**    | 스크롤 시 여러 레이어가 서로 다른 속도로 이동하는 효과 |
| **Sticky Elements**       | 스크롤 시 요소가 특정 위치에 고정되는 효과        |
| **Pin-to-Panel**          | 요소가 특정 구간 동안 고정되다가 해제되는 효과      |
| **Scroll-based Timeline** | 스크롤 진행에 따라 순차적으로 진행되는 애니메이션     |

<br/>

## GSAP로 구현하는 방법
GSAP의 ScrollTrigger 플러그인을 사용하면 이런 효과를 쉽게 구현할 수 있습니다

```jsx
import React, {useEffect, useRef} from 'react';
import {gsap} from 'gsap';
import {ScrollTrigger} from 'Libraries/GSAP/ScrollTrigger/01_ScrollTrigger';

gsap.registerPlugin(ScrollTrigger);

function ScrollRevealPin() {
  const sectionRef = useRef(null);
  const elementRef = useRef(null);
  
  useEffect(() => {
    // 1. 요소 등장 애니메이션 + 고정 효과
    const tl = gsap.timeline({
      scrollTrigger: {
        trigger: sectionRef.current,
        start: "top 80%", // 섹션 상단이 뷰포트의 80% 지점에 도달하면 시작
        end: "+=500", // 시작점으로부터 500px 스크롤 후 종료
        scrub: 1, // 스크롤 위치에 애니메이션 연동 (1초 지연으로 부드럽게)
        pin: elementRef.current, // 이 요소를 고정
        pinSpacing: true, // 고정 시 공간 유지
        markers: true, // 개발 시 마커 표시 (배포 시 제거)
      }
    });
    
    // 요소가 아래에서 위로 올라오는 효과
    tl.from(elementRef.current, {
      y: 100, // 100px 아래에서 시작
      opacity: 0, // 완전 투명 상태에서 시작
      duration: 0.5 // 타임라인 내 상대적 지속 시간
    });
    
    // 요소가 원래 위치에서 오른쪽으로 이동하는 효과
    tl.to(elementRef.current, {
      x: 200, // 오른쪽으로 200px 이동
      duration: 0.5
    });
    
    // 컴포넌트 언마운트 시 정리
    return () => {
      tl.kill();
      ScrollTrigger.getAll().forEach(trigger => trigger.kill());
    };
  }, []);
  
  return (
    <div className="container" style={{height: '3000px', padding: '20px'}}>
      <div className="spacer" style={{height: '500px'}}>
        스크롤을 내려보세요
      </div>
      
      {/* 트리거 역할을 하는 섹션 */}
      <div
        ref={sectionRef}
        className="trigger-section"
        style={{
          height: '500px',
          background: '#f0f0f0',
          position: 'relative'
        }}
      >
        {/* 애니메이션 및 고정될 요소 */}
        <div
          ref={elementRef}
          className="animated-element"
          style={{
            width: '200px',
            height: '200px',
            background: 'blue',
            color: 'white',
            display: 'flex',
            justifyContent: 'center',
            alignItems: 'center',
            position: 'absolute',
            left: '50%',
            top: '50%',
            transform: 'translate(-50%, -50%)'
          }}
        >
          스크롤에 따라 나타나고 고정됨
        </div>
      </div>
      
      <div className="spacer" style={{height: '1000px'}}>
        계속 스크롤하세요
      </div>
    </div>
  );
}

export default ScrollRevealPin;

```

## 다양한 효과의 구현 방법
### 1. 스크롤 시 요소가 나타나고 고정되는 효과 (Reveal and Pin)
```javascript
ScrollTrigger.create({
  trigger: ".trigger-element", // 트리거 요소
  start: "top center", // 트리거 요소의 상단이 화면 중앙에 왔을 때 시작
  end: "+=300", // 시작점에서 300px 더 스크롤한 지점에서 종료
  pin: true, // 트리거 요소를 고정
  animation: gsap.from(".my-element", { 
    y: 100, 
    opacity: 0, 
    duration: 1 
  }),
  scrub: true // 스크롤에 애니메이션 진행 연동
});
```

### 2. 특정 위치로 이동 후 고정되는 효과 (Move and Pin)
```javascript
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: ".section",
    start: "top top", 
    end: "bottom top",
    pin: ".sticky-element", // 이 요소가 고정됨
    scrub: true
  }
});

// 요소를 특정 위치로 이동시키는 애니메이션
tl.to(".moving-element", {
  x: 200,
  y: 100,
  duration: 1
});
```

### 3. 핀 고정 해제 애니메이션 (Unpin Animation)
```javascript
ScrollTrigger.create({
  trigger: ".pin-section",
  start: "top top", 
  end: "+=500",
  pin: true,
  anticipatePin: 1, // 성능 최적화
  onLeave: () => {
    // 핀 해제 시 추가 애니메이션
    gsap.to(".pin-section", {
      y: -50,
      opacity: 0.5,
      duration: 0.5
    });
  }
});
```

## CSS만으로 구현하는 방법
```css
.sticky-element {
  position: sticky;
  top: 0; /* 화면 상단에 고정 */
  z-index: 10;
}

.trigger-section {
  height: 100vh; /* 스크롤 공간 확보 */
}
```
간단한 스티키 요소는 CSS만으로도 구현할 수 있습니다. 그러나 CSS만으로는 스크롤 위치에 따른 복잡한 애니메이션이나 정밀한 제어가 어렵기 때문에 스크롤 트리거 기반의 복잡한 애니메이션은 GSAP 사용을 권장합니다.

## 대표적인 실제 사용 사례
| 사용 사례      | 설명                              |
|------------|---------------------------------|
| 제품 소개      | 페이지	스크롤 시 제품 이미지가 고정되고 텍스트만 변경됨 |
| 스토리텔링 웹사이트 | 스크롤에 따라 스토리가 진행되며 요소들이 고정됨      |
| 포트폴리오 사이트  | 작품이 순차적으로 등장 후 잠시 고정되어 강조됨      |
| 기업 랜딩 페이지  | 	핵심 메시지가 스크롤에 따라 점진적으로 나타남      |
