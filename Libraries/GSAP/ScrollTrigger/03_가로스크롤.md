## GSAP을 활용한 가로 스크롤 적용 알고리즘
GSAP과 ScrollTrigger를 활용하여 가로 스크롤을 적용하려면,   
세로 스크롤을 감지하여 요소를 좌우로 이동시키는 방식을 사용합니다.

<br/>

### 알고리즘 개요
- 전체 컨테이너의 높이를 프로젝트 항목 개수에 맞게 조정   
→ 가로 스크롤을 시뮬레이션하기 위해 height를 증가시켜야 함.

- 스크롤 위치에 따라 요소를 가로로 이동   
→ scrollTrigger의 scrub을 이용하여 부드럽게 적용.

- GSAP의 x 속성을 조정하여 가로로 이동   
→ x: -someValue로 조정.

<br/>

### 코드로 적용하는 방식
#### 1. 컨테이너 높이 조정
가로로 6개의 프로젝트가 배치되므로 스크롤 높이를 넉넉하게 설정해야 합니다.
```js
const projectCount = projects.length;
const itemWidth = 300; // Project 하나의 예상 너비(px)
const totalWidth = projectCount * itemWidth; // 전체 리스트 너비
```
- projectCount : 프로젝트 개수
- itemWidth : 각 프로젝트의 예상 너비 (px 단위)
- totalWidth : 전체 가로 스크롤 거리


#### 2. 세로 스크롤 높이 조정
스크롤을 끝까지 내릴 때까지 충분한 높이가 필요합니다.
```js
const containerHeight = window.innerHeight + totalWidth;
```
- window.innerHeight : 현재 화면의 높이
- totalWidth : 가로로 이동해야 할 거리
- containerHeight : section의 높이를 세로로 확장


#### 3. GSAP ScrollTrigger 적용
GSAP에서 x 값을 조정하여 스크롤 양에 비례하여 좌우 이동하도록 설정합니다.
```js
useGSAP(() => {
  if (horizonRef.current) {
    gsap.to(horizonRef.current, {
      x: `-${totalWidth - window.innerWidth}px`, // 전체 너비만큼 왼쪽으로 이동
      ease: "none",
      scrollTrigger: {
        trigger: containerRef.current, // 스크롤 트리거 기준 요소
        start: "top top",
        end: `+=${totalWidth}`, // 스크롤 끝나는 지점
        scrub: 1, // 부드러운 스크롤 적용
        pin: true, // 고정하여 효과 적용
      },
    });
  }
}, []);
```
scrub: 1을 설정하면 부드럽게 이동하며, pin: true를 설정하면 스크롤 시 해당 요소가 고정됨.   
   
<br/>

### 전체 코드

```js
import clsx from "clsx";
import {Link} from "react-router-dom";
import {useRef, useEffect, useState} from "react";
import gsap from "gsap";
import {useGSAP} from "@gsap/react";
import {ScrollTrigger} from "Libraries/GSAP/ScrollTrigger/01_ScrollTrigger";

gsap.registerPlugin(ScrollTrigger);

const Project = () => {
  const projects = ["Project 1", "Project 2", "Project 3", "Project 4", "Project 5", "Project 6"];
  
  const containerRef = useRef < HTMLElement | null > (null);
  const horizonRef = useRef < HTMLUListElement | null > (null);
  
  const [containerHeight, setContainerHeight] = useState(window.innerHeight);
  
  useEffect(() => {
    const projectCount = projects.length;
    const itemWidth = 300; // 가로 스크롤될 Project 항목 너비(px)
    const totalWidth = projectCount * itemWidth;
    setContainerHeight(window.innerHeight + totalWidth);
  }, [projects.length]);
  
  useGSAP(() => {
    if (horizonRef.current && containerRef.current) {
      const projectCount = projects.length;
      const itemWidth = 300; // Project 하나의 예상 너비
      const totalWidth = projectCount * itemWidth;
      
      gsap.to(horizonRef.current, {
        x: `-${totalWidth - window.innerWidth}px`,
        ease: "none",
        scrollTrigger: {
          trigger: containerRef.current,
          start: "top top",
          end: `+=${totalWidth}`,
          scrub: 1,
          pin: true,
        },
      });
    }
  }, []);
  
  const horizontallyClass = clsx(
    "w-[300px] p-8 flex flex-col items-center justify-start gap-10"
  );
  
  return (
    <section ref={containerRef} className='bg-green-100' style={{height: `${containerHeight}px`}}>
      <article className='flex flex-col content-stretch'>
        <h2>My
          <span>Work</span>
        </h2>
        <ul ref={horizonRef} className="w-full h-full flex relative">
          {projects.map((item, index) => (
            <li key={index} className={horizontallyClass}>
              <div>
                <h3>{item}</h3>
                <h4>Project Name</h4>
                <p>Category</p>
                <h4>Tools and features</h4>
                <p>Javascript, TypeScript, React, Threejs</p>
                <div className='w-full flex justify-center'>
                  <Link to='/'>
                    <div>img</div>
                  </Link>
                </div>
              </div>
            </li>
          ))}
        </ul>
      </article>
    </section>
  );
};

export default Project;
```

<br/>

### 핵심 로직 정리
#### 1. 컨테이너 높이 증가
window.innerHeight + totalWidth를 계산하여 가로 이동을 위한 충분한 스크롤 공간을 확보.
#### 2. GSAP을 이용해 x 값을 조정
x: "-(전체 가로 길이 - 현재 화면 너비)"로 설정하여 자연스럽게 스크롤.
#### 3. ScrollTrigger로 트리거 설정
- start: "top top": 스크롤이 시작될 위치 지정.
- end: "+=totalWidth": 끝나는 지점 계산.
- scrub: 1: 부드럽게 움직이도록 설정.
- pin: true: 해당 요소를 고정하여 스크롤이 적용될 때까지 유지.
