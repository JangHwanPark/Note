## GSAP이란 ?
- GSAP(GreenSock Animation Platform)은 웹 요소에 애니메이션을 주는 JavaScript 라이브러리
- `to()`, `from()`, `fromTo()` 로 시작과 끝 상태를 정해 움직임을 만든다
- ScrollTrigger 플러그인을 쓰면 스크롤 위치에 맞춰 애니메이션을 실행하거나 요소를 고정할 수 있다

<br/>
