## 스크롤 기반 패턴
| 패턴명                                   | 설명                            |
|---------------------------------------|-------------------------------|
| **페럴랙스 스크롤링 (Parallax Scrolling)**    | 배경과 전경이 서로 다른 속도로 움직이며 깊이감을 줌 |
| **호리존탈 스크롤 (Horizontal Scrolling)**   | 가로 방향으로 스크롤되는 레이아웃            |
| **스크롤 스냅핑 (Scroll Snapping)**         | 특정 섹션에 자동으로 정렬되는 스크롤 효과       |
| **스크롤 프로그레스 바 (Scroll Progress Bar)** | 페이지 스크롤 진행 상태를 시각적으로 표시       |

## 애니메이션 패턴
| 패턴명                                | 설명                         |
|------------------------------------|----------------------------|
| **모핑 애니메이션 (Morphing Animation)**  | 한 모양이 부드럽게 다른 모양으로 변형되는 효과 |
| **로티 애니메이션 (Lottie Animation)**    | 복잡한 벡터 애니메이션을 가볍게 구현       |
| **마이크로 인터랙션 (Micro-interactions)** | 작은 요소의 반응형 애니메이션으로 피드백 제공  |
| **스플래시 스크린 (Splash Screen)**       | 웹사이트 진입 시 보여주는 인트로 애니메이션   |
| **페이지 전환 애니메이션 (Page Transition)** | 페이지 간 자연스러운 전환 효과          |


<br/>

## 내비게이션 패턴
| 패턴명                                         | 설명                             |
|---------------------------------------------|--------------------------------|
| **스티키 내비게이션 (Sticky Navigation)**           | 스크롤 시에도 상단에 고정되는 메뉴            |
| **햄버거 메뉴 애니메이션 (Hamburger Menu Animation)** | 모바일에서 햄버거 아이콘이 X로 변하는 등의 애니메이션 |
| **오프캔버스 내비게이션 (Off-canvas Navigation)**     | 화면 바깥에서 슬라이드인 되는 메뉴            |
| **메가 메뉴 (Mega Menu)**                       | 마우스 호버 시 대형 드롭다운 메뉴가 나타나는 패턴   |


<br/>

## 레이아웃 패턴
| 패턴명                                | 설명                         |
|------------------------------------|----------------------------|
| **카드 기반 레이아웃 (Card-based Layout)** | 정보를 개별 카드로 보여주는 패턴         |
| **비대칭 레이아웃 (Asymmetrical Layout)** | 전통적인 그리드를 벗어난 비대칭 디자인      |
| **부분 스크롤 (Split Scrolling)**       | 페이지의 다른 부분이 독립적으로 스크롤되는 효과 |
| **대형 타이포그래피 (Hero Typography)**    | 큰 텍스트를 활용한 시각적 임팩트         |
| **글래스모피즘 (Glassmorphism)**         | 반투명 유리 같은 효과의 UI 요소        |

<br/>

## 로딩 및 상태 표시 패턴
| 패턴명                              | 설명                        |
|----------------------------------|---------------------------|
| **스켈레톤 스크린 (Skeleton Screen)**   | 콘텐츠 로딩 중 윤곽선으로 미리 보여주는 패턴 |
| **무한 스크롤 (Infinite Scrolling)**  | 페이지 하단에 도달하면 자동으로 콘텐츠 추가  |
| **컨텍스트 전환 (Context Switching)**  | 화면 이동 없이 현재 페이지에서 콘텐츠 전환  |
| **토스트 알림 (Toast Notifications)** | 임시로 나타났다 사라지는 알림          |

## 인터랙티브 패턴
| 패턴명                                 | 설명                        |
|-------------------------------------|---------------------------|
| **커서 인터랙션 (Cursor Interaction)**    | 커스텀 커서 효과와 요소와의 인터랙션      |
| **텍스트 하이라이팅 (Text Highlighting)**   | 스크롤이나 마우스 동작에 반응하는 텍스트 강조 |

| **드래그 인터랙션 (Drag Interaction)**     | 요소를 드래그하여 조작하는 패턴         |
| **홀로그램/체적 디자인 (Volumetric Design)** | 깊이감과 3D 느낌을 주는 디자인        |
