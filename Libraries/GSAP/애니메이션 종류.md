## 애니메이션 종류 & GSAP 메서드
| 애니메이션 종류   | 설명               | GSAP 메서드             |
|------------|------------------|----------------------|
| 페이드 인      | 태그가 부드럽게 나타남     | .fromTo(), .to()     |
| 슬라이드 인     | 태그가 왼쪽/오른쪽에서 나타남 | .from()              |
| 버블 효과      | 태그가 살짝 커졌다 작아짐   | .fromTo()            |
| 랜덤 회전      | 태그가 랜덤하게 회전하며 등장 | .set(), .to()        |
| 흔들리는 효과    | 태그가 살짝 흔들림       | .to() 반복             |
| 3D 플립      | 태그가 뒤집히면서 나타남    | rotationX, rotationY |
| 워블(Wobble) | 태그가 부드럽게 흔들림     | .to() & ease 사용      |
페이드 아웃	태그가 점점 사라짐	.to() (opacity: 0)
확장(Expand)	태그가 점점 커지면서 나타남	.fromTo(), scale
축소(Shrink)	태그가 점점 작아지면서 사라짐	.to(), scale
튕기는 효과(Bounce)	태그가 점프하듯 튕기는 애니메이션	.to() & ease: "bounce.out"
진동 효과(Vibration)	태그가 빠르게 흔들림 (떨림 효과)	.to() & repeat: -1, yoyo: true
타이핑 효과(Typing)	글자가 한 글자씩 나타나는 효과	.fromTo(), stagger
글리치 효과(Glitch)	화면이 일시적으로 깨지는 느낌을 줌	.set(), .to(), x: random(-10,10)
텍스트 확산(Text Spread)	글자가 점점 커지면서 퍼지는 효과	.fromTo(), scale, opacity
파도 효과(Wave)	태그가 물결처럼 부드럽게 움직임	.to(), x, ease: "sine.inOut"
배경 흐림(Blur In/Out)	배경이 흐려지면서 태그가 나타남	.to(), filter: "blur(10px)"
스케일 팝(Scale Pop)	태그가 작았다가 커지는 팝업 효과	.fromTo(), scale, ease: "back.out"
랜덤 이동(Random Motion)	태그가 화면을 랜덤하게 움직임	.to(), x: random(-100,100), y: random(-100,100)
비틀기(Twist)	태그가 비틀리는 듯한 효과를 줌	.to(), skewX, skewY
반짝임(Shimmering)	텍스트나 태그가 반짝이는 효과	.to(), opacity, repeat: -1, yoyo: true
무한 회전(Loop Rotation)	태그가 계속해서 회전하는 애니메이션	.to(), rotation, repeat: -1
드래그 가능(Draggable)	태그를 마우스로 드래그할 수 있음	Draggable.create()
스크롤 기반 애니메이션	스크롤 위치에 따라 동작하는 애니메이션	ScrollTrigger
배경색 전환(Background Color Change)	배경 색상이 점진적으로 바뀌는 효과	.to(), backgroundColor
텍스트 투명화(Text Opacity)	텍스트가 흐려지거나 투명해지는 효과	.to(), opacity
3D 카드 플립(Card Flip)	카드가 회전하며 뒤집히는 애니메이션	.to(), rotationY: 180
리프레쉬 효과(Refresh Effect)	태그가 새로고침하듯 깜빡이는 효과	.to(), opacity, repeat: -1, yoyo: true

## N초 마다 반복하는 애니메이션
`repeat`,`repeatDelay`,`yoyo` 옵션을 활용하면 n초마다 반복되는 애니메이션을 만들 수 있습니다.
```js
gsap.to(".box", {
  y: -50,
  duration: 1,
  repeat: -1,      // 무한 반복
  yoyo: true,      // 앞뒤로 반복
  repeatDelay: 1,  // 1초 쉬고 다시 실행
  ease: "power1.inOut",
});
```
- repeat: -1 → 무한 반복
- yoyo: true → 앞뒤로 자연스럽게 반복
- repeatDelay: 1 → 애니메이션 완료 후 1초 대기

<br/>

## GSAP Timeline
GSAP의 Timeline은 여러 개의 애니메이션을 순차적 또는 동시적으로 실행할 수 있도록 해주는 기능입니다.   
즉, 여러 개의 .to(), .from(), .fromTo() 애니메이션을 시간 흐름에 따라 관리할 수 있는 기능입니다.
```js
const tl = gsap.timeline();

tl.to(".box1", { x: 100, duration: 1 })
  .to(".box2", { x: 200, duration: 1 })
  .to(".box3", { x: 300, duration: 1 });
```

## 위로 올라갔다가 내려오는 애니메이션
|          애니메이션 명칭           |         설명          |          GSAP 속성           |
|:---------------------------:|:-------------------:|:--------------------------:|
|       Bounce (바운스 효과)       |  위로 튕겼다가 자연스럽게 내려옴  |     ease: "bounce.out"     |
| Ease In-Out (천천히 올라갔다 내려오기) | 부드럽게 올라갔다가 부드럽게 내려옴 |    ease: "power2.inOut"    |
|      YoYo (앞뒤로 반복 효과)       |   올라갔다 내려오는 걸 반복    |   repeat: -1, yoyo: true   |
|    Ping Pong (상하 왕복 이동)     |  일정 시간 간격으로 위아래 이동  | repeat: -1, repeatDelay: 1 |
|    Ping Pong (상하 왕복 이동)     |  위로 올라갔다가 부드럽게 내려옴  |     위로 올라갔다가 부드럽게 내려옴      |

### stagger 이슈 해결 방법
- stagger를 사용하면 요소들이 순차적으로 애니메이션되지만, 다시 돌아올 때 역순으로 실행됨   
➡ (요소3 → 요소2 → 요소1 순서로 돌아옴)

#### [해결 방법] timeline을 사용하여 각 요소에 개별 애니메이션 적용
```js
const tl = gsap.timeline();

tl.to(".item1", { y: -50, duration: 0.5 })
  .to(".item2", { y: -50, duration: 0.5 })
  .to(".item3", { y: -50, duration: 0.5 });
```
stagger는 동일한 애니메이션을 순차적으로 적용하므로,   
개별적인 바운스 효과를 주려면 timeline을 활용해야 한다.

#### [해결 방법] random 값을 활용하여 다르게 바운싱
```js
gsap.to(".item", {
  y: -50,
  duration: 1,
  ease: (i) => (i % 2 === 0 ? "bounce.out" : "elastic.out(1, 0.3)"),
  stagger: 0.2,
});
```
- 짝수 요소는 bounce, 홀수 요소는 elastic 효과 적용 
- stagger: 0.2 → 요소들이 순차적으로 실행됨

#### [해결 방법] random 값을 활용하여 다르게 바운싱
```js
gsap.to(".item", {
  y: gsap.utils.random([-100, -50, -80]), // 랜덤한 높이 설정
  duration: 1,
  ease: "bounce.out",
  stagger: 0.2,
});
```
- 요소마다 다른 높이로 바운스 효과 적용됨

```jsx
import {useEffect, useRef} from 'react';
import {gsap} from 'gsap'; // GSAP 코어 라이브러리 가져오기
import {ScrollTrigger} from 'Libraries/GSAP/ScrollTrigger/01_ScrollTrigger'; // GSAP의 ScrollTrigger 플러그인 가져오기

// ScrollTrigger 플러그인을 GSAP에 등록해야 사용 가능
gsap.registerPlugin(ScrollTrigger);

function TestGsap() {
  // DOM 요소에 접근하기 위한 ref 생성
  const headerRef = useRef(null);
  
  useEffect(() => {
    // 헤더 애니메이션 정의
    // gsap.from: 지정된 값에서 요소의 현재 값으로 애니메이션
    const showAnim = gsap.from(headerRef.current, {
      yPercent: -100,     // 시작 위치: 위로 100% 이동된 상태 (화면 밖)
      paused: true,       // 애니메이션을 일시 정지 상태로 생성
      duration: 0.2       // 애니메이션 지속 시간(초)
    }).progress(1);       // 애니메이션의 진행 상태를 끝(1)으로 설정 (처음에는 보이지 않음)
    
    // ScrollTrigger 생성 - 스크롤 이벤트에 반응하는 트리거 설정
    ScrollTrigger.create({
      start: "top top",   // 트리거 시작점: 문서 상단이 뷰포트 상단에 닿을 때
      end: 99999,         // 트리거 종료점: 사실상 무한대 (페이지 끝까지)
      onUpdate: (self) => {
        // 스크롤 방향 감지하여 애니메이션 제어
        // self.direction === -1: 위로 스크롤 (음수 방향)
        // self.direction === 1: 아래로 스크롤 (양수 방향)
        self.direction === -1 ? showAnim.play() : showAnim.reverse();
      }
    });
    
    // 컴포넌트 언마운트 시 ScrollTrigger 정리 (메모리 누수 방지)
    return () => {
      ScrollTrigger.getAll().forEach(trigger => trigger.kill());
    };
  }, []); // 빈 배열: 컴포넌트 마운트 시 한 번만 실행
  
  return (
    <>
      {/* 헤더 요소 - 스크롤에 따라 나타나거나 사라짐 */}
      <header
        ref={headerRef}
        style={{
          position: 'fixed',     // 뷰포트에 고정
          top: 0,                // 상단에 위치
          left: 0,               // 좌측에 위치
          width: '100%',         // 전체 너비 사용
          backgroundColor: '#333', // 배경색
          color: 'white',        // 글자색
          padding: '15px',       // 안쪽 여백
          zIndex: 100            // 다른 요소보다 위에 표시
        }}
      >
        헤더 내용이 여기에 들어갑니다
      </header>
      
      {/* 페이지 콘텐츠 - 스크롤을 위한 여백과 높이 지정 */}
      <div style={{paddingTop: '60px', height: '2000px'}}>
        스크롤을 내려보세요
      </div>
    </>
  );
}

export default TestGsap;

```

## GSAP의 주요 메소드 및 이벤트 종류
### GSAP 애니메이션 메소드
1. **gsap.to(target, vars)** - 현재 상태에서 지정된 값으로 애니메이션
2. **gsap.from(target, vars)** - 지정된 값에서 현재 상태로 애니메이션
3. **gsap.fromTo(target, fromVars, toVars)** - 지정된 시작 값에서 지정된 끝 값으로 애니메이션
4. **gsap.set(target, vars)** - 애니메이션 없이 속성 즉시 설정
5. **gsap.timeline()** - 여러 애니메이션을 순차적으로 또는 동시에 실행할 수 있는 타임라인 생성

<br/>

### 애니메이션 컨트롤 메소드
1. **play()** - 애니메이션 재생
2. **pause()** - 애니메이션 일시 정지
3. **reverse()** - 애니메이션 반대 방향으로 재생
4. **restart()** - 애니메이션 처음부터 다시 시작
5. **progress(value)** - 애니메이션 진행 상태 설정 (0-1 범위)
6. **seek(position)** - 애니메이션의 특정 시점으로 이동
7. **timeScale(value)** - 애니메이션 속도 조절 (1=정상, 0.5=절반 속도, 2=두 배 속도)
8. **kill()** - 애니메이션 제거 및 리소스 해제

<br/>

### ScrollTrigger 주요 속성 및 이벤트
1. **trigger** - 트리거 기준점이 될 DOM 요소
2. **start** - 트리거가 시작되는 위치 (예: "top bottom" = 요소 상단이 뷰포트 하단에 닿을 때)
3. **end** - 트리거가 끝나는 위치 (예: "bottom top" = 요소 하단이 뷰포트 상단에 닿을 때)
4. **pin** - 지정된 요소를 스크롤 동안 고정
5. **pinSpacing** - 핀 고정 시 공간 생성 여부 (true/false)
6. **scrub** - 스크롤 위치에 애니메이션 진행 연동 (true/숫자(지연시간))
7. **markers** - 개발 시 트리거 지점 표시 (디버깅용, true/false)
8. **toggleClass** - 활성화 시 클래스 추가/제거
9. **toggleActions** - 진입/퇴장 시 행동 정의 ("play pause resume reverse" 형식)

<br/>

### ScrollTrigger 콜백 이벤트
1. **onEnter** - 트리거 영역에 진입할 때 실행
2. **onLeave** - 트리거 영역을 떠날 때 실행
3. **onEnterBack** - 트리거 영역에 뒤로 돌아올 때 실행
4. **onLeaveBack** - 트리거 영역을 뒤로 떠날 때 실행
5. **onUpdate** - 스크롤 위치가 업데이트될 때마다 실행
6. **onToggle** - 활성/비활성 상태가 전환될 때 실행
7. **onRefresh** - 화면 크기 변경 등으로 ScrollTrigger가 새로고침될 때 실행

<br/>

### ScrollTrigger에서 자주 사용되는 특수 값
1. **self.progress** - 트리거 진행률 (0-1)
2. **self.direction** - 스크롤 방향 (-1: 위로, 1: 아래로)
3. **self.isActive** - 트리거가 활성 상태인지 여부 (true/false)
4. **self.getVelocity()** - 현재 스크롤 속도

## GSAP 애니메이션 속성 (변수)
### 위치 및 변형 관련 속성
- **x** - X축 이동 (픽셀 단위, 예: `x: 100`)
- **y** - Y축 이동 (픽셀 단위, 예: `y: 50`)
- **xPercent** - X축 이동 (요소 너비의 퍼센트, 예: `xPercent: 100`은 요소 너비만큼 이동)
- **yPercent** - Y축 이동 (요소 높이의 퍼센트, 예: `yPercent: -100`은 요소 높이만큼 위로 이동)
- **rotation** - Z축 기준 회전 (도 단위, 예: `rotation: 45`)
- **rotationX**, **rotationY**, **rotationZ** - 각 축 기준 회전
- **scale** - 모든 축의 크기 조절 (1=원래 크기, 예: `scale: 1.5`는 150% 크기)
- **scaleX**, **scaleY** - 개별 축 크기 조절
- **skew**, **skewX**, **skewY** - 비틀림 효과 (도 단위)
- **transformOrigin** - 변형의 중심점 (예: `transformOrigin: "center center"`)

<br/>

### 불투명도 및 색상
- **opacity** - 불투명도 (0~1, 예: `opacity: 0`은 완전 투명)
- **color** - 텍스트 색상
- **backgroundColor** - 배경 색상
- **borderColor** - 테두리 색상
- **fill**, **stroke** - SVG 요소의 채우기, 선 색상

<br/>

### 크기 및 위치
- **width**, **height** - 요소의 너비, 높이
- **top**, **right**, **bottom**, **left** - 위치 속성
- **perspective** - 3D 효과의 원근감

<br/>

### 애니메이션 제어 속성
- **duration** - 애니메이션 지속 시간 (초 단위, 예: `duration: 0.5`)
- **delay** - 애니메이션 시작 전 대기 시간 (초 단위)
- **paused** - 애니메이션 일시 정지 상태로 생성 (boolean)
- **repeat** - 반복 횟수 (-1은 무한 반복)
- **repeatDelay** - 반복 사이의 대기 시간
- **yoyo** - 반복 시 애니메이션 역방향 재생 여부 (boolean)
- **stagger** - 여러 요소 애니메이션 시 시간차 (예: `stagger: 0.1`은 각 요소마다 0.1초 간격)
- **ease** - 애니메이션 가속도 함수 (예: `ease: "power2.out"`, `ease: "elastic"`)

<br/>

## ScrollTrigger 속성
### 트리거 위치 설정
- **trigger** - 트리거 기준점이 될 DOM 요소 (예: `trigger: ".my-element"`)
- **start** - 트리거 시작 위치. 가능한 값 조합:
    - `"top top"` - 요소 상단이 뷰포트 상단에 닿을 때
    - `"top center"` - 요소 상단이 뷰포트 중앙에 닿을 때
    - `"top bottom"` - 요소 상단이 뷰포트 하단에 닿을 때
    - `"center top"` - 요소 중앙이 뷰포트 상단에 닿을 때
    - `"bottom top"` - 요소 하단이 뷰포트 상단에 닿을 때
    - `"top+=100 center"` - 요소 상단 + 100px이 뷰포트 중앙에 닿을 때
    - `"50% 75%"` - 요소의 50% 지점이 뷰포트의 75% 지점에 닿을 때
- **end** - 트리거 종료 위치 (start와 동일한 값 형식 사용)
- **endTrigger** - 종료 트리거로 사용할 다른 요소 (기본값은 시작 trigger와 동일)

<br/>

### 고정(Pin) 관련 속성
- **pin** - 스크롤 중 요소 고정 (boolean 또는 요소 지정)
- **pinSpacing** - 핀 고정 시 공간 생성 여부 (boolean)
- **pinReparent** - 핀 고정 시 요소의 부모를 변경할지 여부 (boolean)
- **pinType** - 핀 고정 방식 ("fixed" 또는 "transform")

<br/>

### 스크롤 동기화 속성
- **scrub** - 스크롤 위치에 애니메이션 진행 연동
    - `scrub: true` - 스크롤 위치에 즉시 반응
    - `scrub: 1` - 1초 지연으로 부드럽게 따라감
- **snap** - 스크롤 릴리스 시 가까운 지점으로 스냅
    - `snap: 1/4` - 1/4 간격으로 스냅
    - `snap: { snapTo: [0, 0.5, 1], duration: 0.5 }` - 특정 지점으로 스냅

<br/>

### 토글 및 클래스 속성
- **toggleClass** - 활성화 시 클래스 추가/제거
    - `toggleClass: "active"` - 단일 클래스
    - `toggleClass: { targets: ".sidebar", className: "show" }` - 대상 지정
- **toggleActions** - 트리거 진입/퇴장 시 행동 정의 (총 4개 값)
    - 첫 번째 값: 트리거 진입 시 (onEnter)
    - 두 번째 값: 트리거 퇴장 시 (onLeave)
    - 세 번째 값: 트리거 재진입 시 (onEnterBack)
    - 네 번째 값: 트리거 재퇴장 시 (onLeaveBack)
    - 가능한 각 값: "play", "pause", "resume", "reverse", "restart", "reset", "complete", "none"
    - 예: `toggleActions: "play reverse play reverse"`

<br/>

### 디버깅 속성
- **markers** - 개발 시 트리거 지점 표시 (boolean 또는 객체)
    - `markers: true` - 기본 마커 표시
    - `markers: { startColor: "green", endColor: "red", fontSize: "18px" }` - 커스텀 마커

<br/>

### 기타 속성
- **id** - ScrollTrigger의 고유 식별자
- **anticipatePin** - 핀 고정 전 성능 최적화 (숫자, 초 단위)
- **fastScrollEnd** - 빠른 스크롤 시 end 이벤트 처리 방식
- **preventOverlaps** - 여러 트리거 간 충돌 방지
- **horizontal** - 가로 스크롤 감지 (boolean)
- **once** - 트리거가 한 번만 작동하도록 설정 (boolean)

## 예제에서 사용된 속성 설명
```javascript
// 예제에서 사용된 속성 상세 설명
const showAnim = gsap.from(headerRef.current, {
  yPercent: -100,     // 요소의 높이 100%만큼 위로 이동된 상태에서 시작
  paused: true,       // 애니메이션이 자동으로 시작되지 않고 대기 상태로 생성
  duration: 0.2       // 애니메이션이 0.2초 동안 진행됨
}).progress(1);       // 애니메이션을 완료 상태(100%)로 설정

ScrollTrigger.create({
  start: "top top",   // 페이지 상단이 뷰포트 상단에 닿을 때 트리거 시작
  end: 99999,         // 사실상 무한대 값으로 페이지 끝까지 트리거 유지
  onUpdate: (self) => {
    // self.direction: 스크롤 방향을 나타내는 값
    // -1: 위로 스크롤, 1: 아래로 스크롤
    self.direction === -1 ? showAnim.play() : showAnim.reverse();
  }
});
```

## 더 복잡한 위치 속성 예제
```javascript
// 다양한 위치 속성 예제
ScrollTrigger.create({
  trigger: ".my-section",
  // 요소의 상단에서 20% 지점이 뷰포트의 중앙에 닿을 때 시작
  start: "top+=20% center", 
  // 요소의 하단에서 100px 위 지점이 뷰포트 상단에서 10% 아래 지점에 닿을 때 끝
  end: "bottom-=100 top+=10%",
  // ...기타 속성
});
```
