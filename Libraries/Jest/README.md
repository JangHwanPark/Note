## Jest란 ?
- JavaScript 코드를 테스트하는 테스트 프레임워크
- `describe` 로 테스트를 묶고, `test` 또는 `it` 으로 테스트를 만들고, `expect` 와 매처(Matcher)로 결과를 확인한다
- Vitest는 Vite 기반의 테스트 프레임워크로, Jest와 비슷한 API를 쓴다
